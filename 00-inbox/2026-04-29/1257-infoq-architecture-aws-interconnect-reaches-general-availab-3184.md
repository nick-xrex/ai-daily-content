# AWS Interconnect Reaches General Availability with Managed Multicloud and Last-Mile Connectivity

<img src="https://res.infoq.com/news/2026/04/aws-interconnect-multicloud-ga/en/headerimage/generatedHeaderImage-1777119366386.jpg" /><p>AWS Interconnect reached general availability, offering managed private Layer 3 connections to Google Cloud and a last-mile capability via Lumen. Azure and OCI support is planned for later in 2026. AWS published the underlying specification on GitHub under Apache 2.0, which Forrester analysts read as a play to set a de facto standard for multicloud connectivity.</p> <i>By Steef-Jan Wiggers</i>
