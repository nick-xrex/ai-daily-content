# pnpm 11 Release Candidate: ESM Distribution, Supply Chain Defaults and a New Store Format

<img src="https://www.infoq.com/styles/static/images/logo/logo_bigger.jpg" /><p>pnpm 11 RC has been released, featuring significant changes in performance, security, and configuration. Key updates include an SQLite-backed store index, tighter security defaults, and a consolidated build script setting. It now requires Node.js v22 or later. Global installs are isolated by default, and new commands enhance usability. Migration guidance is available in the documentation.</p> <i>By Daniel Curtis</i>
