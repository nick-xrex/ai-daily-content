# Microsoft Releases Aspire 13.3 with Major Deployment and Frontend Updates

Microsoft has released Aspire 13.3, introducing a new aspire destroy command for tearing down deployments across Azure, Kubernetes, and Compose. The release adds native Kubernetes deployment in preview, first-class JavaScript publishing for Next.js and Vite, browser log capture, and a default-enabled container tunnel, alongside several breaking changes developers should review. By Almir Vuk
