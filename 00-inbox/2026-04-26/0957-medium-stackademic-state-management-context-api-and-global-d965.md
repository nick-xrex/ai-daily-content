# State Management: Context API and Global State

<figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*2CtDhxNZN7e2-QN5KqvzlQ.png" /></figure><p>So far, you’ve been managing state inside individual components using useState. That works well for small features, but real-world apps need something more structured.</p><p>As your app grows, multiple screens often need access to the same data — like user info, authentication status, or app settings. This is where <strong>global state management</strong> comes in.</p><h3>Why State Management Matters</h3><p>Imagine this situation:</p><ul><li>User logs in on one screen</li><li>You need user data on the dashboard</li><li>You also need it in the profile screen</li></ul><p>Passing data through props across multiple screens becomes messy and hard to maintain.</p><p>State management solves this problem.</p><h3>What is Global State?</h3><p>Global state is data that can be accessed from anywhere in your app.</p><p>Examples:</p><ul><li>Logged-in user</li><li>Theme (dark/light)</li><li>Cart items (in e-commerce)</li><li>App settings</li></ul><h3>Context API (Built-in Solution)</h3><p>React provides Context API to manage global state without extra libraries.</p><p>It’s simple and works well for most apps.</p><h3>Step 1: Create Context</h3><pre>import { createContext } from 'react';</pre><pre>export const AuthContext = createContext();</pre><h3>Step 2: Create Provider</h3><pre>import { useState } from 'react';<br />import { AuthContext } from './AuthContext';</pre><pre>export function AuthProvider({ children }) {<br />  const [user, setUser] = useState(null);</pre><pre>  return (<br />    &lt;AuthContext.Provider value={{ user, setUser }}&gt;<br />      {children}<br />    &lt;/AuthContext.Provider&gt;<br />  );<br />}</pre><h3>Step 3: Wrap Your App</h3><pre>import { AuthProvider } from './AuthProvider';</pre><pre>export default function App() {<br />  return (<br />    &lt;AuthProvider&gt;<br />      {/* rest of app */}<br />    &lt;/AuthProvider&gt;<br />  );<br />}</pre><h3>Step 4: Use Context Anywhere</h3><pre>import { useContext } from 'react';<br />import { AuthContext } from './AuthContext';</pre><pre>export default function Profile() {<br />  const { user } = useContext(AuthContext);</pre><pre>  return &lt;Text&gt;{user?.name}&lt;/Text&gt;;<br />}</pre><pre>Give feedback</pre><h3>Updating Global State</h3><pre>const { setUser } = useContext(AuthContext);</pre><pre>setUser({ name: 'John' });</pre><h3>Real Example: Login Flow</h3><ul><li>User logs in</li><li>Save user in global state</li><li>Access user anywhere</li></ul><p>This avoids passing props between screens.</p><h3>When to Use Context API</h3><p>Context API is perfect for:</p><ul><li>Authentication</li><li>Theme settings</li><li>Small to medium apps</li></ul><h3>Limitations of Context API</h3><p>For large applications:</p><ul><li>Performance can be affected</li><li>Too many updates can cause re-renders</li></ul><h3>Other State Management Options</h3><p>For bigger apps, developers use:</p><ul><li>Redux Toolkit</li><li>Zustand</li><li>Recoil</li></ul><p>But for now, Context API is enough.</p><h3>Best Practices</h3><p>To keep things clean:</p><ul><li>Create separate contexts (Auth, Theme, etc.)</li><li>Avoid storing too much data in one context</li><li>Keep logic inside provider</li><li>Use custom hooks for cleaner code</li></ul><h3>Custom Hook Example</h3><pre>import { useContext } from 'react';<br />import { AuthContext } from './AuthContext';</pre><pre>export const useAuth = () =&gt; useContext(AuthContext);</pre><p>Usage:</p><pre>const { user } = useAuth();</pre><h3>Common Mistakes</h3><ul><li>Putting everything in one context</li><li>Not wrapping the app properly</li><li>Overusing global state</li><li>Mixing local and global state unnecessarily</li></ul><h3>Practice Task</h3><p>Build this:</p><ul><li>Login screen</li><li>Save user in Context</li><li>Show user name on another screen</li></ul><h3>Conclusion</h3><p>State management is what connects your entire app. Once you understand how to manage global state, your app becomes more organized and easier to scale.</p><p>Start with Context API, and as your app grows, you can explore more advanced tools.</p><h3>A message from our Founder</h3><p>Hey, <a
