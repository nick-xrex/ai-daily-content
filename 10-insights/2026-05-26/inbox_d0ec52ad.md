## Java News Roundup: WildFly, Micronaut, Spring AI, Apache Fory, GlassFish Plugin, Open Liberty

2026 年 5 月 18 日的 Java 新聞總整理涵蓋多個重要版本發布。WildFly 40、Micronaut 5.0、Maven Embedded GlassFish Plugin 8.0 和 Apache Fory 1.0 均達成 GA 發布。Open Liberty 發行 2026 年 5 月版本，Spring AI 2.0 發布第七個里程碑版本（M7）。此外還包括 Gatherers4j 和 Apache Kafka 的點版本更新。這反映 Java 生態持續演進，特別是在框架現代化和企業應用支援方面的進展。

### 重點
- WildFly 40、Micronaut 5.0、Apache Fory 1.0 GA 發布；Spring AI 2.0 M7 里程碑版本
- Maven Embedded GlassFish Plugin 8.0 GA 發布
- Open Liberty 2026 年 5 月版本及多個專案點版本更新
