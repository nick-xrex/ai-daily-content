## Google Expands SynthID Adoption for AI Watermarking, Previews Content Detection API

Google 的 SynthID 內容偵測 API 在 Google Cloud 的 Gemini Enterprise Agent Platform 上預覽。SynthID 透過在 AI 生成內容中嵌入不可察覺的浮水印信號，協助識別人工智慧輸出。該技術已獲得 Nvidia 和 OpenAI 等業界重要參與者採用。Google Cloud 客戶現可使用此 API 來驗證內容真實性。這對於規模部署企業的內容來源追蹤具有實務意義，特別是在內容真實性驗證成為合規要求的情況下。

### 重點
- SynthID 內容偵測 API 預覽，於 Google Cloud Gemini Enterprise Agent Platform
- 已被 Nvidia 和 OpenAI 採用的浮水印標記技術
- 在 AI 生成內容中嵌入不可察覺信號，用於真實性驗證
