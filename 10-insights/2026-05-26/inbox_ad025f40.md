## I Tried Andrej Karpathy CLAUDE.MD File (That Got 157K GitHub Stars)

Andrej Karpathy 於 2026 年 1 月在 X 發表針對 Claude Code 編程失敗的深度觀察，引發社群廣泛討論。他指出個人編程工作流在數週內從 80% 手工編碼翻轉至 80% 代理編碼，稱之為二十年編程生涯中最大變化。Karpathy 提出三大關鍵失敗模式：模型自作假設後逕行執行而不驗證、過度複雜化代碼與抽象層、以及無差別修改或移除自身不理解的註釋與代碼。該指南透過明確的失敗框架，協助開發者改進 Claude Code 配置與提示策略，已在 GitHub 獲得 157K 星星。
