## vscode-v0.4.0: release(vscode): v0.4.0 (#910)

Repowise 發布 VS Code 擴展 v0.4.0，整合自 v0.27.0 以來積累的 UI 變更（graph、health、docs、C4 元件）。MIN_SERVER_VERSION 保持 0.26.0，無需新伺服器契約變更。此版本在 release checklist 新增「bundled-UI freeze trap」追蹤項目，防止未來UI整合問題。

### 重點
- VS Code 擴展 v0.4.0 發布，封裝 graph、health、docs、C4 UI 功能
- MIN_SERVER_VERSION 保持 0.26.0，確保向後相容性
- Release checklist 新增 bundled-UI freeze trap 追蹤項目

# vscode-v0.4.0: release(vscode): v0.4.0 (#910)

Bump the extension to 0.4.0 to ship the accumulated @repowise-dev/ui changes 
(graph, health, docs, C4) that have been bundled but unreleased since the 
extension last shipped at the v0.27.0 commit. MIN_SERVER_VERSION stays at 0.26.0 
(no new server contract required). Document the bundled-UI freeze trap in the 
release checklist.
