## Moonrepo Releases Moon v2.0 with WASM Plugin Toolchains and Overhauled CLI

Moonrepo 發布主版本 v2.0，這是 v1 以來首次大幅更新，標示核心架構演進。新版引入 WebAssembly（WASM）驅動的插件工具鏈系統，容許開發者透過插件擴展構建工具能力。組態層面，v2.0 支持 JSON 與 TOML 等多格式，減少框架鎖定並提升組態靈活性。CLI 層經完整重構，強化任務繼承機制、Docker 容器整合與 VCS（版本控制）支持。此版本標示 Moonrepo 從單一工具鏈邁向開放擴展性平台的轉變。

### 重點
- 插件架構：WASM 驅動的工具鏈系統，容許第三方擴展而無需核心修改
- 組態靈活性：支持 JSON、TOML 多格式，減少框架鎖定
- CLI 重構與增強：任務繼承改進、Docker 支持、VCS 整合優化

# Moonrepo Releases Moon v2.0 with WASM Plugin Toolchains and Overhauled CLI

Moonrepo has released moon v2.0, its first major update since v1, featuring a plugin-based toolchain system and support for multiple configuration formats including JSON and TOML. The CLI has been restructured, enhancing task inheritance and Docker integration. Notable changes include a shift in architecture and improvements to VCS support. By Daniel Curtis
