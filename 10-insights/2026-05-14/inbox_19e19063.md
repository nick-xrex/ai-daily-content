## VS Code's new \"Agents window\" lets you use local AI models. Still requires an Internet connection and a Github Copilot plan (because we can't have nice things)

VS Code 推出新的「Agents window」功能號稱支援本地 AI 模型，但社群發現實際仍需網際網路連接和 GitHub Copilot 訂閱計畫。用戶評論指出這不符合「本地」的期待，質疑功能設計缺乏真正離線能力。

### 重點
- VS Code 的「本地」agents 實際需要網際網路和 GitHub Copilot 付費訂閱，偏離本地優先理想
- 社群認為此功能尚未成熟，需觀望社群能否繞過限制或推出真正本地版本
