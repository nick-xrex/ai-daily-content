## I built Enlive, a free website that makes LLM prompting easier in 40 languages

作者開發了 Enlive，一個免費網站工具，支援 40 種語言，旨在簡化用戶撰寫 LLM prompt 的流程。作者指出『輸入障礙』——即用戶難以有效表達需求給 LLM——是 LLM 應用的關鍵瓶頸，儘管模型能力已大幅進步。Enlive 通過提供結構化的 prompt 輔助，降低非技術用戶的使用門檻，擴大 LLM 的可及性。

### 重點
- Enlive：支援 40 種語言的免費 LLM prompt 輔助工具
- 核心痛點：輸入障礙，用戶難以撰寫有效 prompt
- 目標：降低 LLM 使用門檻，擴大非技術用戶可及性
