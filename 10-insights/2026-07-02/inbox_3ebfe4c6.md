## SwiftUI Adds New Document Protocol, Improves Performance, and More

Apple 在 WWDC 2026 發表 SwiftUI 最新版本，引入 Document protocol 用於高效磁碟存取和快照式更新。新增列表、網格和分區的項目重排 API，擴展展示功能（如任意視圖的滑動操作、AsyncImage 快取改進）。Observable 類型的懶初始化狀態可提升性能。

### 重點
- Document protocol 實現快照式更新與磁碟存取優化
- 列表、網格、分區的重排 API 簡化開發
- AsyncImage 快取改進和 Observable 懶初始化提升運行效能
