## Release Candidate v1.6.9-rc.43

GitNexus v1.6.9-rc.43 發布。本版本包含 44 個主要變更和修復，重點在 Python/Java/Kotlin 污點分析、多倉庫 PDG 追蹤、Django 路由提取、全文搜尋 CJK 支持等功能完善。新增 Kilo Code 與 GitNexus MCP 設定指南，便利工具集成。此版本為發布候選版，供社群早期測試反饋。

### 重點
- 完整的 Python、Java、Kotlin 多語言污點分析和路由提取，跨倉庫 PDG 追蹤能力
- 全文搜尋增強：FTS stemmer 可配置、向量距離閾值調整、CJK 雙字符分割
- MCP 支援文件發布，提供 Kilo Code + GitNexus 整合指南
