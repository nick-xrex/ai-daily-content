## Release Candidate v1.6.9-rc.39

GitNexus v1.6.9-rc.39 發布。本版本新增 Python 和 Java 污點分析模型、Kotlin Spring HTTP 消費者提取、Django 多倉庫路由提取、跨倉庫 PDG 調用追蹤、全文搜尋的 CJK 雙字符分割。修復 LadybugDB 雙重釋放和連接序列化、Windows 橋接重開、FastAPI APIRouter 前綴應用等問題。為發布候選版本，供測試。

### 重點
- 污點分析框架新增：Python 來源和目標識別，Java 保守策略模型，Kotlin Spring 支援擴展
- 跨倉庫依賴分析：PDG 實現倉庫間調用追蹤，多倉庫環境下的代碼依賴可視化
- 搜尋能力強化：全文搜尋 CJK 雙字符分割支持，提升中文代碼倉庫搜尋品質
