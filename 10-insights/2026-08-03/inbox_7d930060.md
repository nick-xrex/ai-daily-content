## How to Build CLI Agents with Python & Ollama

教程文章介紹如何使用 Python 和 Ollama 在本地環境免費建構 CLI 代理。文章指導讀者從零開始創建完整代理，無需調用付費 API，利用開源 Ollama 模型運行器實現。此方法使開發者在本地實驗代理型 AI 模式，避免基礎設施成本和外部依賴。文章重點是 CLI 型自主代理的實踐實現方法。適合快速原型開發或學習代理架構的開發者。

### 重點
- Python + Ollama 本地建構 CLI 代理，完全免費無需 API 金鑰
- 支援本地執行，無外部依賴和雲端成本
- 適合原型開發和代理型 AI 模式的本地實驗
