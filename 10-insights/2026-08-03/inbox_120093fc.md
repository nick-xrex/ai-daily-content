## ChatGPT Codex Voice + browser + Sites: an expert’s AI workflow | Nick Baumann (OpenAI)

ChatGPT Voice 推出三項重大功能更新：(1) 多線程管理，允許在對話中同時處理多個任務主線；(2) 屏幕讀取能力，賦予模型視覺上下文感知；(3) 後台任務執行，支持自主運行異步操作。Nick Baumann (OpenAI) 在 Lenny's Podcast 中展示完整工作流程。這些功能合力使 ChatGPT 逼近真正的 agent 能力——從被動對話助手向主動、感知、執行的智能體方向演進。多線程支持並行對話而不丟失上下文，屏幕讀取增強對用戶實時工作環境的理解，後台任務執行標誌著主流 LLM 平台在 agent 化方向的實質推進。

### 重點
- ChatGPT Voice 支持多線程對話管理（multiple threads），允許並行討論不同主題而保持上下文完整性
- 屏幕讀取功能提供視覺上下文感知，使模型能理解用戶當前工作環境與具體場景需求
- 後台任務執行支持自主運行工作流程，標誌 LLM 向真正 agent 能力（感知、記憶、自主執行）的邁進
