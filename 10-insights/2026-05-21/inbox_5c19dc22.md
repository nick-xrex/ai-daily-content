## datasette-agent-charts 0.1a2

datasette-agent-charts 0.1a2 發布，改進圖表可見性。新增「View SQL query」按鈕，用戶可直接查看生成圖表的底層 SQL 查詢，提升透明度和可調試性。

### 重點
- 新增 SQL query 查看按鈕於圖表下方，幫助用戶理解資料如何轉化為視覺化，改善可解釋性
