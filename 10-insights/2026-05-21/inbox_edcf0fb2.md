## Top 10 Claude Prompts That Make AI Feel Like a Real Assistant

Sam Loh 論述良好 prompting 為可習得技能，將 Claude 從聊天機器人轉化為策略顧問、編輯、研究員等角色。文章列舉 10 個高效 prompt patterns，包含：(1) 針對特定受眾深度的『Explain Like Expert』(2) 改進文章流暢度的『Rewrite Flow』(3) 批判性評價的『Think Like Critic』(4) 透過約束激發創意的『Better Ideas』(5) 組織混亂想法的『Turn to Structure』(6) 尋找盲點的『Find Blind Spots』(7) 學習風格模仿的『Write Like Person』(8) 保留細微差別的『Condense』(9) 角色扮演策略的『Act Strategist』。每個 pattern 皆具體應用場景示例（行銷、部落格、決策、研究等）。

### 重點
- 9 個具體 Claude prompt 模式可直接應用：Explain Like Expert / Rewrite Flow / Think Like Critic / Better Ideas / Turn to Structure / Find Blind Spots / Write Like Person / Condense / Act Strategist
- Prompt 工程將 Claude 角色轉化：從聊天機器人 → 策略顧問、編輯、批判者、組織者、顧問
- 強約束與特定角色設定提升創意質量，優於模糊寬泛的指令
