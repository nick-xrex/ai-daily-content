## rc/797e4ef8f6d426478b8af305369007ce1541265d: fix(ai-context): document CLI graph fallbacks (#2803)

GitNexus 發布 RC 版本，增強 AI 上下文文檔教導 agent 在 MCP 不可用時切換至存放庫作用域的 CLI 備用方案。此設計透過將強制 MCP 圖形檢查與 CLI 備用方案配對，實現多層韌性結構，使 agent 在 MCP 層故障時仍能透過 CLI 介面完成操作。該模式提升系統的故障恢復能力，是分散式系統中常見的降級策略。
