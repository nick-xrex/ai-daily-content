## Build an LLM Agent That Can Write and Run Code

Towards Data Science 教程示範如何使用 OpenAI Agents SDK 搭配 Docker 構建可執行程式碼的 LLM agent。文章採取實踐導向，逐步引領開發者實現 agent 寫入、編譯、執行程式碼的完整迴圈流程。Docker 整合提供隔離的程式碼執行環境，降低安全風險，適合 agent 開發初學者快速原型化。

### 重點
- OpenAI Agents SDK 的具體實踐步驟：程式碼生成→編譯→執行→反饋迴圈
- Docker 隔離容器提供程式碼執行沙箱，防止惡意代碼對主機的影響
- 端到端教程適合初學者快速上手 agentic 工作流程
