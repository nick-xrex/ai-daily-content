## Unleashed power of AI agents on Intel® ArcTM Pro B70 GPU with OpenVINOTM Model Server.

Intel 展示了使用 Arc Pro B70 GPU 和 OpenVINO Model Server 實現高效本地 AI agents 部署的方案。Arc Pro B70 是 Intel 專業 GPU，針對 AI 推理計算進行優化；OpenVINO Model Server 提供 OpenAI-compatible API 界面，使開發者可無縫集成現有工具鏈。該解決方案支持開發者在本地運行 AI agents，避免雲端依賴，同時保持與現有 OpenAI API 生態的兼容性。這對追求數據隱私和成本控制的企業具有實務價值。

### 重點
- Intel Arc Pro B70 GPU 針對 AI 推理計算優化，專業級硬件設計
- OpenVINO Model Server 提供 OpenAI-compatible API 介面實現生態兼容
- 完整方案支持本地部署 AI agents，避免雲端依賴、降低數據隱私風險
