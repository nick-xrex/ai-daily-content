## Your harness, your memory

文章探討了 agent harness（代理框架）成為主流的趨勢。作者指出 agent harness 已成為構建 agent 的主流方式，這是長期的、不可逆的趨勢。文章核心洞察是 harness 與記憶系統之間存在緊密的內在聯繫。設計 harness 時必須同時考慮記憶管理、上下文持久性等需求。Harness 的設計決策直接影響 agent 的長期可靠性與擴展能力。這些考慮對於構建生產級別的 agent 系統至關重要。

### 重點
- Agent harness 正成為構建 agent 的主流且不可逆轉的範式
- Harness 設計與記憶系統不可分割，必須聯合考慮架構與持久化策略
- Harness 決策直接影響 agent 的長期可靠性、知識積累與系統擴展性
