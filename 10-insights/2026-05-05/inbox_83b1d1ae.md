## Both ChatGPT & Grok think Musk will defeat OpenAI in the trial

对比 ChatGPT 与 Grok 在法律推理中的能力差异。作者分析 Musk 诉 OpenAI 案：在「Instant Mode」下，两个 LLM 都认为 Musk 败诉；切换至「Thinking Mode」并要求使用「第一原则推理」（排除已发表专家意见）后，两者均改口认为 Musk 更可能胜诉。ChatGPT 进一步指出胜诉范围有限（不一定能回到非营利模式）。核心发现：推理模式选择深刻影响 LLM 的分析质量——Thinking Mode + 第一原则推理能使 LLM 超越从众偏差，生成差异化的独立判断。

### 重點
- Instant Mode 下两个 LLM 都倾向跟随已发表的专家意见认为 Musk 败诉
- Thinking Mode + 第一原则推理后，两者改口认为 Musk 胜诉概率更高
- 推理模式切换可大幅改变 LLM 的输出，Thinking Mode 能更好地实现独立分析
