## Demand-Driven Context: A Methodology for Coherent Knowledge Bases Through Agent Failure

IKEA Digital 講者分享企業 AI 代理的知識庫構建方法論。傳統自上而下策展知識庫常失敗，改為「需求驅動」：給代理真實問題，觀察失敗點揭示缺失知識。提出知識三層（Green=通用、Orange=已教授、Red=機構/隱性知識）、代理生命週期（問題→發現→文檔化），用 GitHub 存儲知識庫，展示 14 個事件案例如何提升代理信心度。用 Meta Model 管理域名關係。影片 68 分 15 秒，觀看 6,635 次，是可落地的企業 AI context 管理框架。

### 重點
- 知識三分法（Green/Orange/Red）和「需求驅動」優於自上而下策展：觀察代理失敗點，正是缺失知識的訊號
- 14 個真實事件案例驗證：同知識庫在解決類似問題時信心度逐步提升，說明知識累積和複用的效應
- GitHub 作為知識庫存儲、Meta Model 管理域名關係、80/20 法則和 cache-based context 優化都是可直接套用的實踐模式
