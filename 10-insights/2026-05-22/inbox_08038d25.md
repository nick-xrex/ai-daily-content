## Welcome! This interactive guide is designed for absolute beginners.

Yerram Naidu Parupalli 編寫初學者 15 分鐘 Claude 互動指南，強調四元素 prompt 結構：Task（任務）+ Context（上下文）+ Format（格式）+ Tone（語調）。指南列舉常見錯誤（模糊請求、缺乏脈絡、期望一次完美）並提供五個實踐應用（草稿郵件、筆記摘要、腦力激盪等），搭配 prompt 範本與檢查清單。教學導向，無技術障礙。

### 重點
- Prompt 四元素公式：Task + Context + Format + Tone，適用於大多數初級任務
- 常見陷阱：模糊請求、過度複雜、缺乏上下文、期望一次完美（應該迭代）
- 實踐應用五項：草稿郵件、筆記摘要、腦力激盪、文字優化、概念學習
