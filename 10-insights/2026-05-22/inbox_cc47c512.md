## xAI Releases Grok Skills and Updates Tool Calling Responses API

xAI 推出 Grok 4.3 的 Grok Skills 功能，支持用戶在會話間保留自定義專業知識。同時增強 Tool Calling Responses API，提升工具調用能力。該功能使 Grok 模型具備跨對話的持久化個性化能力，用戶可保留自定義工具和專業知識配置。

### 重點
- Grok Skills 支持跨會話持久化自定義專業知識
- Tool Calling Responses API 增強工具調用能力
- 用戶可在多輪對話間保持自定義配置
