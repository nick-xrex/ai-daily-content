## xAI Releases Grok Skills and Updates Tool Calling Responses API

xAI 發佈 Grok 4.3 模型新功能 Grok Skills，支援持久化客製專長，模型可在多個對話中保留並運用這些自定義能力。同時增強 Responses API，提升工具調用功能。此更新使 Grok 用戶能定制模型行為，類似 OpenAI GPTs 概念。

- Grok Skills — 持久化客製專長，對話間保留記憶
- Responses API 增強工具調用能力
