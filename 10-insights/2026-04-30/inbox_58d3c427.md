## Cloudflare Announces Agent Memory, a Managed Persistent Memory Service for AI Agents

Cloudflare 推出 Agent Memory（私密測試），為 AI agents 提供託管持久記憶服務。核心機制是自動從 agent 對話中提取結構化記憶，使用五通道並行檢索加 Reciprocal Rank Fusion 技術進行召回。支持 agent 團隊的共享記憶配置，增強多 agent 協作能力。競品生態包括 Mem0、Zep、LangMem、Letta，表明 agent memory 已成為關鍵基礎設施。

### 重點
- 五通道並行檢索 + Reciprocal Rank Fusion 演算法，從對話自動提取結構化記憶
- 支持 agent 團隊共享記憶配置，新增多 agent 協作的知識共享機制
- 競品眾多（Mem0, Zep, LangMem, Letta），agent memory 已成為標準基礎設施層
