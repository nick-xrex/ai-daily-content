## Cloudflare Announces Agent Memory, a Managed Persistent Memory Service for AI Agents

Cloudflare 宣布推出 Agent Memory 托管服務（私密測試），可從 AI agent 對話中提取結構化記憶，並通過五通道並行檢索搭配倒數排名融合(RRF)精準檢索。支持共享記憶檔案讓 agent 團隊訪問共同知識，直接對標 Mem0、Zep、LangMem、Letta 等現有競爭方案。

### 重點
- 五通道並行檢索 + 倒數排名融合(RRF)實現高效記憶檢索機制
- 共享記憶檔案(Shared Memory Profiles)允許 agent 團隊協作訪問共同知識庫
- 進入私密測試階段，主要競爭對手：Mem0、Zep、LangMem、Letta
