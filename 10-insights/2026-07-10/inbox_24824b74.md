## Release Candidate v1.6.10-rc.15

GitNexus v1.6.10-rc.15（Release Candidate，npm install gitnexus@rc）包含 25+ 項改進。核心成就包括全 Codex 支援（hooks、plugin marketplace、完整 setup flow）、CodeBuddy 與 Qoder 編碼 agent 整合、Proxy-blocked 環境 onnxruntime-node 自癒機制、FTS extension LOAD 錯誤診斷與自癒、MCP symbol content 精確定位（0-based 行號存儲 + 1-based MCP 顯示協議）、Windows FTS 依賴診斷、HTTP embedding endpoint 錯誤報告改進、FastAPI 路由常數解析修復、Windows 跨平台 CI timeout 修復、MCP query hint DB lock 偵測機制、以及大型增量 writeback 可靠性改進（#2425）。

### 重點
- Codex 完整整合：hooks、plugin marketplace、setup flow，新增 CodeBuddy 與 Qoder 編碼 agent 編排能力
- MCP DB lock query hint 模式：伺服器持有 DB lock 時自動發出 hint，解決分散系統中的鎖爭搶問題
- 三層自癒機制：Proxy-blocked postinstall（onnxruntime-node）、FTS extension 診斷、HTTP embedding endpoint 自動恢復
