## Java News Roundup: TornadoVM 5, JHipster, Google ADK, OmniFish Build of Payara, Introducing Vidocq

2026 年 7 月第一周的 Java 生態新聞匯總涵蓋多個主要版本發布：TornadoVM 5.0 正式版、JHipster 與 Keycloak 的維護版本、Google ADK 更新、GraalVM Native Build Tools 和 Micronaut 維護版本、新的 OmniFish 版本 Payara，以及新推出的 Vidocq（Jakarta EE 11 Core Profile 和 MicroProfile 7.1 實裝）。此為 Java 開發工具鏈的常規週期更新摘要，主要面向需要追蹤框架和基礎設施工具升級的開發者。

### 重點
- TornadoVM 5.0 宣佈正式版本 (GA)
- Vidocq 是新推出的 Jakarta EE 11 Core Profile 和 MicroProfile 7.1 實裝
- GraalVM、Micronaut、Keycloak 等核心工具完成維護版本更新
