## AWS Expands DevOps Agent with AI-Powered Release Management to Validate Code Before Production

AWS 宣布擴展 AWS DevOps Agent，增加 AI 驅動的發布管理功能，可自動評估代碼變更、執行軟體測試並在生產前驗證。新功能旨在自動化 CI/CD 流程中的代碼審核和測試環節，減少人工介入並加快交付速度。該擴展標誌著 AWS 將代理式 AI 應用於 DevOps 工作流的產品化進展。

### 重點
- AWS DevOps Agent 新增自動化發布管理能力，涵蓋代碼評估與測試驗證
- 代理可在生產前自動驗證代碼變更，集成於 CI/CD 流程
- AI 驅動自動化有助於降低人工審核成本和加快軟體交付周期
