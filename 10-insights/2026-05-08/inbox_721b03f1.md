## When using Claude Code for agent-based coding, I’ve often noticed that the AI limits itself by claiming that a task could take a developer several weeks to complete, and therefore suggests solutions that are more like quick fixes. That’s complete nonsense, of course.

使用者回報 Claude Code 的一項傾向：AI 過度保守地估計任務時間（聲稱需要多週開發），因此傾向提出快速修補而非全面解決方案。發文者認為這低估了 Claude 的實際能力，希望 Claude 更了解自己的速度和能力。

### 重點
- Claude Code 傾向因時間悲觀而自我限制，建議快速修補而非徹底重構
- 使用者期待 Claude 知道自己能在數小時內完成原本預估的週級任務
