## v2.1.136

Claude Code v2.1.136 修復了 40 多個 bug。重點修復：(1) MCP 伺服器在 /clear 後消失的問題——使用者在多個遠端 MCP 伺服器場景下不再需要每日重新認證；(2) OAuth 刷新令牌在併發更新時遺失導致登入迴圈；(3) Plan Mode 檔案寫入權限檢查失效；(4) WSL2 影像貼上支援（PowerShell fallback）。另外改進了 UI 視覺一致性（slash 指令對話框、bash 輸出色彩位置、ReasonML diff 渲染）。

### 重點
- MCP OAuth 刷新令牌併發更新問題已修復——多台遠端 MCP 伺服器使用者不再需要每日重新認證
- Plan Mode 檔案寫入權限檢查失效問題修復——即使存在 Edit(...) allow 規則，仍能正確阻擋未授權寫入
- 修復 40+ 個 bug，涵蓋 MCP 伺服器持久化、OAuth 登入迴圈、WSL2 影像貼上、UI 色彩渲染等
