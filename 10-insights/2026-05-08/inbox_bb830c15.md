## Thank you for the doubled Claude Code plans limits!

Anthropic 宣布將 Claude Code 計劃的使用額度加倍。根據用戶分享的截圖，訂閱客戶獲得明顯增加的配額分配。此舉改善了高頻用戶的服務價值主張，降低額度耗盡導致服務中斷的風險。

### 重點
- Claude Code 計劃額度翻倍（具體倍數從截圖可見，用戶獲得更高配額）
- 高頻使用者受益：額度增加降低開發工作因配額限制而中斷的風險
- 產品策略信號：Anthropic 針對訂閱用戶的投資擴大
