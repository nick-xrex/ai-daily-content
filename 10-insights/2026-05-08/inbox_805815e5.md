## You can now read Gemma 3's mind

Anthropic 與 Neuronpedia 發布自然語言自動編碼器（NLA）技術，可解釋 Gemma 3 27B 在生成每個 token 時的內部推理過程。NLA 由兩個 LLM 組成：自動驗證器（AV）將 LLM 激活翻譯為可讀文本，激活重建器（AR）驗證轉換的可逆性。用戶可在 Neuronpedia 網頁上與 Gemma 3 互動，點擊任意 token 檢視模型生成時的思考內容。具體案例：提示「I am Elon Musk」時，模型在初始 token 階段即內部標記該輸入為「虛構」和「諷刺」，展示模型的隱性評估能力。此工具首次使 LLM 的內部表示以人類可讀的方式被檢查和驗證。

### 重點
- 開源模型權重：Auto Verbalizer (kitft/nla-gemma3-27b-L41-av) 和 Activation Reconstructor 在 Hugging Face 可用
- 互動式檢查界面：Neuronpedia 提供網頁工具直觀展示每 token 的模型推理內容
- 驗證真實案例：「I am Elon Musk」在初始 token 階段已標記為虛構內容，展示模型的內部真實性評估

Anthropic has released new research to show what an LLM is thinking when generating next token using NLA or &quot;Natural Language Autoencoders&quot;, the NLAs are a pair of LLMs that can translate internal thoughts of LLM for any specific token. Neuronpedia in partnership with Anthropic have also released NLA model weights for Gemma 3 27b instruct at: - Auto Verbalizer (AV): https://huggingface.co/kitft/nla-gemma3-27b-L41-av - Activation Reconstructor (AR): https://huggingface.co/kitft/nla-gemma3-27b-L41-ar And Neuronpedia is currently hosting them on their site at https://www.neuronpedia.org/gemma-3-27b-it/nla So you go to neuronpedia link above, ask Gemma 3 a question, then click on any token and click explain, and the site will show you what the model was thinking when generating that token Auto Verbalizer (LLM) is what translates LLM's activations to readable text, Activation Reconstructor is just to verify if the text generated by AV can be translated back to LLM activations.
