## Release Candidate v1.6.9-rc.8

GitNexus v1.6.9-rc.8 发布，为目标稳定版 1.6.9 的第 8 个 RC 版本。相比 rc.12 缺少 HTTP 处理程序解析特性、Kotlin 语言修复。包含 Python 污点分析模型、修复 Ladybug 双重释放与连接序列化问题、Kotlin Spring HTTP 消费者提取、Django 多仓库路由提取、Java/Kotlin HTTP 消费者提取扩展、Java source/sink 模型、性能优化、PDG 跨仓库调用追踪。新贡献者参与。

### 重點
- 缺少 HTTP 处理程序多维度解析（命名跨文件、内联行号对应）与 Kotlin fun interface 修复
- 保留污点分析双模式（Python/Java）、Kotlin Spring、Django、Java/Kotlin 提取核心功能
- 包含 PDG 跨仓库与连接序列化硬化
