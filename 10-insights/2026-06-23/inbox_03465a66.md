## v0.23.0

Repowise v0.23.0 發布「倉庫理解與 MCP 增強」版本。強化 HTTP 契約提取：新增路由掛載前綴解析、HTTP consumer 衛生檢查、基礎 URL 服務解析，支援跨倉庫契約匹配；擴充 MCP get_health API 以支持 PR 前自動檢查。新增 Rust 性能方言。知識圖譜新增可折疊資訊面板、execution-start 排序與 churn 熱點檢測；引入 C4 模型衍生行為圖（domain/flow/step），後因架構調整被還原。新增 KG 不變量檢查器。

### 重點
- HTTP 契約提取新增路由掛載前綴與服務解析，支援跨倉庫聯動檢查
- MCP get_health API 擴充以支持 PR 前自檢，降低集成成本
- 新增 Rust 性能方言，支援語言特定性能模式檢測（如 for...of 迭代常量集合）
