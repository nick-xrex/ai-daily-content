## Anthropic Introduces MCP Tunnels for Private Agent Access to Internal Systems

Anthropic 擴展 Claude Managed Agents 平台，推出自託管沙箱與 MCP tunnels 兩項企業功能，解決企業 AI 部署中的核心難題：組織需要自主 agent 但不能讓執行環境或內部系統離開安全邊界。MCP tunnels 允許 agent 透過加密通道存取內部系統，同時保持自託管沙箱提供執行隔離。此舉針對企業特定的安全合規需求。

### 重點
- MCP tunnels：agent 可透過加密通道安全存取內部系統，執行環境保留在企業內部
- 自託管沙箱：提供獨立執行環境控制，滿足高合規企業的隔離要求
- 針對企業 AI 部署的核心挑戰：自主性（agent）vs. 安全邊界（離不開內網）的矛盾
