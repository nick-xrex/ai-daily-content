## ArrowJS Reaches 1.0, Recast as the First UI Framework for the Agentic Era

ArrowJS 由 Justin Schroeder 開發，經 3 年迭代於 2026 年 6 月達成 1.0 里程碑，定位為「代理程式時代的首個 UI 框架」。該框架採用核心 Web 技術，避免 JSX 與編譯步驟，核心功能聚焦於 reactive、html、component 三個函式，並提供可選 WASM 沙盒執行不信任程式碼。

### 重點
- ArrowJS 1.0 GA：無 JSX、無編譯、純核心 Web API 架構
- 可選 WASM 沙盒安全執行代理程式生成的程式碼
- 最小化依賴設計，核心功能由三函式構成
