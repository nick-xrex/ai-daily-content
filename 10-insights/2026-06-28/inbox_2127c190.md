## v0.43.0

RTK v0.43.0 發布，包含 2 項新功能與 21 項 bug 修復，旨在提升開發者工具鏈的可靠性。新功能包括 OpenShift CLI 支持（與共享 Kubernetes 過濾）及 Pulumi CLI 過濾器（用於 preview、up、destroy、refresh、stack 操作）。關鍵修復涵蓋：Git 命令退出代碼傳播（修復提交失敗與狀態緊湊路徑模式下的代碼遺漏）；Docker、dotnet、grep 等工具的輸出守衛與錯誤處理；測試框架整合（pytest under uv run）；視覺測試報告保留。共計 15+ 服務與工具的改進。

### 重點
- Git 命令退出代碼傳播修復（commit 失敗、status 緊湊路徑）確保 CI/CD 腳本正確偵測失敗
- OpenShift/Pulumi CLI 支持擴展容器編排與基礎設施即程式碼工具相容性
- 輸出守衛與錯誤捕捉機制改進防止工具輸出異常或不完整
