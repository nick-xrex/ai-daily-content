Claude Code 和 Kiro 都基於相同的 Claude 模型驅動，共享同一個「大腦」。儘管底層模型完全相同，但兩者在介面設計和功能設計上卻有明顯的差異。這說明了相同的基礎模型可以適配不同的開發工具和使用場景。該發現展示了 Claude 模型的高度靈活性和可擴展性。對於想要整合或客製化 Claude 模型的開發者有參考價值，說明如何根據不同的工具需求來調適同一個核心模型。反映了 AI 基礎模型在不同應用層的適配機制。

- Claude Code 和 Kiro 使用相同的 Claude 基礎模型
