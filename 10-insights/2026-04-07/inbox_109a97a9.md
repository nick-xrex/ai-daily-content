## How to build a Team OS in Claude Code with Hannah Stulberg, PM @ DoorDash

DoorDash 產品經理 Hannah Stulberg 分享在 Claude Code 中構建 Team OS 的實踐。該系統將所有文件、指標和客戶電話紀錄集中在共享 repository，允許整個團隊自主查詢，而非依賴 PM 逐一傳遞。這展示了 Claude Code 從單人開發工具向團隊協作系統的新應用，提高團隊信息透明度和決策效率。

### 重點
- DoorDash 用 Claude Code 建立統一的 Team OS，集文件、指標、客戶電話於一體
- 團隊成員可自主查詢信息，而非依賴 PM 逐一傳遞
- 這是 Claude Code 從單人開發工具向團隊協作系統的實踐應用
