## Designers don't need to ship code

針對「設計師是否需要寫程式才能上線」的問題，講者的核心觀點是：是否交付程式碼不重要，重要的是深入理解設計的「材料」(material)。設計師若只懂 UI 細節調整但不理解 agent loops 機制，不如找到真正理解 agent loops 的人。主張設計師應該透過編碼來強制自己深度審視所設計系統的本質，而非只為了上線。這反映 AI 時代設計的新需求：理解底層機制 > 樣式調整。

### 重點
- 編碼的目的不是交付程式碼，而是強制設計師審視「設計的材料」(interrogate the material)
- AI 時代設計師必須理解 agent loops 等底層概念，比傳統 UI 細節調整更重要
- 深度理解系統運作機制（透過親自構建）= 設計的新基礎
