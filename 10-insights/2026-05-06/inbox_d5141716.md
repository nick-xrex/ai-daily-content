## Higher usage limits for Claude and a compute deal with SpaceX

Anthropic 宣佈與 SpaceX 簽訂重大計算能力協議，將在一個月內獲得 300 MW 的新容量（超過 22 萬塊 NVIDIA GPU），直接惠及 Claude Pro 和 Max 訂閱用戶。同時 Anthropic 調升了 Claude Code 各階方案的速率限制（五小時內翻倍），並移除了 Pro 與 Max 用戶的尖峰時段限制。此外 Anthropic 還與 Amazon（5 GW）、Google（5 GW）、Microsoft/NVIDIA（$300 億 Azure 容量）等簽訂合作，展示出產業級的計算基礎設施競賽。

### 重點
- SpaceX Colossus 1 數據中心：300 MW 新容量、超過 22 萬塊 NVIDIA GPU，於一個月內上線供 Claude Pro/Max 使用
- Claude Code 速率限制翻倍：Pro、Max、Team、Enterprise 方案的五小時內額度加倍，移除尖峰時段限制
- 多元計算夥伴：Amazon 5 GW、Google 5 GW、Microsoft/NVIDIA $300 億、Fluidstack $500 億，反映 AI 基礎設施競爭升級
