## Agents can now create Cloudflare accounts, buy domains, and deploy

Cloudflare 与 Stripe 推出新协议，允许 AI agents 自动化云基础设施部署流程。Agents 现可直接创建 Cloudflare 账户、启动付费订阅、注册域名、获取 API 令牌，无需人工干预（除权限批准）。通过 Stripe Projects CLI 和 Code Mode MCP server，agents 可从零开始部署生产应用，整个过程无需访问仪表板或手动输入信用卡。这打破了 agents 在云基础设施自动化中的传统限制，使代码生成与部署可一气呵成。

### 重點
- Agents 可自动执行账户创建、域名购买、支付链接等生产部署前置任务，不再需要人工逐步操作
- 采用 Discovery-Authorization-Payment 三层协议设计，基于 OAuth/OIDC 和支付令牌化扩展而来
- 与 Stripe Atlas 新创公司计划捆绑推出，Cloudflare 提供 $100,000 信用额
