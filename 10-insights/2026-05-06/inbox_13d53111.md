## AI Gave the Solo Creator a Studio. The Studio Is Rented.

文章論述 AI 工具雖讓個人創作者能生產過去需要團隊的專業級內容（電影、互動作品），但這些能力完全依賴於付費 inference API，而 API 的條款由公司單方面控制，可以在任何時刻改變。核心問題：創作者獲得了工具，卻失去了所有權和穩定性。這不是「平台 vs 協議」的辯論，而是根本的結構性困境——「工作室」是租賃的，租約由房東決定。

### 重點
- 單人用筆電可生成電影、互動世界（組合 LLM + 圖像生成 + 視頻工具），這在十年前需要完整團隊
- 所有工具層都位於 inference API 之上，API 的使用政策和費率「可在週二被修改」，月費制造持續依賴
- 創作者面臨根本權衡：得到民主化工具，卻失去所有權、自主權、定價權
