## How I’m Using Claude to Prep for Handoff

設計師分享了一套 8 步驟工作流程，將 Claude 整合到產品設計交付流程中。工作流包括：(1) 用原型、設計系統、研究稿輸入 Claude 建立上下文；(2) 讓 Claude 識別缺失功能模塊（如購買流程、批量操作、邊界情況）；(3) 用 Claude 生成低保真 HTML 原型而非直接 Figma；(4) 人工驗證物件關係和產品邏輯；(5) 檢查屏幕設計是否符合源材料；(6) 合併重複互動；(7) 添加導航和亮點；(8) 遷移到設計系統組件提高保真度。核心價值在於 Claude 加速了繁瑣但非不可能的設計工作，使隱形設計流程提前可見，便於工程交付前更快迭代。

### 重點
- 8 步結構化工作流：上下文輸入 → 缺口映射 → HTML 原型 → 邏輯驗證 → 設計系統對齊
- HTML 原型優先於 Figma：生成一次性低保真原型進行邏輯驗證，加快產品邏輯迭代
- 人機協作邊界明確：Claude 處理繁瑣任務，人類判斷結構正確性與優先級
