## SpaceX Conpute Deal - Double Limits

Anthropic 與 SpaceX 達成計算能力合作協議，大幅增加運算資源。自 2026 年 5 月 6 日起，Anthropic 移除 Claude Code Pro/Max 方案在高峰期的限制減速，並顯著提升 Opus 模型的 API 速率限制。此舉直接解除了長期困擾用戶的容量瓶頸，使更多用戶能獲得更高使用配額。

### 重點
- 移除 Claude Code Pro/Max 高峰期限制減速；API Opus 模型速率限制大幅提升
- SpaceX 提供計算基礎設施支撐 Anthropic 容量擴張
- 即刻生效，影響全球 Pro/Max/API 用戶

# SpaceX Conpute Deal - Double Limits

 per @claudeai on X: We’ve agreed to a partnership with @SpaceX that will substantially increase our compute capacity. This, along with our other recent compute deals, means that we’ve been able to increase our usage limits for Claude Code and the Claude API. Effective today, we are: Removing the peak hours limit reduction on Claude Code for Pro and Max plans; and Substantially raising our API rate limits for Opus models.
