## Show HN: Red Squares – GitHub outages as contributions

Red Squares 是一個創意工具，將 GitHub 的停機時間（outage）轉換為用戶 contribution graph 上的視覺標記，將負面事件變為「貢獻」數據點。本質上是一個有趣的數據可視化和黑色幽默項目，對理解開發者工具的社區創意有參考價值，但主要是娛樂性質。

### 重點
- Red Squares 將 GitHub 停機時間映射為 contribution graph 上的紅色方塊
- 通過黑色幽默重新標籤負面事件，提升開發者社區的娛樂性
- 展示開發者工具生態中創意應用的潛力
