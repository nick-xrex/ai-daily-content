## Setting Up Claude Code: Your AI Coding Assistant in Terminal

Shubhankar 為 Windows 用戶提供 Claude Code 終端工具的完整設置指南。首先需 Node.js 與 npm 已安裝，用 `npm install -g @anthropic-ai/claude-code` 安裝，從 console.anthropic.com 取得 API key，在 C:\Users\user_name\.claude\settings.json 配置環境變數，然後在專案資料夾執行 `claude` 命令啟動。關鍵優勢是無需手動分享上下文，比瀏覽器 chat 界面更直接存取 codebase。

### 重點
- npm 全域安裝指令：`npm install -g @anthropic-ai/claude-code`，用 `claude --version` 驗證
- API key 需視為密碼，不可分享或提交 GitHub；在 ~/.claude/settings.json 配置含 API key 和 token 上限
- 終端方式提供直接 codebase 訪問，無需手動上下文分享，優於瀏覽器 chat 界面
