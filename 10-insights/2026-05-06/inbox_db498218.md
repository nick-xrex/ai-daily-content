## MCP UI: Extending the frontier — Liad Yosef and Ido Salomon, MCP Apps

MCP Apps 的 Liad Yosef 和 Ido Salomon 展示如何通過 MCP 標準將工具轉變為交互式 UI，集成至 ChatGPT、Claude、VS Code、Cursor 和 Copilot 等主機。演講涵蓋 MCP Apps 的核心架構、UI 在 MCP 上的傳遞機制、交互如何通過主機保持上下文完整性，以及這如何重新定義 agent-first 世界中應用的分發模式。標誌 MCP 從文本型工具擴展至品牌化、功能完整的應用體驗的轉折點。

### 重點
- MCP UI 架構將交互式介面帶入 ChatGPT、Claude、VS Code、Cursor、Copilot 等主機
- 核心機制：UI 作為 MCP 消息傳遞、交互上下文通過主機保留（不中斷）
- 應用分發模式轉變：從純文本回應 → 品牌化、功能應用體驗
