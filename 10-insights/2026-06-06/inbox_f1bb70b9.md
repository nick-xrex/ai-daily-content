## Developers Shock: How the New Usage Based Billing GitHub Copilot Broke the Bank

GitHub Copilot 於 2024 年從固定訂閱制轉為按使用量計費（按完成次數計費）。「代幣燃燒綜合症」現象浮現：開發團隊生成完成量超出預期，導致帳單陡升，在社群引發「成本可預測性、價值感知、AI 輔助開發經濟學」的激烈辯論。此事件被視為 AI 工具定價轉折點，衍生大量段子與戰爭故事。文章指出使用量計費模式暴露了開發工作流中的隱性成本預期，但具體定價、成本案例等細節在摘取內容中遭截斷。

### 重點
- GitHub Copilot 改為按完成次數計費，打破開發者對成本預算的線性預期；「代幣燃燒」成為新風險向量
- 開發社群反應兩極：從接納 API 模式到對成本失控的焦慮；引發關於 AI 工具定價公平性的根本性討論
- 事件突顯 AI 輔助編碼的隱性經濟學——工具愈好用、用量爆發、帳單代價愈大；需要新的成本可視性文化
