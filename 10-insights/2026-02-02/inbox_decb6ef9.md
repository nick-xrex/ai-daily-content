## Introducing the Codex app

OpenAI 推出 macOS 專用的 Codex 應用，將 AI 編程助手轉化為功能完整的開發命令中心。該應用支援多個並行 agent、複雜工作流和長時間運行任務，為開發者提供了統一的代碼生成與審查介面。Codex app 代表了 OpenAI 將生成式 AI 編程工具從 API 層面提升到完整桌面應用的進化。

### 重點
- Codex app 是 macOS 專用的 AI 編程命令中心
- 支援多個 agents 並行執行、複雜工作流和長期任務
- 提供統一的代碼生成、編輯和審查體驗
