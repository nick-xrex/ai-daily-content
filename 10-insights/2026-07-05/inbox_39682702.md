## v0.27.0

Repowise v0.27.0 發布，新增對 Dart、SQL DDL 符號和 dbt lineage 的支持，改進涵蓋 SQL health markers、app-to-database contracts，以及 VS Code 擴充的代理交接、原生聊天工具和 per-file 變更風險分析。其他改進包括 Coverage tab 的分頁和排序、add-repo wizard 的成本預檢和即時首次索引體驗、CLI 的登入/登出/whoami 命令和儲存足跡顯示。

### 重點
- 新增 Dart AST 支持和 SQL health markers，涵蓋交易語義分析
- VS Code 擴充改進：代理交接代碼操作、原生聊天工具、per-file 變更風險分析
- UI 一致性基礎建立：統一表格、統計圖磚、骨架屏和全詞彙表
