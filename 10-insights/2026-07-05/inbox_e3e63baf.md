## vscode-v0.3.0: release: v0.27.0 (#698)

repowise 核心版本從 0.26.x 升至 0.27.0，VS Code 擴充從 0.2.x 升至 0.3.0，進行全面版本號同步。此次版本號碰升涵蓋 pyproject 設定、CLI/core/server 初始化模組、uv.lock 依賴鎖定檔案，以及兩份 Claude Code plugin 清單。相應的 docs/CHANGELOG.md 已重新同步並生成 0.27.0 段落說明。packages/vscode 擴充與 package-lock 同時更新確保一致性。然而發佈文本未包含任何具體的功能變更、API 調整或已修復的 issue，無法確定此版本更新的實質內容。

### 重點
- repowise 核心 0.27.0、VS Code 擴充 0.3.0 版本號同步升級
- 版本更新跨越 pyproject、CLI/core/server、uv.lock、Claude Code plugin manifests
- docs/CHANGELOG.md 與 package-lock 同步更新
