## How I use AI, EP.1: Building My Own Wealth Tracker

泰國投資者 Kan 利用 Claude API 開發個人財務追蹤應用，解決資產分散問題（基金、股票、加密貨幣、黃金、保險無統一視圖）。應用支援 Thai-specific 資產（96.5% 純度黃金、本地稅優基金如 ESG/RMF）、即時金價/加密/外匯行情、統一淨值計算、稅務減扣規劃、Claude API 驅動的財務健康分析。技術棧：Cloudflare Pages（前端）、Cloudflare Workers（API）、Google Sheets（資料庫），零運營成本。Kan 強調「AI 不是替我做，而是與我共同做」：確定需求、架構決策、邊界案例由 Kan 負責，Claude 加速代碼生成、除錯、原型開發，一日內從概念到可用系統。

### 重點
- 支援 Thai 特定資產類別（96.5% 純金、ESG/RMF 基金）與即時定價
- Cloudflare Pages/Workers + Google Sheets 堆棧零運營成本
- Claude 加速開發流程：一日內從概念到可用應用
