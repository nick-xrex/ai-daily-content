## What Is a Token? ChatGPT’s Smallest Building Block Explained Simply

本文以最直白的方式解釋 Token 的概念──它是 ChatGPT、Claude、Gemini 等現代 LLM 的最小構成單位。文章強調理解 Token 是掌握 LLM 語言處理機制的最快途徑，因為 Token 決定了模型如何分割輸入、計算成本，以及設置輸出限制。對於使用 AI 模型的開發者而言，Token 認知直接影響成本預估和性能設計。

### 重點
- Token 是 LLM 的基本組成單位，影響推理成本和輸出限制
- 理解 Token 是掌握 ChatGPT、Claude、Gemini 等模型運作的最快途徑
- Token 計數直接決定了 API 調用的成本
