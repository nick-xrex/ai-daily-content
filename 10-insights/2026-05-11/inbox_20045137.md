## PySpark for Beginners: Mastering the Basics

面向初學者的 PySpark 完整教程，逐步介紹分散式資料處理的核心概念與實踐方法。重點涵蓋 Spark 的 lazy evaluation（延遲計算）機制，講解 DataFrame 作為分散式資料運算基本單位的角色，以及如何構建第一個 PySpark 應用。教程幫助開發者從單機 Python pandas 思維轉變到分散式計算框架，理解 RDD 和 DataFrame 的區別，掌握轉換（transformation）和行動（action）的執行模式。

### 重點
- Lazy evaluation 機制：PySpark 轉換延遲執行，只在 action 觸發時真正計算，提升效率和資源管控
- DataFrame 與 RDD：DataFrame 是結構化分散式資料的標準抽象，支援 SQL 查詢和優化器加速
- 循序漸進的初學路徑：從基本概念到完整應用的有序步驟，降低 PySpark 的入門門檻
