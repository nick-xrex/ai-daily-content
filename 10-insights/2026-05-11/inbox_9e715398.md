## New in Claude Code: agent view.

Claude Code 推出「Agent View」研究預覽版功能，提供統一儀表板管理多個 Agent 會話。用戶可一次派遣多個 Agent 執行任務，每個 Agent 持續運行而不佔用終端標籤。功能支援一目瞭然地查看任務狀態（運行中、等待回應、已完成），允許內聯回覆解除阻塞，以及隨時進出任何會話而不丟失進度。此功能現已向所有付費方案用戶開放。

### 重點
- Claude Code 新增 Agent View 研究預覽版功能
- 支援一次派遣多個 Agent 並行執行，每個獨立運行不佔終端
- 提供統一儀表板查看所有任務狀態與進度
