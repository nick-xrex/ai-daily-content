## Java News Roundup: GraalVM, Spring AI, JobRunr, GlassFish, Grails, Groovy, Quarkus Agent MCP

Java 周報（2026 年 5 月 4 日）匯總本週發布動態，涵蓋 OpenJDK JEP 面向 JDK 27、Spring AI 2.0 第 6 個 milestone、Grails 8.0 及 Groovy 6.0 進入新版本週期、JobRunr 點版本更新，以及 GraalVM、GlassFish、TomEE、Tomcat 等主流框架的維護版發布。其中最值得關注的是 Quarkus 新增了 Agent MCP server 支持，標誌著 Model Context Protocol（MCP）在 JVM 生態中的應用範圍進一步擴展，不再侷限於 Python 和 Node.js 社區。

### 重點
- Spring AI 2.0 milestone 6 發布，推進 Java 生態內 AI 能力整合和生產級支持
- Groovy 6.0 alpha、Grails 8.0 milestone 進入新代版開發週期，帶動 JVM 動態語言更新
- Quarkus Agent MCP server：MCP 支持從 Python/Node.js 生態擴展至 JVM 原生框架，開啟跨語言 AI agent 協作新局面
