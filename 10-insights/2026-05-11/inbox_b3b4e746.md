## Java News Roundup: GraalVM, Spring AI, JobRunr, GlassFish, Grails, Groovy, Quarkus Agent MCP

Java 生態系在 5 月迎來多項重要版本更新。Spring AI 2.0 推進至第六個里程碑版本，Grails 8.0 和 Groovy 6.0 分別發布首個里程碑和 alpha 版本；GraalVM 加速發布周期。同時 GlassFish、TomEE 和 Tomcat 推出維護更新，OpenJDK JEPs 被列入 JDK 27 目標。特別地，Quarkus 推出新的 Agent MCP server，為開發者提供模型無關的智能體開發能力。本次匯總反映 Java 生態系的蓬勃發展動力。

### 重點
- Spring AI 2.0 M6、Grails 8.0 M1、Groovy 6.0 alpha 同步發布，GraalVM 加速迭代
- Quarkus Agent MCP server 新增，支持模型無關的 AI 智能體集成
- 多個基礎設施層組件（GlassFish、TomEE、Tomcat）同步維護更新
