## Netflix Introduces ‘Model Lifecycle Graph’ to Scale Enterprise Machine Learning

Netflix 開發了 Model Lifecycle Graph，一套圖形化架構用於在企業級規模管理機器學習系統。該系統映射 datasets、models、features 和 workflows 之間的互連關係，提升 ML 操作的可發現性、治理與組件重用能力。通過自助服務方式，降低工程師和數據科學家的操作複雜度，支持大規模 ML 生態中的跨團隊協作與衍生組件的快速發現。解決了傳統 ML 管理中的資料依賴追蹤、模型血統記錄和特徵發現困難等長期痛點。

### 重點
- 圖形化映射 ML 依賴關係：datasets → models → features → workflows，可視化整個生命週期和互連
- 自助服務架構：降低工程師和數據科學家的進入門檻，加速模型迭代和發現可複用組件
- 提升治理與管控：中央化組件發現性和版本管理，減少技術債和重複開發
