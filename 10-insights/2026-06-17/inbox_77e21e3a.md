## Learn Claude Code: /sandbox

文章介紹 Claude Code 的 /sandbox 功能，該功能允許用戶在隔離環境中執行不信任的程式碼，不會暴露檔案系統或網絡存取。這是一個重要的安全特性，解決了在 AI 協助程式碼編寫時的信任問題——用戶可以執行並檢驗生成的程式碼行為，而不用擔心惡意或意外的系統操作。功能對於測試、驗證和探索 AI 生成程式碼的正確性特別有用。

### 重點
- Claude Code /sandbox 提供隔離的程式碼執行環境
- 防止不信任或未驗證的程式碼存取系統資源和網絡
- 支援安全的程式碼驗證和測試工作流
