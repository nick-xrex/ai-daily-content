## Introducing GPT-5.4 mini and nano

OpenAI 推出 GPT-5.4 系列的兩款新型號：mini 和 nano。這兩款型號相比標準 GPT-5.4 更小、更快，能在資源受限的環境中運行。新型號針對多項能力進行了優化，包括代碼生成、工具使用和多模態推理。特別地，mini 和 nano 被設計用於處理高容量的 API 調用和子代理 (sub-agent) 工作負載。此舉擴展了 GPT-5.4 在不同應用場景中的可用性和可部署性。

### 重點
- GPT-5.4 mini 和 nano 新版本發布，體積更小、速度更快
- 優化編碼、工具使用、多模態推理能力
- 適合高容量 API 和子代理工作負載的生產部署
