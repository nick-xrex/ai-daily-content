## From Camera to Cloud: Netflix’s Scalable Media Processing Pipeline

Netflix 公開雲端媒體處理管道，使用 FilmLight API 與分散式計算，處理攝像機檔案的攝取、驗證、中繼資料提取與轉換。該系統標準化全球電影和電視製作的編輯、VFX 及色彩分級工作流程，減少手動處理並提升跨製作的一致性。展示企業級媒體工程如何在大規模下整合異構工具鏈。

### 重點
- 使用 FilmLight API 與分散式計算在雲端進行大規模媒體轉換
- 標準化編輯、VFX、色彩管道，提升跨製作一致性
- 減少手動檔案處理，提升製作效率
