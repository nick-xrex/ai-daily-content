## Ky 2.0 Fetch API Wrapper with Revamped Hooks, Smarter Timeouts, and Built-In Schema Validation

Ky 2.0 基於 Fetch API 的 HTTP 客戶端發布，整合 hook 處理、智能超時管理、URL 標準化及 schema 驗證。相比 axios，Ky 體積更輕，與現代瀏覽器和 Node.js 運行時相容性更好。此版本強調從舊版遷移路徑，定位為 axios 的輕量級替代品。

### 重點
- 整合 hook 系統、智能超時、內建 schema 驗證簡化請求流程
- 體積輕、基於標準 Fetch API，相比 axios 具有現代化優勢
- 提供清晰遷移指南，降低從 axios 切換的成本
