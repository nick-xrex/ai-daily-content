## Claude Skills for IaC: Stop Hardcoded Secrets Before They Hit Git

Claude Code Skills 功能可用於基礎設施即程式碼（IaC）工具鏈，在 Git pre-commit 階段自動檢測硬編碼的祕密（如 API keys、密碼、token）。該方案將安全檢測左移至開發流程最早期，防止敏感資訊進入版本控制系統。透過客製化 Skills 擴充，開發團隊可建立全自動的祕密掃描防線，顯著降低生產環境祕密外洩的風險。

### 重點
- Claude Code 可通過 custom skills 實現 IaC 工具鏈的 pre-commit 祕密檢測
- 自動攔截硬編碼的 API keys、密碼、token 等敏感資訊
- 將安全檢測左移，在 commit 最早期防止祕密進入版本庫
