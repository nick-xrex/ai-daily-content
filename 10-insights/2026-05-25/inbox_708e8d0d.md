## Ship a Claude Code Plugin as a .zip URL: A 7-Step May 2026 Build

Claude Code v2.1.128+ 新增 `plugin-url` flag，支援通過 .zip URL 直接部署插件到 Claude Code，無需手動配置檔案。開發者在 marketplace.json 定義元資料後，一行命令即可安裝插件，簡化第三方工具整合流程。此功能降低生態應用開發門檻，加速 Claude 周邊工具擴張。

### 重點
- Claude Code v2.1.128+ 推出 `plugin-url` flag，支援 .zip 格式 URL 插件部署
- marketplace.json 元資料 + 一行命令 (`--plugin-url <url>`) 完成安裝，無需額外設定
- 降低第三方開發者整合難度，加速生態應用市場化
