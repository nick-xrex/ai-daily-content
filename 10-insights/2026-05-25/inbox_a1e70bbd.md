## Podcast: Chasing Efficient Java Development: From 1BRC to Developing Hardwood AI Natively

Gunnar Morling（Confluent 技術人與 Java Champion）分享高性能 Java 開發經驗。涵蓋 durable execution engine 設計、bootstrapping 優化與 AI 原生開發。他主導開發 Apache Hardwood，一個最小依賴的 Parquet 解析器，展示在資料密集場景中 Java 本機開發的可行性。該 Podcast 融合實驗成果與社群實踐經驗。

### 重點
- Durable execution engine 與 bootstrapping 在高性能應用中的角色
- Apache Hardwood：最小依賴 Java Parquet 解析器
- AI 原生 Java 開發在資料空間的應用案例
