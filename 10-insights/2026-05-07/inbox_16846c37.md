## DeepSeek 4 Flash local inference engine for Metal

DeepSeek V4 Flash 專用本地推理引擎 ds4.c 發布，採用 Metal 圖執行專門針對 macOS/Apple Silicon 優化。支援 1 百萬 token 上下文、2-bit 量化（可在 128GB RAM MacBook 運行）、高度可壓縮 KV cache 支援記憶體與磁碟持久化。核心優勢是 DeepSeek V4 Flash 的「較少活躍參數」設計使其速度更快，思考模式產生較短的思考段落。提供 OpenAI 與 Anthropic 兼容 API，整合 OpenCode、Pi、Claude Code 等 coding agent。代碼組成：C 56%、Objective-C 29.8%、Metal 13.6%，MIT 授權。

### 重點
- 1M token 上下文 + 2-bit 量化支援：MacBook(128GB+) 可直接運行 DeepSeek V4 Flash
- 專門引擎而非通用 GGUF 包裝：Metal 圖執行、KV cache 持久化、思考模式控制，針對性優化
- Coding agent 整合：OpenAI/Anthropic 兼容端點，可與 Claude Code 直接配合
