## Code with Claude: The 5 biggest updates explained

Anthropic 在 Code with Claude 发布 5 项重大功能：(1) Claude Code Routines 支持基于时间表或 webhook 触发的自动化工作流；(2) Outcomes Feature 提供基于评分标准的 AI 代理性能评估系统；(3) Multi-Agent Orchestration 支持具有不同角色与工具的专门 AI 团队协作；(4) Dreams Memory System 实现跨长期交互的代理行为学习与记忆；(5) 扩展 Claude Code 使用限额。这些更新旨在让 AI 产品建造者能够今日交付生产级别的代理能力，而非实验性原型。

### 重點
- Claude Code Routines：时间表或 webhook 触发的自动化工作流
- Outcomes Feature：基于评分标准的代理性能评估框架
- Multi-Agent Orchestration：多个专门化 AI 代理协作执行复杂任务
