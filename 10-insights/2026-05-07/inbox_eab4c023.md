## Google Announces GKE Agent Sandbox and Hypercluster at Next '26, Positioning Kubernetes as AI Agent

Google 在 Cloud Next '26 發表 GKE Agent Sandbox，這是基於 gVisor 核心隔離技術的安全代理執行環境，能達到 300 個沙箱/秒的性能。同時發佈的 Hypercluster 技術可從單一控制平面管理 100 萬晶片，支援大規模 AI Agent 部署。Agent Sandbox 目前是三大雲端商（AWS、Azure、Google）中唯一提供原生 Agent 隔離方案的服務。這兩項宣佈標誌著 Kubernetes 正式演進成為 AI Agent 基礎設施平台。Google 透過這些技術建立起在代理計算領域的競爭優勢。

### 重點
- GKE Agent Sandbox 基於 gVisor 核心隔離達 300 沙箱/秒性能，作為開源 Kubernetes SIG Apps 子項目
- Hypercluster 從單一控制平面管理 100 萬晶片規模，支援生產級 AI Agent 部署
- Google 在三大雲端商中率先提供原生 Agent 隔離解決方案，形成差異化優勢
