## Playground in Prod: Optimising Agents in Production Environments — Samuel Colvin, Pydantic

Samuel Colvin (Pydantic 創始人) 演示如何在生產環境中優化 Agent。核心內容包括使用 Jeepper (遺傳演算法優化庫) 和 Logfire managed variables 進行 prompt 優化。在英國議員政治關係識別任務上，初始 prompt 准確度 87%，經專家 prompt 改進至 92%，經 Jeepper 自動優化達 96.7%。演示展示了評估 (eval)、對比 (compare)、最佳化 (optimize) 的完整迴圈，以及如何在不重新部署的情況下使用 managed variables 進行生產實驗。

### 重點
- Jeepper 遺傳演算法優化：從 87% → 92% → 96.7% 准確度，通過自動提議和評估 prompt
- Logfire managed variables 實現零部署的生產 A/B 實驗，支持 Pydantic model 類型的多欄位管理
- 評估 (eval) 基於黃金資料集，可設定自訂評估器；需要足夠資料覆蓋邊界情況以避免過度擬合
