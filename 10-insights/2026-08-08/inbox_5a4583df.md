## The Strange Mind of an LLM

文章探討大型語言模型的認知特性，指出 LLM 的「思維方式」與人類有根本差異。LLM 具備「一次性讀取全部內容」與「即時學習（in-context learning）」的特點，但在 session 間無長期記憶保留。標題諷刺暗示「artificial」可能是誤稱，因為 LLM 認知模式在某些層面有其獨特邏輯。該觀點揭示了 LLM 與人類認知的差異，對理解 AI 系統的行為與限制具有指導意義。對於開發者與用戶，了解 LLM 的「一次性 + 即時適應 + 無記憶」模式，有助於設計更合理的 prompt 策略與會話管理。

### 重點
- LLM 一次性讀取整個 input context 進行全局對應，而非逐序列化處理
- 具有即時學習與適應能力（in-context），但在 session 間無記憶保留
- 認知模式的獨特性反映 transformer 並行計算特性，挑戰「artificial」標籤的準確性
