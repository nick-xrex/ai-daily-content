## MCP + Claude Plugin: A Surprisingly Simple Alternative to Building a Custom Martech Agent

介紹用 MCP + Claude Plugin 快速構建行銷自動化智能體的方法論。傳統企業軟體做法是為自動化流程而開發新工具；該文提出新思路：通過組合現有 MCP 與 Claude Plugin 能力，以更低複雜度達成相同自動化目標。具體示例：用 MCP + Claude Plugin 替代客製化 martech agent 開發，簡化工具堆棧、加速上市時程。

### 重點
- MCP + Claude Plugin = 快速構建行銷智能體的簡化路徑，相比傳統自製工具複雜度大幅降低
- 工具組合原則：連結現有系統 = 工具組合，不需新工具開發（對 martech 工作流尤其適用）
- 設計模式轉變：從「自製特定工具」到「組合通用元件」可提升開發速度與降低維護成本
