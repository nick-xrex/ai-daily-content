## Java News Roundup: Spring Tools, Helidon, Open Liberty, TomEE, JobRunr, Hibernate, Commonhaus

InfoQ Java 生態新聞匯總（2026 年 6 月 15 日）報導 Java 企業框架與工具的最新進展。涵蓋 Spring Tools、Helidon、JobRunr 及 Gradle 的點版本更新，Open Liberty 月度版本發布，Apache TomEE 11.0 首個里程碑版本，Hibernate ORM 8.0 首個 beta 版本，以及 Quarkus 緊急維護版本修補 CVE-2026-50559 漏洞。同時四個開源項目新加入 Commonhaus 基金會，反映 Java 生態治理與開發工具的持續演進。

### 重點
- Hibernate ORM 8.0 beta 與 Apache TomEE 11.0 M1 標誌主流企業框架的大版本推進週期
- CVE-2026-50559 Quarkus 漏洞修補反映 Java 生態的持續安全維護需求
- 四個項目加入 Commonhaus 基金會顯示開源治理結構調整與基金會模式的拓展
