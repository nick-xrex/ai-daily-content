## Designing AI agents to resist prompt injection

OpenAI 發表 ChatGPT 在 agent workflows 中防止 prompt injection 和 social engineering 的防禦機制。通過約束風險操作、保護敏感數據等措施，強化模型在執行代理任務時的安全性。這套方案針對日益複雜的 agent 攻擊場景，確保即使在動態指令環境中也能維持控制力。

### 重點
- 約束風險操作以防止惡意指令執行
- 敏感數據保護機制在 agent workflows 中的應用
- 針對 agent 環境中的 social engineering 防禦
