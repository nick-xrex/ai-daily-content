## From model to agent: Equipping the Responses API with a computer environment

OpenAI 採用 Responses API、shell tool 和 hosted containers 構建 agent runtime，實現安全且可擴展的代理執行環境。此架構支援文件操作、工具整合和狀態管理，為生產環境中的 agent 應用奠定基礎。這套實現方式解決了 agent 執行中的隔離性、安全性和資源管理的核心挑戰。
