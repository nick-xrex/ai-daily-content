## Introducing the Stateful Runtime Environment for Agents in Amazon Bedrock

OpenAI 與 Amazon 在 Amazon Bedrock 上推出 Stateful Runtime for Agents，為多步驟 AI 工作流帶來持久的編排、記憶與安全執行能力。該運行時環境允許 Agent 維持對話狀態與執行上下文，提升企業級 AI Agent 的可靠性。Stateful Runtime 特別針對長程工作流優化，支援 Agent 跨越多個步驟時保留狀態資訊。此功能對於金融交易、供應鏈最佳化、複雜客服等需要多輪互動的產業具有重要實務意義。

### 重點
- Stateful Runtime 提供持久編排、記憶、安全執行三大核心能力
- Amazon Bedrock 整合 OpenAI 動力，支援企業級 Agent 部署
- 針對長程 AI 工作流設計最佳化，維持跨步驟的狀態保留
