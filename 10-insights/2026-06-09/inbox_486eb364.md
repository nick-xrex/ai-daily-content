## Anthropic requires 30 day data retention for Fable and Mythos

Anthropic 對 Fable 與 Mythos 等旗艦模型強制實施 30 天數據保留政策。該政策影響零數據保留協議的用戶（包括 Claude Console、Claude Code Enterprise、AWS Bedrock、Google Cloud 與 Microsoft Foundry）。Anthropic 聲稱保留用於檢測「Best-of-N jailbreaking」與協調威脅等濫用模式；數據訪問需要批准且僅限小規模審核小組，所有訪問記錄於防篡改日誌中，30 天後自動刪除（法律或安全調查除外）。

### 重點
- Fable 與 Mythos 強制 30 天數據保留，影響企業與 API 用戶
- 數據訪問需批准、記錄於防篡改日誌、30 天自動刪除
- 保留目的為偵測 Best-of-N jailbreaking 與協調威脅等大規模濫用模式
