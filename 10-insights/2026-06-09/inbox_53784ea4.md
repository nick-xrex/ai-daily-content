## Microsoft Foundry Adds Runtime, Tooling, and Governance for Production Agents

Microsoft 在 Build 2026 大會宣布為 Foundry 平台增強生產級代理能力。新功能涵蓋 runtime、工具、記憶體、grounding、模型、可觀測性與治理等層面，旨在將代理從實驗階段過渡到生產系統。此次發布強調 Foundry 不僅是新模型端點，而是完整的生產代理開發與部署基礎設施。

### 重點
- Foundry 新增完整生產棧：runtime + 工具 + 記憶體 + grounding + 可觀測性 + 治理
- 核心價值主張：代理從實驗到生產的完整生命週期支援，超越模型端點層級
- Microsoft Build 2026 重點發布，標誌著代理開發生態成熟度提升
