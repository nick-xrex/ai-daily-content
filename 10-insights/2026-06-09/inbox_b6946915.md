## Release Candidate v1.6.7-rc.12

GitNexus v1.6.7-rc.12 候選版本發布。主要變更包括 Taint/PDG 子圖基礎設施 M0 實現（schema + seams + spikes），可選語法惰性載入以防止分析器崩潰，C++ 繼承鏈成員查詢解析，FTS 擴展集成與記憶體優化，Kotlin 工具鏈優化，gitnexus uninstall 卸載命令，tree-sitter 無工具鏈預編譯支援（npm 打包 + arm64 運行時），以及 MCP list_repos 分頁優化以避免客戶端 token 截斷。本版本為預發布測試版。

### 重點
- Taint/PDG 子圖基礎設施 M0 完成——為靜態分析奠定基礎架構
- 可選語法惰性載入防止分析器崩潰；FTS 擴展已集成至 CLI 映像
- tree-sitter 預編譯依賴 npm 打包；支援 arm64 運行時；MCP 端點分頁支援
