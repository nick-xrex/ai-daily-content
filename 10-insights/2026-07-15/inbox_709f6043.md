## I Built an AI Agent That Knows Which Changes Matter

Medium 文章分享開發 AI agent 的實踐案例。作者通過一個具體應用——自動監視服務條款細節變更——展示了 AI agent 與網頁爬蟲（scraper）的本質區別。案例隱含的洞察是：agent 應具有「選擇性監視」的能力，而非無差別爬取。這是 agent 應用從「全量自動化」向「智能判別式自動化」進化的體現。然而文章形式為視頻，摘要中缺乏詳細的技術實現細節。

### 重點
- AI agent 與 scraper 的區別在於任務選擇性：agent 知道「哪些變更重要」，scraper 無差別採集
- Terms of Service 監視是 agent 的典型應用場景，涉及合規性、風險識別等高價值決策
- 視頻形式的完整技術細節未在文字摘要中透露
