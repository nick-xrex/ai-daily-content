## AI Ajanınıza Beyin Fırtınası Yapacak Birini Verin

作者建議 AI 編碼 agent 應包含一個驗證角色：當 agent 遇到困難或不確定時，應停下來問另一個模型「我遺漏了什麼？」。這種協作方式讓編碼 agent 能通過外部模型的視角發現自身盲點，提升代碼品質與決策品質。該框架將編碼工作流轉變為多角色協作，而非單一 agent 獨自決策。

### 重點
- AI coding agent 應包含「驗證者角色」（另一個模型或 AI）
- 核心模式：暫停問「我遺漏了什麼？」而非持續向前推進
- 多模型協作顯著優於單一 agent 自洽性，特別是複雜編碼決策
