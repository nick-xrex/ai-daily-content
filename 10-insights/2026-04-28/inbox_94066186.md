## Who owns the code Claude Code wrote?

Claude Code 在 2026 年 3 月 31 日被 Anthropic 意外洩露 512,000 行源代碼，隨後的衍生品「claw-code」倉庫於 24 小時內達到 100,000 星（歷史最快紀錄）。該事件激發了對 AI 生成代碼所有權的法律危機：若代碼主要由 Claude 自身生成，Anthropic 能否聲稱所有權並發起 DMCA 訴訟？美國版權法的核心原則——只有人類創作的作品受保護（Thaler 案件確認，2026 年最高法院拒絕受理上訴）——直接威脅 AI 工具生成的代碼。開發者所有權取決於三個因素：(1) 人類是否做了足夠的創意決策；(2) 僱傭合同是否已分配；(3) 是否來自未可見的 GPL 污染。**實務含義**：使用 Claude Code 或 Cursor 生成但未做實質修改的代碼可能進入公共領域，競爭者可自由使用。

### 重點
- 法律基線（現已穩定）：AI 生成無人類創意投入的代碼不受版權保護；Thaler 案（DC Circuit，2026 最高法院拒絕上訴）為先例
- 512,000 行 Claude Code 源代碼洩露 → 100,000 GitHub 星 → DMCA 困境（Anthropic 自己可能無法合法起訴衍生品）
- 開發者須文檔化人類創意決策以保護所有權；未修改的 AI 代碼可能淪為無保護的公共資源
