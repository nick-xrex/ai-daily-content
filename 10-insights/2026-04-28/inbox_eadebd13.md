## Ghostty is leaving GitHub

知名開源開發者 Mitchell Hashimoto（Vagrant 創始人，GitHub 用戶 #1299）宣布將 Ghostty 項目遷出 GitHub。他在過去 18 年每天使用 GitHub，但在過去一個月內記錄了幾乎每日的服務中斷，嚴重影響工作效率。當天（2026/4/28）因 GitHub Actions 中斷而無法進行 PR review 達 2 小時。Ghostty 將完整遷移至其他平台（商業或開源，仍在討論），並在 GitHub 保留唯讀鏡像。此舉反映 GitHub 作為全球代碼協作樞紐的基礎設施穩定性危機。

### 重點
- 18 年長期用戶決策：GitHub 基礎設施日均中斷，過去一個月幾乎每日記錄異常
- 具體影響：Ghostty 項目完全遷出，個人項目暫留 GitHub，計畫漸進式去依賴
- Hashimoto 的號召力：作為 Vagrant/HashiCorp 創始人，此舉可能鼓勵其他大型項目效仿
