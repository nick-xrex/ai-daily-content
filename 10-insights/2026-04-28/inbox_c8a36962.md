## Auto-Save Every Snippet You Copy in Chrome - Then Pipe It to Claude or ChatGPT

介紹 ClipGate Chrome 擴充套件，自動捕捉使用者複製的代碼片段、API 文件等內容，防止被後續複製覆蓋丟失，並可整批發送給 Claude/ChatGPT。解決跨 30 個標籤頁研究時常見的「複製即失」問題（已驗證使用案例：Stripe webhook 簽名驗證、Tailwind CSS 類名搜尋、GitHub README 配置塊等）。

### 重點
- ClipGate 自動緩存複製片段，防止剪貼板反覆覆蓋導致丟失
- 支援直接與 Claude/ChatGPT API 整合，整理後批量傳輸
- 典型應用場景：跨多文檔研究（Stripe docs + Stack Overflow + GitHub，8 個標籤頁內文件段落）
