## GitHub Copilot code review will start consuming GitHub Actions minutes

GitHub 宣布自 2026 年 6 月 1 日起，GitHub Copilot code review 將消費 GitHub Actions 分鐘數。政策涵蓋 Copilot Pro、Pro+、Business、Enterprise 四版本，私有儲存庫每次審查皆消費 Actions 額度；公開儲存庫不受影響。同步，所有 Copilot 使用改按 AI Credits 計費。此政策變化要求用戶重新評估 Actions 額度使用與成本預算。

### 重點
- GitHub Copilot code review 自 6 月 1 日起消費 Actions 分鐘數（私有儲存庫）；公開儲存庫免費
- 政策涵蓋 Pro、Pro+、Business、Enterprise 四版本，所有 Copilot 使用改按 AI Credits 計費
- 影響大量付費用戶成本預算，需重新規劃 CI/CD pipeline 的額度分配
