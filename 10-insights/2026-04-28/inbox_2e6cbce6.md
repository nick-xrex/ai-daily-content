## Before GitHub

Armin Ronacher（Pocoo 項目創始人、Flask 作者）回顧開源的演變史。早期開源（1990–2000 年代）依賴自托管基礎設施（Trac、Subversion、SourceForge），高摩擦但低依賴；GitHub（2008 年後）集中化全球開源，大幅降低發布與消費代碼的門檻，導致微依賴爆炸；然而 GitHub 也成為社區身份與專業關係的中心。Ronacher 感嘆 GitHub 衰退，並思考後 GitHub 時代的替代方案，強調基礎設施集中化的長期代價：失去對自有工具的掌控，且將社區命運交由單一商業實體。

### 重點
- 開源三階段：自托管 → 中心化 GitHub → 可能的多元化；每階段的權衡是「摩擦 vs 依賴」
- GitHub 的雙面性：降低協作摩擦同時加深中心化風險，打破了分布式版本控制的理想
- 社區基礎設施的非技術價值：GitHub 不只是代碼宿主，更是開源身份與職業發展的平台
