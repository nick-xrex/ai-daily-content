## Anthropic Lead: HTML Increasingly Better Than Markdown at Keeping Humans Engaged in Agentic Loops

Anthropic Claude Code 團隊工程負責人 Thariq Shihipar 發表分析指出，HTML 相比預設 Markdown 輸出，透過更豐富的視覺化、色彩和互動性，顯著提升人類-agent 通訊效率，特別是在 agentic loops 場景中。這表明輸出格式不只是表現層選擇，而直接影響 agent 可靠性和使用者體驗。

### 重點
- HTML 格式相比 Markdown：更豐富視覺化、色彩、互動性提升 agentic loop 效率
- Claude Code 團隊實驗驗證格式選擇對人類-agent 互動生產力的直接影響
- 輸出格式是 agent 可靠性的基礎設施級決策，非僅 UX 關注
