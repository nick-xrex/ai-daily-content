## Learn Claude Code: /rewind

Claude Code 推出 /rewind 功能，允許使用者在開發過程中出錯時回滾程式碼和對話記錄至較早的檢查點。此功能無需手動重新輸入即可快速恢復工作狀態，有助於提升開發效率和降低除錯成本。

### 重點
- Claude Code 新增 /rewind 指令，可回滾至任意檢查點
- 回滾包括程式碼變更與對話歷史的同步復原
- 適用於除錯和工作中斷的快速恢復
