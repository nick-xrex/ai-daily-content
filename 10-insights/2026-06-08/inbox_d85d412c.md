## Java News Roundup: JDK 27 in Rampdown, JDK 28 Expert Group, GlassFish, Infinispan, Kotlin

本週 Java 新聞摘要涵蓋 JDK 27 進入 Rampdown Phase One 穩定化階段、JDK 28 Expert Group 正式成立、GlassFish Arquillian 連接器套件發佈、Infinispan 與 Kotlin 點更新、GlassFish 與 Micronaut 維護版本，以及 Open Liberty 六月 beta 版發佈。此為定期技術進展概況，涵蓋主流 Java 生態工具鏈的更新。

### 重點
- JDK 27 進入 Rampdown Phase One，接近穩定發佈
- JDK 28 Expert Group 成立，下一代 Java 版本規劃啟動
- Jakarta EE TCK 認證工具持續完善，確保企業 Java 互操作性
