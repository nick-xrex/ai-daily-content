## Java News Roundup: JDK 27 in Rampdown, JDK 28 Expert Group, GlassFish, Infinispan, Kotlin

本週 Java 產業新聞週刊涵蓋多個重要發展。JDK 27 目前處於 Rampdown Phase One，意味著功能開發即將凍結，即將進入穩定期。同時 JDK 28 的專家組正式成立，開始規劃下一代 Java 的新特性。開源生態方面，GlassFish 發佈了 Jakarta EE TCK 相容性驗證套件。Infinispan 和 Kotlin 兩個重要專案都推出了點版本更新。此外 GlassFish 和 Micronaut 也各自發佈了維護版本。

### 重點
- JDK 27 進入 Rampdown Phase One，即將達到功能凍結
- JDK 28 專家組正式成立，開始規劃下一代特性
- 多個生態工具發布版本更新（Infinispan、Kotlin、GlassFish、Micronaut）
