## Your Terminal Just Got a Superpower — Are You Using It?

強調 Claude Code 的斜杠命令（slash commands）不僅是快速鍵，而是整合的工作流系統改革工具。正確運用可優化代碼交付安全性並自動化多個開發步驟。文章從終端生產力角度論述斜杠命令的戰略價值，惟具體命令類型與實踐案例在摘要中未詳述。

### 重點
- Claude Code 斜杠命令不是單純快捷鍵，而是整合的工作流系統
- 可用於提升代碼交付安全性標準和自動化終端開發操作
