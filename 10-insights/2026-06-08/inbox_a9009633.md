## Release Candidate v1.6.7-rc.1

GitNexus 發布 v1.6.7-rc.1，為基於 main branch 的 release candidate 構建。此版本主要同步 Claude plugin manifests 與 1.6.6 穩定版保持一致，為 1.6.7 最終版本前的驗收測試。RC 版本供早期測試使用，穩定版本保持在最新 dist-tag。可透過 npm install gitnexus@rc 進行安裝。

### 重點
- v1.6.7-rc.1（rc #1）對應 main commit 689e6ef，release commit 72466dc
- 同步 Claude plugin manifests 確保跨工具平台相容性
- 無破壞性變更，供早期驗收測試使用
