## Cloudflare Launches Code Mode MCP Server to Optimize Token Usage for AI Agents

Cloudflare 推出基於 Code Mode 的 MCP 伺服器，專門優化 AI Agent 與大規模 API 的互動。該伺服器支援 2,500+ 端點，能大幅減少 context 佔用、改善多 API 編排，並為 LLM Agent 提供安全的程式碼執行環境。這個方案解決了 AI Agent 在調用複雜 API 時的 token 成本問題，讓 Agent 能更有效地與外部系統整合。

### 重點
- 支援 2,500+ 個 API 端點，顯著降低 context 佔用量
- 提供安全的程式碼執行環境，改善多 API 編排能力
- 基於 Model Context Protocol (MCP)，使 AI Agent 與 API 互動更高效
