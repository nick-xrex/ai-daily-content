## Accelerating the cyber defense ecosystem that protects us all

OpenAI 宣布啟動「可信網路安全計畫」(Trusted Access for Cyber)，與全球領先的安全公司及企業合作。計畫向參與者提供 GPT-5.4-Cyber 模型及 1000 萬美元的 API 使用額。GPT-5.4-Cyber 是專門為網路防禦優化的模型，能夠增強全球網路防禦生態系統。此舉意味著 AI 能力與網路安全領域的深度整合。對安全企業及防禦人員而言，這提供了尖端 AI 工具來對抗日益複雜的網路威脅。

### 重點
- 推出 GPT-5.4-Cyber，專用於網路安全防禦
- 提供 1000 萬美元 API 額度支持全球防禦人員
- 與領先安全公司合作，強化整體防禦生態
