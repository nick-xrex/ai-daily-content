## Anthropic Introduces Routines for Claude Code Automation

Anthropic 推出 Routines 功能於 Claude Code，允許開發者配置自動化編碼工作流，支援排程觸發、API 呼叫或外部事件驅動。此功能擴展 Claude Code 自動化能力，使長時間運行開發工作流可異步無人值守執行。
