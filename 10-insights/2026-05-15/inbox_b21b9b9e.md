## Anthropic Introduces Routines for Claude Code Automation

Anthropic 推出 Claude Code Routines 功能，允許開發者設定自動化編碼工作流，支援排程、API 呼叫、外部事件三種觸發方式。此功能將 Claude Code 從互動式工具擴展為自主代理，可持續執行定期維護、CI/CD 整合、事件驅動編碼任務，無需手動介入。

### 重點
- Routines 支援排程、API、事件觸發三種自動化模式，覆蓋 CI/CD、定期維護、外部事件處理
- Claude Code 從互動編輯器轉向代理式工作流執行，支援長期後台運作
- 開發者可配置無人值守自動化，減少手動編碼和檢視循環
