## Claude Opus 4.8 Just Dropped. But DeepSeek Already Made the Price Look Awkward.

Claude Opus 4.8 發布後面臨根本性定價挑戰。DeepSeek V4-Pro（2026-04-24 發布）：1.6T 參數、49B active tokens/step、1M context、MIT 授權、可自託管，性能只略遜 Opus 幾分點但價格低 30 倍。此對比破壞了專有 frontier 模型的價格論證：同一效能層級下，開源自託管選項幾乎無成本，迫使 API 提供者需為可靠性、安全性、更新速度等溢價辯護，而非純能力。

### 重點
- DeepSeek V4-Pro specs：1.6T 參數、MIT 授權、自託管、1M context、性能差距 < 5 分點（對比 Opus 4.8）
- 30 倍價差正當性危機：開源模型成本可控，frontier API 無法單靠能力微弱優勢收費
- 競爭轉向非能力維度：可靠性、安全認證、API 穩定性、更新頻率等軟因素成為定價基礎
