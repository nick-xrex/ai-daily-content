## OpenVINOTM 2026.2: More models, GPU Optimizations, and Enhanced Agentic Support

英特尔 OpenVINO 2026.2 发布，为本地 AI 推理优化。新增支持 Gemma 4 E2B/E4B、Qwen3.5/3.6、Trinity-mini、LFM2 系列、YOLO26 等 15+ 模型。GPU 优化方面：INT4 KV cache 压缩可减少大提示词（超 32K token）的内存占用；增强模型加载速度，特别对多模型管道与智能体工作流；XAttention INT8 KV cache 按通道量化提升准确度。OpenVINO Model Server 新增对 Qwen 3.5/3.6 的工具调用支持（tool calling），用于智能体应用；支持语音实时转录加速。面向边缘计算与实时 AI。

### 重點
- 模型扩展：Gemma 4（31B/26B）、Qwen3.5（智能体工作流）、Qwen3.6（编码/推理）、Qwen3-Coder-Next（3B 激活参数）、YOLO26 对象检测
- GPU 内存优化：INT4 KV cache 压缩（32K+ token 场景）、按通道 INT8 量化、模型加载时间大幅下降
- 智能体支持：Model Server 新增 Qwen 3.5/3.6 工具调用，实时转录流式处理（语音对话 AI）
