## v2.1.158

Claude Code v2.1.158 發布，Auto mode 功能現已在 AWS Bedrock、Google Vertex AI 和 Anthropic Foundry 三個雲端平臺上支援。該功能適用於 Claude Opus 4.7 和 4.8 兩個模型版本，開發者設定環境變數 CLAUDE_CODE_ENABLE_AUTO_MODE=1 即可啟用。此擴展使 Claude Code 的自動代碼編輯能力覆蓋更多企業級部署選項，便利客戶在偏好的雲平臺上使用自動化開發功能。跨雲部署成為企業平臺標準。

### 重點
- Auto mode 支援 Bedrock、Vertex AI、Foundry 三大雲端平臺
- 相容 Claude Opus 4.7 和 4.8 模型版本
- 啟用方式：設定 CLAUDE_CODE_ENABLE_AUTO_MODE=1 環境變數
