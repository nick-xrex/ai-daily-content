## Windows Platform Security and the Race to Secure AI Agents

Microsoft 在新文章中宣佈將 Windows 定位為可信任的自主 AI 代理作業系統，並推出 Microsoft Execution Containers (MXC) SDK 作為核心安全策略。該方案強調 containment（隔離）、identity（身份）、manageability（可管理性）三層安全能力必須內建於作業系統層級，以支撐企業部署自主代理。

### 重點
- Microsoft Execution Containers (MXC) SDK：作業系統層級的代理沙箱容器標準
- 三層安全模型架構：containment、identity、manageability 缺一不可
- Windows 戰略定位：信任作業系統作為企業 AI 代理部署基石
