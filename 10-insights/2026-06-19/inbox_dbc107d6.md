## .NET 11 Preview 5: Brings File-Based App Improvements, New C# Features, and a Blazor Validation Wave

.NET 11 Preview 5 發布了跨 SDK、C#、ASP.NET Core、MAUI、EF Core 的多項更新：C# 新增 closed classes 與 unions 型別特性強化型別安全，文件型應用迎來改進，Blazor 進行驗證系統大升級，MAUI 推出大規模可靠性修復，EF Core 將預設相容性級別切換至 SQL Server 2022。

### 重點
- C# 新語言特性：closed classes（密閉類）、unions（聯集型）強化靜態型別安全與表達力
- .NET MAUI 可靠性波：大規模修復提升跨平台穩定性
- EF Core 升級：SQL Server 2022 設為預設相容性級別
