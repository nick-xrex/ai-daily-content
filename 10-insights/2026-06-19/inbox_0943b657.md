## Presentation: AI Agents to Make Sense of Data at OpenAI

OpenAI 的 Bonnie Xu 介紹 Kepler，一個內部 AI 數據分析代理，能查詢 600+ petabytes 的數據。該系統使用 MCP 克服 context window 限制、自動代碼爬行與 RAG 增強檢索，並透過 scoped semantic memory 實現自學習能力。評估管道採用 AST-based LLM grading 以確保迴歸無誤。這展示了大規模數據代理的完整技術棧：MCP 解決 context 邊界、語義記憶駕馭持久學習、LLM 評分保證質量。

### 重點
- 可查詢 600+ petabytes 數據、使用 MCP 解決 context window 限制
- 自動代碼爬行 + RAG 技術，構建自適應知識檢索系統
- Scoped semantic memory 實現自學習、AST-based LLM grading 提升評估精度

OpenAI’s Bonnie Xu discusses Kepler, an internal AI data analyst agent built to query 600+ petabytes of data.
