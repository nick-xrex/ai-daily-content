## Build Your Own Local AI Coding Assistant with Ollama + Qwen + VS Code in your mac(No GPU Required)

教學指南展示如何用 Ollama + Qwen 模型 + Continue 擴充套件，在 Mac 本地建構無 GPU 需求的 AI 編程助手。透過 Ollama 管理 LLM 部署並暴露 API，支援 Qwen 3.6 (27B)、Qwen 2.5-Coder (14B、7B) 三種變體。VS Code 整合後，Continue 外掛可與 Ollama 提供者連結，提供程式碼生成、解釋、測試與重構能力。相比雲端助手，本地部署避免速率限制、保護代碼隱私、支援離線使用，並得益於開源基礎。

### 重點
- Ollama + Qwen 組合提供 CPU 專用推理選項，避免 GPU 硬體投資，支援最小 7B 模型 (Qwen 2.5-Coder)
- Continue VS Code 擴充與 Ollama 原生整合，無需複雜設定即可在工作區內獲得上下文感知 AI 回應
- 本地部署消除雲端 API 速率限制、網路依賴和代碼隱私風險
