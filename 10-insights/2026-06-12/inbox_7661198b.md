## Release Candidate v1.6.8-rc.22

GitNexus v1.6.8-rc.22 發佈，包含 20+ 項修復和新功能。重點包括：新增 multi-branch indexing 和 branch-scoped querying 能力、新增 Java Spring route annotation 提取功能、新增 TS/JS control-flow-graph 分析層、新增 intra-procedural taint analysis、VECTOR index 建立修復（改用 conn.query 而非預備路徑）、Docker 運行時資源修復確保 hooks/skills 資源被打包、impact()/route_map blast radius 報告改進、circular import cycle 檢查新增、embeddings 依賴解析修復支援 pnpm-strict。

### 重點
- Multi-branch indexing 和 branch-scoped querying：新增跨分支索引和分支範圍查詢能力
- TS/JS control-flow-graph 分析層：提供 TypeScript/JavaScript 的控制流程圖分析
- Intra-procedural taint analysis：新增函數內污點分析以支援更精細的安全分析
