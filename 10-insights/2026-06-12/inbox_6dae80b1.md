## Angular's Official Agent Skills Helps AI Coding Tools Write Modern Angular

Google Angular 團隊釋出 angular/skills 儲存庫，包含專為 AI coding agents 最佳化的 Agent Skills。該 skills 增強了 AI 工具編寫現代 Angular 程式碼的能力，涵蓋程式碼生成和應用程式腳手架。儲存庫作為 Angular 最佳實踐快照，幫助 AI agents 瞭解最新慣例，進而改進程式碼建議品質。
