## Using a Local LLM as a Zero-Shot Classifier

該文提出一套實踐管道，運用本地部署的 LLM 將混雜的自由文本數據進行零樣本分類，無需標記訓練數據。由於原始摘要資訊不足，無法提供具體的方法論步驟。整體定位為實踐指南，面向需要快速分類髒數據的場景。

### 重點
- 零樣本分類無需標記訓練集，降低數據準備成本
- 本地 LLM 部署避免外部 API 呼叫與隱私疑慮
- 適用於自由文本的分類任務
