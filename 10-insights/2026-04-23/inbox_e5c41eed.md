## Claude Got Worse. Now Anthropic Has Confirmed It

Anthropic 官方認可 Claude 確實經歷了性能下降，用戶感受（代碼能力下滑、記憶力衰退、更易受挫）均被驗證。問題源自產品層變更（Claude Code、Claude Agent SDK、Claude Cowork），而非核心模型本身。此事凸顯傾聽用戶反饋的重要性——廣泛的開發者抱怨最終證明了真實的技術問題存在，不應被自動駁回為臆測。

### 重點
- 三個獨立變更影響了 Claude Code、Claude Agent SDK、Claude Cowork
- 問題位於產品層而非基礎模型或 API
- 用戶駅群信號驅動了正式問題確認與檢視
