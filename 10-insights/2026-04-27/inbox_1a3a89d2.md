## Podcast: A Java Performance Quest: Taming Unsafe Code, Embracing Idiomatic Style & Debugging the Linux Kernel

InfoQ 播客邀請高層次資料系統專家 Jaromir Hamala 分享高效能軟體開發心法。Hamala 強調現代 Java 如何在保持「機械共鳴」（mechanical sympathy）原則下撰寫習慣用法程式碼，並分享他除錯 Linux 核心漏洞的實戰經驗，說明跨層級系統知識對效能最佳化的必要性。內容涵蓋應用層、系統層至核心層的效能觀點整合。注：本項目為工程效能話題，非 AI 相關。

### 重點
- 現代 Java 支援習慣用法程式碼與『機械共鳴』並存，不必犧牲效能
- 講者具備高吞吐量資料系統與 Linux 核心除錯實戰經驗
- 跨層級系統知識：應用→系統→核心層深厚理解對效能最優化關鍵
