## Building Human-Like Memory for AI Agents (Part 1): Mastering Short-Term Memory

文章第 1 部分系統探討 AI 代理的短期記憶機制與架構。介紹四大支柱：對話緩衝用於存儲對話歷史、滑窗用於固定大小重疊記憶、摘要用於語意壓縮、token 感知記憶用於動態調整。Token 感知記憶特別重要，它根據剩餘 token 預算自動調整保留粒度。這使代理在有限 context window 下保留跨越多輪對話的歷史資訊。短期記憶架構是代理連貫推理、任務連續性與自適應決策的基礎。

### 重點
- AI 代理短期記憶四層架構：對話緩衝（對話歷史）、滑窗（固定重疊記憶）、摘要壓縮（語意提取）、token 感知記憶（預算動態調整）
- Token 感知記憶根據剩餘 token 預算自動調整保留粒度，在有限 context window 內最大化歷史資訊密度
- 短期記憶是多輪代理互動基礎：支援跨任務狀態延續、上下文一致性、自適應決策調整
