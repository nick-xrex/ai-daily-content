## I Built an AI Data Agent Which Can Query Data and Answer Business Questions. Here’s How.

介绍如何构建 AI 数据 agent 和对话界面，使业务用户能用自然语言查询数据库、回答业务问题，无需 SQL 知识。该方案结合自然语言处理和数据查询能力，降低数据探索的门槛，是将生成式 AI 应用于企业数据分析的实践案例。

### 重點
- 数据 agent 通过自然语言界面隐藏 SQL 复杂度，扩大数据查询的用户群体
- 业务用户无需 SQL 知识即可独立进行数据探索和问题回答
- 结合对话界面可实现多轮交互式数据分析
