## Anthropic Introduces Agent-Based Code Review for Claude Code

Anthropic 為 Claude Code 引入了新的代理型代碼審查功能，利用多個 AI 審閱者對 pull request 進行自動化分析。該功能整合在 Claude Code IDE 內部，能夠識別代碼質量問題、風格違反和最佳實踐建議。代理架構的引入簡化了開發工作流，減少了人工審查的時間成本，使開發者能更快地迭代代碼。這是 Claude Code 向完整開發助手發展的重要步驟。

### 重點
- Claude Code 新增代理型代碼審查，多個 AI 審閱者並行分析
- 自動識別代碼質量問題、風格違反和最佳實踐建議
- 整合到 IDE 內部，簡化開發工作流程
