## AWS Launches Agent Registry in Preview to Govern AI Agent Sprawl across Enterprises

AWS 正式發布 Agent Registry 預覽版作為 Amazon Bedrock AgentCore 的一部分，提供企業級的 AI agent 集中化治理平台。該 registry 支持跨組織發現、治理和重用 AI agents、tools 和 MCP servers，無論它們在何處運行。系統原生支持 MCP 和 A2A 協議，與 Microsoft、Google Cloud 和 ACP Registry 等競爭方案形成對標。這標誌著企業 AI agent 生態從孤立走向統一管理的轉變。

### 重點
- AWS Agent Registry 提供集中式 AI agent / tool / MCP server 目錄，支持跨組織治理和發現
- 原生支持 MCP 和 A2A 協議，兼容多種 agent 運行環境
- 與 Microsoft、Google Cloud、ACP Registry 等形成競爭格局，反映企業 AI 治理的市場需求
