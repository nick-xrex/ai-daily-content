## Beyond Prompting: Using Agent Skills in Data Science

作者分享如何將八年來每週的資料視覺化習慣發展成可複用的 AI agent skill，展示了超越單純提示詞的工作方式。Agent skills 提供了一種更系統的方法，將重複性工作流程結構化、參數化並與 AI 無縫整合，特別適用於資料科學中的視覺化、分析等周期性任務。

### 重點
- 個人工作習慣可轉化為可複用的 agent skill，八年實踐驗證
- Agent skills 超越提示工程，實現工作流的真正自動化和複用
- 適用於資料科學工作的視覺化等周期性任務自動化
