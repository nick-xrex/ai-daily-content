## Human-in-the-Loop Automation with n8n — Liam McGarrigle

AI Engineer 頻道發布 Liam McGarrigle 主講的 79 分鐘 workshop：「Human-in-the-Loop Automation with n8n」。講座通過 Gmail 與 Google Calendar 管理 agent 實例，演示如何在 n8n 視覺化平臺中構建安全、可觀察的人在環工作流。涵蓋關鍵設計模式：chat 觸發器、工具集成、認證憑證管理、批准閘道與存取控制。進階部分包含 Slack 互動、排程執行、子工作流與專用 subagent 在大規模自動化中的應用（觀看 455 次，讚數 35）。

### 重點
- 人在環設計核心：批准閘道與多通道觸發（chat、Slack），確保 agent 決策可控與可審計
- n8n 視覺化工作流支持子工作流與 subagent 分工，降低單一 agent 複雜度，提升系統可維護性
- Gmail/Calendar 管理 agent 展示可觀察的流程設計：工具調用→結果展示→人工確認→執行
