## Context Engineering: How It Changes Enterprise AI Delivery

本文強調在企業 AI 部署中，上下文工程（context engineering）的重要性應超越傳統 prompt 工程。通過精心設計和管理 LLM 的輸入上下文——包括檢索相關文檔、整理外部知識源、構建領域數據庫——能更有效地提升模型輸出品質、降低幻覺風險。工程團隊應優先投資於上下文管理系統的構建，而非過度關注 prompt 措辭微調。

### 重點
- 上下文品質對 LLM 輸出影響大於 prompt 設計（context > prompt 優先級框架）
- 企業 AI 系統應圍繞上下文工程架構，而非單純 prompt 優化
- 上下文工程需投資於檢索、數據管理、知識組織等基礎設施
