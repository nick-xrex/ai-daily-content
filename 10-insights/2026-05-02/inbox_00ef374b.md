## How users actually use Computer-Use Agents

根據用户使用數據，Computer-Use Agents 的最成熟應用場景集中在兩個領域：編碼自動化（代碼生成、重構、測試編寫）和 UI 自動化測試（QA）。這兩類應用相比其他通用場景（如數據分析、客服自動化）表現更穩定、更可驗證，反映了 AI agents 在結構化、確定性任務上的優勢。

### 重點
- 編碼自動化（coding automation）是最成熟、最清晰的 computer-use 應用場景
- UI 質量保證（QA 自動化測試）是第二個驗證過的成熟應用領域
- 結構化、可驗證的任務比通用性應用更適合當前 agents 能力邊界
