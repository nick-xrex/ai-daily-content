## What if humans don’t have a “context window” like AI?

本文反思 context window 作為 LLM 核心制約因素是否真的類似人類認知的侷限。隨著研究進展，AI context window 已從數千 token 擴展到百萬級規模（1 百萬 tokens）。新的擴展甚至達到 200 萬 tokens，足以容納整個代碼庫或完整法律檔案。作者以認知科學角度提出批判性問題：人類學習和推理時是否也受類似的「context window」限制。人類認知機制是否根本不同於 AI 的序列處理方式。這次思考挑戰了將 AI 技術限制直接類比人類認知的常見假設。

### 重點
- AI context window 已擴展至百萬 token（1M+）和 200 萬 token，可容納整個代碼庫和法律檔案
- 人類認知是否有類似的 context window 限制是未解決的認知科學問題
- 挑戰 AI/human 認知直接類比的假設，提示兩者可能有根本性差異
