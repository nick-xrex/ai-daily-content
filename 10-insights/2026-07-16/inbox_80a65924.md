## Release Candidate v1.6.10-rc.34

GitNexus v1.6.10-rc.34 為繼續迭代版本，強化 MCP 協議相容性，新增避免頂層 api_impact schema 組合器的修復（#2489）。此版本保留先前的 CodeBuddy/Qoder 整合、Codex 支援、Wiki HTTP LLM 主機功能，並持續改進穩定性。核心修復涵蓋 FTS 診斷、嵌入向量自癒、Windows 跨平台相容性、C++ 型別查詢索引化、NUL 位元組解析恢復。版本號遞進表示開發快速迭代，以確保各組件系統整合。

### 重點
- MCP 協議增強：修復頂層 api_impact schema 組合器問題，改善 MCP 回應結構化（#2489）
- 累積功能：CodeBuddy/Qoder 代理、Codex 整合、Wiki HTTP LLM 主機配置
- 系統穩定性：Windows FTS/嵌入向量/C++ 型別查詢改進，快速迭代驗證各項修復
