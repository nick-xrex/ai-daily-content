## Release Candidate v1.6.10-rc.32

GitNexus v1.6.10-rc.32 為預發布版本，包含 CodeBuddy 和 Qoder 編碼代理整合、完整 Codex 支援（hooks、plugin marketplace），以及廣泛的穩定性改進。重點修復包括：代理安裝韌性（onnxruntime-node 自癒）、FTS 擴展錯誤診斷、MCP 符號儲存的基數轉換（0-based vs 1-based）、Windows 平台依賴項載入失敗診斷、嵌入向量自癒、樹狀語法分析器 NUL 位元組恢復。此外修復了 C++ SIGABRT 問題（型別查詢索引化）和 Windows 影子錯誤。

### 重點
- 新增 CodeBuddy 和 Qoder 編碼代理整合，提供擴展 IDE 能力
- 完整 Codex 支援含 plugin marketplace、hooks、自動化設定（#2328、#2369）
- Windows 跨平台穩定性全面改進：FTS 診斷、自癒式嵌入向量、C++ 型別查詢索引化、Worker 生命週期管理
