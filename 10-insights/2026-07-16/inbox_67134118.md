## Release Candidate v1.6.10-rc.33

GitNexus v1.6.10-rc.33 繼 rc.32 之後，新增 Wiki 功能允許使用者指定明確的 HTTP LLM 主機，強化用戶對模型端點的控制。核心功能包括 CodeBuddy/Qoder 代理整合、完整 Codex 支援，以及針對 Windows 平台、MCP 協議及嵌入向量處理的廣泛修復。此版本著重提升穩定性與診斷能力，包括 FTS 擴展錯誤診斷、符號儲存基數轉換修正、C++ 型別查詢索引化。

### 重點
- Wiki 功能擴展：允許使用者指定自定 HTTP LLM 主機（#2491），增強端點靈活性
- 穩定性聚焦：Windows FTS 診斷、onnxruntime-node 自癒、嵌入向量管道韌性
- MCP 協議改進：符號儲存基數轉換（0-based vs 1-based）、查詢 hint 發出、C++ SIGABRT 修復
