## AWS Continuum to Enable Agentic Code Security for Enterprises

Amazon Web Services 推出 AWS Continuum，一個整合式安全平台，利用代理技術自動化發現、強制執行和補救程式碼庫、依賴項和應用程式中的安全問題。該平台啟動時具備四項核心代理功能，涵蓋漏洞生命週期的全程：滲透測試、程式碼審查、威脅建模與程式碼漏洞掃描。Continuum 旨在將 DevSecOps 工作流從被動反應轉變為主動自動化，使企業能夠在開發早期捕捉和修復安全缺陷，提升企業級安全防禦的效率與深度。

### 重點
- AWS Continuum 四項代理功能涵蓋完整漏洞生命週期：滲透測試、程式碼審查、威脅建模、程式碼漏洞掃描
- 自動化安全發現與補救，針對程式碼庫、依賴項和應用程式的跨層安全檢測
- 為企業級 DevSecOps 自動化提供端到端的代理驅動安全平台
