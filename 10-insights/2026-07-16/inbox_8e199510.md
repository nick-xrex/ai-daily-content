## Claude Code Can Now Browse the Web While It Codes

Anthropic 為 Claude Code 桌面應用新增了內建網頁瀏覽能力，填補了 AI 編碼工具的一個重大功能缺口。Claude Code 現在在編碼時可以直接存取網路資源，無需手動複製貼上網頁內容。這項功能讓開發者能夠在編碼期間實時查閱文檔、API 參考、Stack Overflow 等網路資源。Claude Code 的網頁瀏覽集成大幅提升了編碼效率與上下文完整性。

### 重點
- Claude Code 桌面應用新增內建網頁瀏覽功能，可在編碼時直接存取網路資源，無需手動 copy-paste
- 該功能填補了 AI 編碼工具的關鍵缺口，讓開發者能實時查閱文檔、API 參考、Stack Overflow
- 網頁瀏覽集成大幅提升編碼效率與上下文完整性，改善開發者工作流
