## I Built an AI Advisor on Power Platform. Here’s the Architecture I Promised

開發者在 Power Platform 上用 HTML Widget + Power Automate + SharePoint + Claude API 構建企業 AI 顧問。系統分四層：前端為無框架依賴的原生 JavaScript 聊天小工具，Power Automate 負責文檔檢索、對話狀態與 API 通訊，SharePoint 為政策與參考資料的單一來源，Claude Sonnet 4.5 提供文檔上的推理能力。設計中將對話歷史存於瀏覽器記憶體（刷新會消失），限制 12 則訊息以最佳化 payload 大小。Power Automate 工作流分七階段：HTTP 觸發、歷史保存、文檔載入、Base64 編碼、JSON 組裝、API 呼叫、回應格式化。提示工程採五層結構：角色定義、來源權威、容錯條件、語氣指引、邊界情況處理；容錯部份在測試中反覆擴展以防止特定幻覺。生產主要挑戰是速率限制，提示快取嘗試需要位元組完全相同的負載。建議改進包括伺服器端 Dataverse 狀態管理、Azure Functions 串流回應與專案初期建立評估框架。

### 重點
- 四層架構：HTML Widget（前端）→ Power Automate（編排）→ SharePoint（文檔源）→ Claude Sonnet 4.5（推理）
- 客戶端歷史管理：瀏覽器記憶體存儲，訊息限 12 則，刷新丟失；七階段 Power Automate 工作流完成 API 通訊與格式化
- 提示工程五層結構與容錯擴展最關鍵；速率限制為主要瓶頸，建議升級層級；改進方向：Dataverse 狀態 + Azure Functions 串流 + 事前評估框架
