## Building a Local AI Research Assistant for Health & Supplement Research Using RAGWire, Ollama...

本文介紹如何使用 RAGWire 和 Ollama 兩個開源工具搭建本地 AI 研究助手，針對健康、健身、運動科學與營養補充劑領域的應用。隨著這些領域研究論文數量的爆炸式增長，使用傳統方法定位、閱讀和摘要相關論文變得越來越困難。該本地助手方案透過 RAG（檢索增強生成）技術實現離線知識檢索與智能總結，避免依賴雲端 API 服務。本地部署的方式同時能保護敏感研究數據的隱私。該實現展示了如何將開源模型和 RAG 框架靈活應用於垂直領域的知識管理場景。

### 重點
- 使用 RAGWire + Ollama 構建本地 RAG 系統，支援完全離線運行
- 針對健康補充劑領域研究論文檢索與摘要痛點設計
- 本地部署避免雲端 API 依賴，保護敏感研究數據隱私
