## dev-0.43.0-rc.253

RTK dev-0.43.0-rc.253 簡化 symlink 解析邏輯，改用 Rust 標準庫 `fs::canonicalize()` 統一處理 chained symlink、相對路徑及邊界情況，替代自定義的 `resolve_atomic_target()` 實現。此改進基於 code review 反饋，減少自定義邏輯的維護複雜度、統一行為、降低 bug 風險。

### 重點
- 用 Rust 標準庫 fs::canonicalize() 替代自定義 resolve_atomic_target()，統一處理 chained symlink、相對路徑、邊界情況
- 減少自定義邏輯、降低維護複雜度、統一行為
