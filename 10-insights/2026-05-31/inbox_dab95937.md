## Testing AI Tools for Unity Prototyping: BEZI vs Codex vs Claude

Victor Corvalán 測試三款 AI 工具在 Unity 遊戲原型設計的表現：Codex (GPT-5.5)、Claude (Opus 4.8)、BEZI (Frontier Opus 4.6)。評估目標為協助美術設計師而非程式設計師快速產製概念原型。Claude 與 Codex 整合 AnkleBreaker Unity MCP 獲得 Unity 編輯器原生能力；BEZI 在免費版預設設定下也產生值得注意的成果。文章形容上述三款工具皆可在 $20 基礎方案上執行。

### 重點
- 三款工具對比：Claude Opus 4.8、Codex GPT-5.5、BEZI Frontier Opus 4.6（全數 $20 基本方案）
- Claude、Codex 用 AnkleBreaker Unity MCP 實現編輯器整合與 Unity 特定功能存取
- 評估重點：非開發者（美術設計師、企劃）的原型製作效率與易用性
