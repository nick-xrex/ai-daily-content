## Announcing OpenAI Grove Cohort 2

OpenAI 推出第二屆 Grove 創業加速計畫，為期 5 週，向任何階段的創業者開放申請。參與者將獲得 5 萬美元的 API 額度，並享受 OpenAI 團隊的手把手指導與最新 AI 工具的早期存取權。該計畫旨在支持從概念發想到產品上線的創業家，降低 AI 應用開發的進入門檻。

### 重點
- Grove Cohort 2：5 週創業者計畫，提供 $50K API 額度
- 適用於任何階段創業者（從前期概念到產品版本）
- OpenAI 團隊直接指導與工具早期存取
