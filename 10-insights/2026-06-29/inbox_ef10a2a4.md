## You’re Not Pair Programming Anymore. You’re Managing

文章主張現代 AI 編碼工具代表人機協作從配對編程到管理的根本轉變。作者指出 GitHub Copilot（2021）是被動協助，僅在使用者主動輸入時才啟動；而當代 Claude Code 等智能體能獨立分析整個程式碼庫、規劃多階段工作、自主執行任務，讓開發者從「編寫程式碼」轉變為「管理 AI 智能體」。此轉變涉及技術門檻的越過，卻在主流開發者文化中未獲充分認可。

### 重點
- GitHub Copilot（2021）被動輔助 vs 2026 Claude Code 主動智能體：根本性轉變
- 現代 AI 編碼工具獨立分析程式碼庫、制定多階段策略、自主執行——不只反應式幫助
- 開發者角色從寫程式碼轉為審查、驗證、指導 AI 生成工作（類似管理 junior 開發者）
