## The Pulse: is GitHub still best for AI-native development?

GitHub 數月來持續遭遇可用性問題，引發對其作為 AI 原生開發平台地位的質疑。同期爆出大規模 LLM 供應鏈攻擊，攻擊者試圖透過污染開源依賴影響使用 LLM 的應用。Windows 品質問題（Microsoft 承諾改善「Microslop」)亦反映工具鏈信任危機。這三起事件共同凸顯 AI 時代開發基礎設施的脆弱性。

### 重點
- GitHub 長期可用性故障威脅其作為 AI 開發主要平台的角色
- 大規模 LLM 供應鏈攻擊瞄準開源依賴，風險波及所有 LLM 應用
- 開發工具鏈信任危機（GitHub、Windows）暴露 AI 基礎設施短板
