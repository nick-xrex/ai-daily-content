## [AINews] All Model Labs are now Agent Labs

AI 業界正歷經範式轉變，從「模型實驗室」轉向「代理實驗室」，核心概念是模型本身不再是單獨的產品。領先企業（包括 OpenAI、DeepSeek、AI21）都在改變策略，轉向開發整合代理框架、工作流、使用者介面、記憶系統及經濟結構的完整系統。DeepSeek 的 V4-Pro 永久折扣使推理成本比前沿模型便宜 12-19 倍，形塑新的成本競爭格局。OpenAI 的 Codex 新增應用快照、目標設定、遠端電腦存取等功能，Claude 的工具也在擴展，代碼代理成為產業領先力量。Model Context Protocol（MCP）發布無狀態架構，簡化分散式代理系統的擴展和負載均衡，安全領域也開始看到 AI 在生產環境偵測漏洞的應用。

### 重點
- AI 產品從單一模型轉向完整 stack：模型 + 代理框架 + 工作流 + UI + 記憶系統 + 經濟結構
- DeepSeek V4-Pro 推理成本比前沿模型便宜 12-19 倍，重塑成本競爭格局
- Model Context Protocol（MCP）無狀態架構簡化分散式代理系統的擴展與負載均衡
