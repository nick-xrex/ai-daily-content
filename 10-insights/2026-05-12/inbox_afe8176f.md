## GitHub Expands Secret Scanning with General Availability of MCP Server Integration

GitHub 宣佈 MCP Server 祕密掃描功能正式版推出，將自動化憑證檢測和修復能力擴展至 AI 輔助和代理驅動的開發工作流程。此整合讓開發者在使用 AI 工具時仍能自動偵測和修復祕密洩露。MCP Server 整合象徵 GitHub 在 AI 驅動開發時代對安全性的重視。該功能適用於新興的代理驅動開發場景。由 Craig Risi 報導。

### 重點
- GitHub 正式推出 MCP Server 整合的 Secret Scanning GA 版本，支持 AI 輔助和代理驅動工作流
- 自動化憑證檢測和修復功能深入 agent-driven development 模式
- 在 AI 工具普及的開發流程中，保持祕密管理和安全合規的自動化
