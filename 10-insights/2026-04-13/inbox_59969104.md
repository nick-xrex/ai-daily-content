## v2.1.105

Claude Code v2.1.105 引入多項工作流和可靠性增強。新增 EnterWorktree 工具的 path 參數以切換至現有 worktree；PreCompact 鉤子現可透過返回 {"decision":"block"} 或結束代碼 2 阻止壓縮；插件可透過清單 monitors 鍵支援背景監視，於會話開始或技能調用時自動啟動。改進 API 流處理：5 分鐘無數據後中止並重試；改進網路錯誤訊息直達；改進檔案寫入顯示（長單行內容截斷）；改進 /doctor 佈局和技能敘述長度上限。修復 25+ 項問題包括：隊列訊息中的圖像遺失、螢幕閃爍、多行終端逸出碼、alt+enter 換行失效、stdio MCP 伺服器輸出驗證、插件市集自動更新、會話復原時格式錯誤、無色彩終端相容性等。

### 重點
- EnterWorktree 新增 path 參數支援切換現有 worktree；PreCompact 鉤子可透過結束碼 2 或 {"decision":"block"} 阻止壓縮
- 插件透過 monitors 清單鍵支援背景監視，於會話開啟或技能調用時自動啟動
- API 流 5 分鐘超時機制、網路錯誤訊息改進、25+ 項 UI/流程修復（終端相容、插件更新、會話復原）
