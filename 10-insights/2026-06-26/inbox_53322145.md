## Build a Multi-Agent AI Personal Learning Assistant Using LangGraph

本文介紹如何使用 LangGraph 框架構建多代理 AI 個人學習助手系統。該系統由 8 個專門化代理組成，透過 LangGraph 的雙狀態機管理代理間的複雜工作流。系統整合 Tavily MCP 搜尋管線以即時檢索資訊，並融入歷史悠久的 SM-2 間隔重複演算法優化學習效果。作者為 Nagesh Singh Chauhan，展示了多代理系統在教育應用中的具體實踐。

### 重點
- 多代理架構設計：8 個專門化代理分別處理不同學習任務，透過 LangGraph 狀態機協調
- Tavily MCP 搜尋管線提供即時資訊檢索；SM-2 記憶演算法實現科學間隔重複
- LangGraph 雙狀態機管理複雜代理交互，展示狀態機在多代理系統中的實踐價值
