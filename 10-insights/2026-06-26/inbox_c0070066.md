## From Local LLM to Tool-Using Agent

Medium 文章介紹如何使用本地 LLM 和開源工具堆疊構建工具使用 agent。具體技術組合為 Gemma 4 本地語言模型、Ollama 推理框架、OpenAI Agents SDK 作為 agent 協調層、Tavily MCP 提供搜索工具能力。此混合架構展示了本地部署 + 雲端 API + MCP 工具的整合方式，適合構建輕量級研究助手，降低推理成本同時保持功能完整性和靈活性。

### 重點
- 本地部署 Gemma 4 + Ollama 降低推理成本和延遲，相比完全依賴雲端 API 具有成本優勢
- OpenAI Agents SDK 提供 agent 協調和決策邏輯框架，Tavily MCP 集成搜索工具能力，實現完整的工具使用 agent
- 混合本地和雲端資源的架構模式，適合資源受限場景構建高效能研究 agent
