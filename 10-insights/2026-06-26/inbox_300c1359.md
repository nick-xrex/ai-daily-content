## dev-0.43.0-rc.291

RTK dev-0.43.0-rc.291 修復了 git worktree list 命令失敗時的結束碼傳播問題。此前，當 git worktree list 執行失敗時，系統可能未能正確地將結束碼傳播給上層調用者，導致錯誤檢測失效。此修復（#2499 涉及 git 子系統）確保 git worktree list 失敗時的結束碼被完整地傳播到調用堆棧，讓錯誤處理和故障診斷成為可能。這對於使用 git worktree 進行多分支並行開發的工作流特別重要，使自動化腳本能正確識別和應對 worktree 操作失敗。

### 重點
- 修復 git worktree list 失敗時的結束碼不傳播問題
- 確保 git 錯誤能被上層應用正確捕捉和處理
- 改進 git worktree 工作流的自動化和可靠性
