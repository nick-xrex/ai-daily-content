## I Tried Claude’s AI Courses — These 5 Are Worth Your Time

評論者實踐驗證 Claude 官方免費課程，並篩選出 5 門最具實用價值的課程。「Claude 101」（1-2 小時）涵蓋基礎功能（project、artifact、skills、research mode），提供角色特定摘要（寫手、分析師、行銷、營運）與可分享證書。「Claude Code in Action」（1 小時）15 講教授 SDK 與智能體編碼，被譽為「全校最有價值課程」。「Building with the Claude API」（8+ 小時）最完整，覆蓋生產級集成、系統提示、自訂工具與智能體架構，「可替代數週文件閱讀」。「Introduction to Model Context Protocol」（2-3 小時）用 Python 教 MCP 基礎，「最快從認知到實作」。「MCP Advanced Topics」（3-4 小時）進階模式，需完成入門課且成為雲認證架構師之必修。

### 重點
- Claude 101 → Claude Code in Action → Building with Claude API 形成遞進路徑，從基礎操作→開發工作流→生產系統架構，3 階段覆蓋完整開發生命週期
- MCP 雙層課程（入門 2-3h + 進階 3-4h）統一管理外部服務與資料庫連接，進階課為雲認證架構師必修，強調 MCP 為現代 LLM 應用基礎
- 所有課程免費提供，涵蓋 SDK、API、MCP、智能體編碼等核心技能，提供可驗證證書與角色特定教學模組
