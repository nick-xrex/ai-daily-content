## Release Candidate v1.6.8-rc.31

GitNexus v1.6.8-rc.31 發佈，為 1.6.8 版本的第 31 個預發佈候選。包含過程內污點分析、控制流圖層、MCP HTTP 伺服器、向量索引與 Docker 部署修復。相較 rc.32，缺少過程間污點分析功能。提供早期測試用 RC 版本。

### 重點
- 過程內污點分析實裝（intra-procedural taint analysis）
- MCP HTTP 伺服器與 Claude Code 相容性修復
- 向量索引建立與 Docker 資源部署改善
