## Terraform MCP Server Enables AI Assistants to Interact with Terraform Infrastructure

HashiCorp 正式推出開源 Terraform MCP Server，讓 AI agent 可整合 Terraform Registry API，用於自動化基礎設施任務。此舉旨在減輕基礎設施工程師的重複工作，提升團隊生產力。MCP（Model Context Protocol）作為 agent 與外部系統互動的標準協議，這是 Terraform 官方首次提供的 MCP server 實現，開闊了 IaC 自動化的新應用場景。

### 重點
- HashiCorp 發布 Terraform MCP Server 開放版本，支援 Terraform Registry API 整合
- MCP 標準化 agent 與基礎設施工具的互動協議，減少手工操作的重複工作
- 開源項目讓基礎設施團隊可直接在 agent 中執行 Terraform 操作（資源查詢、配置管理等）
