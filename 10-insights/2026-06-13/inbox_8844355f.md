## Release Candidate v1.6.8-rc.26

GitNexus 1.6.8-rc.26 發布，為 1.6.8-rc.27 前一小時發行的候選版本。源自主分支 cab63b5 commit。變更清單與 rc.27 幾乎相同，但缺少最後的 MCP 參數重命名修復。包含 VECTOR index 修復、Docker 資源打包、Java Spring route annotation 自動提取、多分支索引、影響分析精度、TypeScript/JavaScript 控制流圖、汙點分析、圓形導入檢查等功能。代表同日快速迭代中的穩定化階段。

### 重點
- embedding 索引創建路徑修復及 Docker 運行時資源包含問題解決
- 新增 Java Spring 框架自動分析：route annotation → Route 節點提取
- 多分支索引、控制流圖、汙點分析等程式碼分析能力擴展
