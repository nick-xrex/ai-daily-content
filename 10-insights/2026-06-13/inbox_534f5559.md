## Release Candidate v1.6.8-rc.24

GitNexus 1.6.8-rc.24 發布，為 rc.25 更早的候選版本，發布於 2026-06-13 06:53，源自主分支 6bd2d11 commit。此為同日 RC 循環的最早發行版本，包含相同功能修復集合，未包含後續版本的 MCP 參數重命名。涵蓋 embedding 索引、Docker 資源、Java Spring 支持、多分支索引、汙點分析等功能，反映功能完成度從初版到最新的演進過程。

### 重點
- embedding 索引創建與 Docker 資源包含的穩定性修復
- Java Spring 框架分析支持新增
- 多分支索引與衝擊分析精度改進基礎實現
