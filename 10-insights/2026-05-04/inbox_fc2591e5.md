## I am worried about Bun

Anthropic 於 2025 年 12 月收購 Bun JavaScript runtime，社群開發者隨後表達擔憂。基於 Bun 構建的 Claude Code 近期出現推理能力下降、會話狀態 bug 以及提示詞品質劣化等問題（來自 Anthropic 官方事後分析）。作者認為隨著 Bun 與 Anthropic 深度整合，可能面臨類似 Claude Code 的品質衰退風險，遂決定遷移至 pnpm。這反映開發工具社群對大型 AI 公司收購開源項目後維護承諾的普遍憂慮，尤其是在 Anthropic 的產品治理問題已浮現的背景下。

### 重點
- Claude Code（Bun 構建）出現「預設推理能力下降、會話 bug、提示詞改動影響編碼品質」（Anthropic 官方確認）
- Anthropic 承諾保持 Bun MIT 開源與原技術團隊，但收購後可能面臨與 Claude Code 類似的整合質量風險
- 開發者示警：大型 AI 公司收購開源項目後，產品治理疏失可能導致長期衰退
