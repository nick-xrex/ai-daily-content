## Connecting LLMs to the Real World: Tool Use, Function Calling, and MCP

文章追蹤 LLM 能力進化的三個里程碑：基礎工具調用(tool use)、函數調用(function calling)和 Model Context Protocol(MCP)。這個演進過程讓大語言模型從單純的文本生成工具，升級為可以與外部系統互動、為終端用戶解決實際問題的智能助手。MCP 進一步擴展了 LLM 與真實世界的連接能力。

### 重點
- LLM 工具能力的三階段進化：基礎 tool use → function calling → MCP
- MCP 定義了 LLM 與外部系統的互動協議，突破孤立文本生成的限制
- 實現 LLM 從被動文本工具升級為主動解決真實問題的助手
