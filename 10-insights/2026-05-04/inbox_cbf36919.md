## The bottleneck was never the code

這篇文章挑戰了 AI coding agents 是編碼瓶頸的常見假設，主張真正的瓶頸是人類協作與組織溝通。文中指出當代碼實現變得輕鬆時，團隊開始受限於精確規格的生成與隱性知識的外化。作者強調受 Jevons 悖論影響，便宜的開發導致功能膨脹，許多產品添加不必要特性。agents 無法通過浸泡式學習獲得組織背景知識；成功的企業將是那些能維持一致性、有效外化隱性知識、優化組織協調的團隊。

### 重點
- 隱性知識成關鍵瓶頸：agents 無法通過會議、Slack 頻道或故障排除獲得組織背景，真正需要外化
- 規格說明與焦點成新瓶頸：當編碼成本下降，精確規格和「說不」的能力變成限制因子，Jevons 悖論導致功能膨脹
- 組織協調優於個人生產力：agent 是組織協調的倍增器，但只會放大既有的組織文化和溝通能力
