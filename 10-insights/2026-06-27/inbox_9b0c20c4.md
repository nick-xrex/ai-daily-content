## AWS Introduces Workload Credentials Provider for Automated Certificate and Secret Management

AWS 公告 Workload Credentials Provider 開源工具，用於自動化交付與更新應用程式的憑證與密鑰。支援 AWS 與非 AWS 環境，減少自訂自動化需求，防止過期憑證引發的宕機風險。

### 重點
- AWS Workload Credentials Provider：開源工具，自動交付與更新憑證、密鑰
- 跨環境支援：AWS 及非 AWS 環境均可部署
