## How Claude Code and Codex Sandbox Untrusted Code

文章探討 Claude Code 和 Codex Sandbox 如何對未審查的代碼進行沙盒隔離。當 AI agent 在代碼庫中執行 shell 命令時，實際上是在運行未經人類編寫或審查的代碼，帶來潛在安全風險。該文討論沙盒技術對於安全執行自動化代碼的重要性。

### 重點
- Claude Code 和 Codex Sandbox 支援安全執行自動化生成的代碼
- AI agent 運行的 shell 命令存在未審查風險，需要隔離機制
- 沙盒隔離是防止惡意或意外代碼執行的關鍵防線
