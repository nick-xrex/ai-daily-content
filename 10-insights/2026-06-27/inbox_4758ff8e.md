## GitHub for PMs: Version Control for Everything You Build With AI

文章提出關鍵框架：應將 prompt、CLAUDE.md 配置檔、評估標準等 AI 開發要素當作可版本化的程式碼資源來管理。隨著迭代，這些配置每週都在演進，若無版本控制將無法追蹤哪個版本效果最優。用 Git 風格的版本管理開發者可記錄每次 prompt 變更背景、比較版本間的效果差異，必要時回滾。此框架將 AI 開發流程正式化，使其與傳統軟體工程並駕齊驅，降低實驗中的熵。

### 重點
- prompt 與 eval criteria 應被視為可版本化資產，每週演進都應記錄
- 用 Git 管理 prompt 版本，可追蹤變更背景、對比效果、回滾失敗決定
- 版本化 CLAUDE.md 等配置，將 AI 開發流程與代碼開發一致，降低混亂
