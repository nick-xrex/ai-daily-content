## v3.14.3 — 70+ plugin fixes (concurrent darwin sweep)

Ruflo v3.14.3 發布 70+ 個 plugin 級別修正，由 4 輪並行 Darwin loop 跨 35 個 ruflo plugin 自動生成（PR #2477）。修正涵蓋：18× ADR-112 compliance 缺陷（補充 skill 描述中的「Use when...」指引以改善 Claude Code 自動路由），~10× CLI flag 與 MCP tool 參考錯誤，~12× 過期 README 計數，6× 命名空間錯誤、4× 未驗證效能宣稱、8× 跨檔案一致性漂移。驗證成果：4 輪 × 35 plugin 共 140 個組合中零 smoke contract 失敗，~12.6M 總 token、~28 分鐘牆時完成。這展示大規模並行 Darwin loop 對系統性發現跨檔案一致性問題的有效性。

### 重點
- 4 輪並行 Darwin loop × 35 plugins = 140 組合，零 smoke 失敗，驗證自動化一致性檢測的可靠性
- 修正分類：18× ADR-112 指引、~10× 參數錯誤、~12× 計數過期、~22× 其他（命名空間、效能宣稱、跨檔案漂移）
- 成本效益：~12.6M tokens、28 分鐘，並行化節省顯著時間同時達成 0 失敗率
