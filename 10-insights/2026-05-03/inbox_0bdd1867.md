## Mergeable by default: Building the context engine to save time and tokens — Peter Werry, Unblocked

Unblocked 的 Peter Werry 和 Brandon 介紹如何構建 Context Engine，專門用於為 AI Agents 提供優化的上下文。Context Engine 的核心目的是在 Agent 開始執行任務前，供應所有必要的上下文（例如代碼庫、組織信息）但不包含無關信息，以節省 tokens 和執行時間。演講駁斥了關於 Context Engines 的三個常見誤解，並討論了構建社交工程圖等實用組件。

### 重點
- Context Engine 是為 AI Agents 優化上下文輸入的專用系統，避免 Agent 無謂地搜索代碼庫
- Context 供應的原則：只提供必要信息，排除無關內容，以最優化方式呈現
- 社交工程圖（Social Engineering Graph）是 Context Engine 中的關鍵組件
