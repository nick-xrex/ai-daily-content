## Release Candidate v1.6.8-rc.35

GitNexus 1.6.8-rc.35 發布，包含 25+ 項改進，強化程式碼分析與 AI agent 集成能力。核心更新：MCP HTTP 伺服器新增 Streamable HTTP 和 legacy SSE 傳輸、多分支索引與分支作用域查詢（#2106）、Java Spring 路由註解提取、TypeScript/JavaScript control-flow-graph 層、intra/interprocedural taint analysis、PDG 控制相依性分析（Ferrante 演算法）、新增 trace MCP tool 查找符號間最短調用路徑。同時修正 Docker 資產發布（hooks/、skills/）、embedding VECTOR 索引建立、大型倉庫分析穩定性、hooks 子程序綁定等問題，包含 4 位新貢獻者。

### 重點
- MCP HTTP server 支援 Streamable HTTP + legacy SSE 傳輸，強化 Claude Code 可呼叫性（#2141）
- 多分支索引與分支作用域查詢（#2106）+ taint analysis（intra/interprocedural via function summaries #2083, #2084）提升靜態分析深度
- 新增 trace tool BFS 實現最短調用路徑、PDG 控制相依性、circular import 檢測，提升 AI agent 程式碼理解能力
