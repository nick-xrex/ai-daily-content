## Vercel's Andrew Qu on why agents are a new kind of software

Vercel 推出了名为 eve 的 agent framework。Vercel Chief of Software Andrew Qu 详细阐述了该框架的设计理念。根据 Qu 的观点，现代 agent 软件的关键设计要素包括三个维度：skills（技能组件）、sandboxes（隔离执行环境）和 agent-readable websites（便于 agent 理解和交互的网站接口）。这个框架代表了 Vercel 对 agents 作为新型软件形态的系统化思考。整体而言，eve 框架试图通过重新定义这三个核心维度来改进 agent 的能力和可靠性。

### 重點
- Vercel eve agent framework 正式推出，Chief of Software Andrew Qu 主导设计
- 三核心设计维度：skills、sandboxes、agent-readable websites
- 框架将 agents 定位为新型软件形态，需要重新思考交互和执行模式
