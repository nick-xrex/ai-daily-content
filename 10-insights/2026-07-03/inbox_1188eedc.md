## Google Releases A2UI v0.9: Portable, Framework-Agnostic Generative UI

Google 發布 A2UI v0.9，一套框架無關的標準，使 AI agents 能跨多個平台聲明用戶界面意圖，無需編寫任意代碼。新版本強調與現有設計系統的對齐，新增 Python SDK、改進錯誤處理、支援多種傳輸方法，並提供遷移指南和演進規範，推進 generative UI 的標準化。

### 重點
- 框架無關標準，AI agents 可跨平台聲明 UI intent 無需任意代碼
- 新增 Python SDK，改進錯誤處理與多種傳輸方法支援
- 與現有設計系統對齐，提供完整遷移指南和演進規範
