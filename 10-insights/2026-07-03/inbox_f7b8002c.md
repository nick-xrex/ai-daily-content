## AI Agents Explained: What Is a ReAct Loop and How Does It Work?

介紹 ReAct（推理-行動-觀察）循環框架，解釋 AI 代理如何通過逐步推理、執行行動、觀察結果的反覆迭代過程達成最終答案。ReAct 將傳統推理與實時反饋結合，是現代 agent 系統的核心設計模式。

### 重點
- ReAct 循環的三個核心步驟：推理（Reason）、行動（Act）、觀察（Observe）
- Agent 通過迭代循環逐步逼近最終答案，而非單次生成
- ReAct 模式已成為現代 AI agent 系統的標準推理框架
