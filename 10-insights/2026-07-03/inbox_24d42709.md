## Hardwood Promises High-Speed JVM Apache Parquet Processing with Zero Mandatory Dependencies

Hardwood 是一个处理 Java 中 Parquet 文件的库，由知名开源开发者 Gunnar Morling 启动。该项目已达到 v1.0，标志着首个稳定版本的发布。Hardwood 相比 Apache 官方的 Parquet Java 实现提供了两个核心优势：采用多线程设计以提升性能，并且零强制外部依赖，简化了依赖管理和部署。目前 Hardwood 仅支持 Parquet 文件读取，写入功能预计在后续版本推出。这个项目为 Java 开发者提供了一个更轻量级且高效的 Parquet 处理选项。

### 重點
- Hardwood v1.0 发布，由 Gunnar Morling 领导开发
- 多线程设计、零强制外部依赖，相比 Apache Parquet Java 实现更轻量高效
- 目前仅支持读取（read），写入（write）支持在后续版本
