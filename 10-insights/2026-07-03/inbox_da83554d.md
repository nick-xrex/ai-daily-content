## Hardwood Promises High-Speed JVM Apache Parquet Processing with Zero Mandatory Dependencies

由 Gunnar Morling 發起的 Hardwood 項目達到 v1.0 版本，提供高效的 JVM 環境下 Apache Parquet 文件處理方案。採用多線程設計且零必須外部依賴，相比 Apache Parquet Java 官方實現更簡潔高效。目前版本支援讀取功能，寫入功能預計在後續版本實現。

### 重點
- v1.0 版本發布，多線程設計、零必須依賴
- 相比 Apache Parquet Java 實現更簡潔高效
- 目前僅支援讀取，寫入功能預計後續推出
