## Anthropic Launches Claude Platform on AWS

Anthropic 宣佈 Claude Platform 在 AWS 上正式發布 General Availability。AWS 客戶可使用 AWS IAM 認證、計費和監控服務直接存取 Anthropic 的原生 Claude 平台。此舉拓展了 Claude 的部署選項，簡化企業級 AI 應用在 AWS 生態內的部署流程。該發布對標 OpenAI 在多雲環境中的佈局策略，使 AWS 用戶能在既有基礎設施內無縫整合 Anthropic 的 AI 能力。

### 重點
- Claude Platform 在 AWS 上進入 GA，支援 AWS IAM、計費和監控整合
- AWS 客戶可直接部署和管理 Anthropic 模型，無需額外認證層
- 擴大 Claude 在企業市場的可用性，對應多雲 AI 部署需求
