## Giving an Agent a Design Layer Instead of a PowerPoint Template

介紹一個高效的設計系統化方法：用單個 JSON 檔案替代傳統 PowerPoint 設計模板，為 Agent 提供明確的設計規則層。通過結構化 JSON 定義品牌約束，Agent 無需猜測「on-brand」的定義，能精確遵循規範自動生成設計產物。這是一個輕量但高效的 AI 代理設計治理方案。

### 重點
- 用 JSON 檔案替代 PowerPoint template 作為設計規則載體
- Agent 無需自動推斷，可直接理解 「on-brand」的精確定義
- 結構化設計層方法提升 AI 代理的設計準確度和品牌一致性
