## MCP Servers & Agents — Connect Once, Delegate Forever

Richard Taujenis 介绍了 MCP 在 agent 架构中的关键角色，核心理念是「Connect Once, Delegate Forever」。通过在初期建立 MCP 服务连接和工作流配置（如 Claude Code 环境中的 CLAUDE.md 规则定义），agent 可在此基础上持续自主执行任务，无需重复配置。这代表了现代 agent 设计中的重要架构模式：将声明式配置与运行时执行逻辑分离，使 agent 能够在固定约束下灵活决策。

### 重點
- "Connect Once, Delegate Forever" 模式：初次配置 MCP + rules 后，agent 可持续自主委派工作
- 配置内容：CLAUDE.md 规则、工作流定义、Claude Code 环境参数等
- 架构优势：声明式配置与运行时执行分离，降低配置复杂度，提升 agent 自主性
