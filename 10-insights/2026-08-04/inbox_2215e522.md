## Running Kimi K3 on AWS: The Real Cost of Self-Hosting a 2.8-Trillion Parameter AI Model

本文分析在 AWS 上自託管 Kimi K3（2.8 兆參數超大規模模型）的真實成本投入。針對考慮超大規模模型自託管的工程師，文章揭示 GPU 基礎設施成本（涉及數十萬美元投資層級）、電力與冷卻營運開銷、維護複雜度等決策關鍵因素。作者以『在花費數百萬美元購置 GPU 前，每個 AI 工程師都必須理解的』為主軸，系統性分析自託管部署的完整成本結構。該分析對比自託管（高效能、數據隱私保護）與雲端 API 託管（低成本、託管維護）兩種模式。Kimi K3 作為超大規模模型的代表性案例，其自託管可行性分析直接影響中大型企業對本地部署策略的評估。

### 重點
- Kimi K3 具 2.8 兆參數規模，單次部署 GPU 投資通常超過百萬美元
- 自託管成本不限於硬體購置，尚需考量電力、冷卻、維保等營運開支
- 工程師應在自託管（高效能、數據隱私）vs. API 託管（低成本、託管維護）間進行 ROI 分析
