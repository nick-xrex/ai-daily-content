## Using Agents as Tools

探討如何使用 AI Agent 作為工具構建複雜工作流。利用 OpenAI Agents SDK 實現經理-專家角色架構，由經理 Agent 協調分工，由不同專家 Agent 負責各自的專業領域執行。這種架構分離了決策協調與領域執行。

### 重點
- OpenAI Agents SDK 支持多 Agent 協作系統構建
- 經理-專家架構：協調層與執行層分離，降低單一 Agent 認知負擔
- 每個 Agent 聚焦特定專業領域提高可靠性
