## Claude Code Patched 4 Permission Bypasses in One Release — One Was a Tab Character

Claude Code 最近版本修補了 4 個 Permission Bypass 漏洞；其中一個漏洞巧妙地只需一個 Tab 字符就能繞過權限檢查。作者正在開發權限規則審計工具，該工具在執行時發現其自身示例配置也包含可利用漏洞。這一發現揭示出權限驗證邏輯在處理邊界情況（特別是 whitespace 字符）時存在系統性缺陷。開發者需要在字符級別進行更嚴格的權限檢查與規範化，才能有效防止被看似無害的字符繞過。

### 重點
- 單個版本修補 4 個 Permission Bypass 漏洞，其中包含 Tab 字符繞過攻擊
- Whitespace 邊界情況（如單個 Tab）可用於規避權限驗證邏輯
- 權限審計工具自身示例配置亦包含可利用漏洞，表明防護需多層驗證機制
