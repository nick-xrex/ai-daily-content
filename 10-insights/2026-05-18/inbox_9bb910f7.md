## Java News Roundup: OpenJDK JEPs, Azul Payara, WildFly, LangChain4j, OpenXava, Google ADK

InfoQ Java 新聞綜合（5 月 11 日）涵蓋 Java 生態的多項重點動態。OpenJDK 側，三項 JEP 已列入 JDK 27 目標清單。應用容器領域，Azul 推出 Payara Community、WildFly 推出 wado CLI 工具。AI 集成方面，LangChain4j 和 Google ADK 均發布 point releases，推進 Java 對 LLM 和生成式 AI 的原生支持。此外，Micronaut 和 OpenXava 發布維護版本，生態保持穩定迭代。整體反映 Java 在容器、AI 集成、模型驅動開發領域的持續演進。

### 重點
- 三項 JEP 列入 JDK 27 目標；Azul Payara Community 和 WildFly wado CLI 工具發布
- LangChain4j 和 Google ADK 發布 point releases，擴展 Java 對 LLM 集成的支持
- Micronaut 和 OpenXava 維護版本發布，Java 生態在容器化和 AI 賦能方向持續推進
