## Stop Wasting Your Claude Tokens! (New Open-Source Extension)

新開源瀏覽器擴充軟體「Claude Counter」解決 Claude.ai 使用者的 token 用量限制問題。提供實時 token 計數、prompt cache 倒數計時、以及 5 小時 session 與 7 天週限制的使用量視覺化進度條，直接在 Claude 介面上顯示。完全免費開源（MIT License），所有處理均在本地瀏覽器執行，無外部伺服器、無追蹤、無廣告，隱私優先設計。已上架 Chrome Web Store 官方下載。

### 重點
- 實時 token 計數 + prompt cache 倒數計時，使用者能預測 context 重置時機
- 視覺化進度條準確追蹤 5 小時 session + 7 天週限制，直接讀取 Claude 後台串流資料
- 隱私優先，開源（MIT），Chrome/Brave/Edge/Opera 通用，無外部依賴
