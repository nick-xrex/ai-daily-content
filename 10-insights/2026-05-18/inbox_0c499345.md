## The Ralph Loop: How to Build Software Without Babysitting the Agent

Ralph Loop 是構建 AI 編碼代理長期專案的循環架構。傳統方式中 AI 在同一上下文視窗內反覆修復，導致「context rot」—— 原始任務框架被 40 分鐘的失敗嘗試和相互矛盾的假設蓋住。Compaction（壓縮會話）更糟，因為模型把自己的錯誤假設也壓縮進去。Ralph Loop 用結構化方法規避此問題：每次迭代用新的乾淨上下文啟動，從 Git 歷史、進度追蹤器、PRD.md 讀取狀態（記憶存外部檔案，注意力存上下文）。實作是簡單的 bash 迴圈，呼叫 Claude 時注入 PRD、進度檔和最近提交，要求代理一次只做一個任務。核心心法：把 AI 當作可靠的 CI 執行器而非需要精準指令的初級開發者，減少「babysitting」。

### 重點
- Context Rot：AI 在長對話中，上下文視窗被失敗嘗試污染；Compaction 損失框架因為模型壓縮自己的錯誤假設
- Ralph Loop 架構：每迭代用新上下文，從檔案（git log、progress.md、PRD.md）重新讀入狀態，記憶外部化
- 實務實作：Bash 迴圈 + Claude CLI，傳入 @PRD.md @progress.md，檢測 <promise>NO MORE TASKS</promise> 信號終止
