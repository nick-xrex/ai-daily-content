## Article: Building a Secure MCP Server on AWS for a Million-Company B2B Platform

InfoQ 文章詳細介紹如何在 AWS 上構建安全的 MCP Server，用於 B2B 智能平台暴露涵蓋 100 萬家公司的企業檔案。方案允許終端用戶透過 LLM 客戶端以自然語言查詢（例：「找德國 50-200 人員的 SaaS 公司」），系統自動轉化為結構化 API 調用。核心工程挑戰在於如何在保障生產環境數據安全的前提下，建立 LLM 與關鍵業務系統的可靠連接，避免直接的不安全橋樑。該安全 MCP Server 架構模式可應用於其他需要 LLM 訪問內部數據的場景。

### 重點
- MCP Server 在 AWS 上安全地暴露 100 萬家公司檔案，支援自然語言查詢轉換為結構化調用
- 核心模式：使用 MCP Server 作為訪問控制層，隔離 LLM 與生產數據庫的直接連接
- 架構可推廣至其他 B2B 場景，如 CRM、ERP 等內部系統的 LLM 安全訪問
