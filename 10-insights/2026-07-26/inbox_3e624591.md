## v3.32.10 — tracker-sweep (9 bug fixes + promo seed + follow-ups)

Ruflo v3.32.10 是 2026-07-24~26 追踪器扫描周期的综合修复发布，涵盖 9 个已跟踪 bug 和 1 个冷启动回归。核心改进包括：恢复冷启动时本地种子池的宣传行显示（ADR-311 修复），修复 ruflo init 的 97MB 超大导入问题（仅保留单个 ~2KB SKILL.md），完善 ADR 索引的数据解析（规则接受多行和包装的关系描述），修正 Windows shell 执行问题，消除并发写入竞态条件（WorkerDaemon.saveState 等）。测试覆盖改善从 98 failures 至 91 failures（净减 7 个，未引入新失败），共 3199 个测试案例。

### 重點
- 冷启动优化：恢复本地种子池宣传行，支持远程同步前的 ≤60 秒本地显示（9 条种子消息：1 披露 + 7 教育 + 1 宣传）
- 安装体积改善：ruflo init 从 97MB 仓库导入缩减为单个 SKILL.md，并检测过期安装自动重新生成
- 可靠性提升：9 个 bug 修复主要针对无声失败、竞态条件、API 不匹配和 Windows 兼容性（net -7 failures，无新增失败）
