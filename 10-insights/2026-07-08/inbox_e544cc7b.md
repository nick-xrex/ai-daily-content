## Why AI Infrastructure must evolve for Agent Experience — Akshat Bubna, Modal CTO

Modal 联合创始人兼 CTO Akshat Bubna 讨论了 AI 基础设施为何必须为 Agent 体验而演进。经过两年发展，Agent 体验技术已从理论概念进阶到可生产使用的阶段，标志着代理系统从研究跨越到实务应用的关键转折点。Modal 在构建新一代 agent cloud 平台中积累了核心经验，涉及底层基础设施如何高效支撑复杂代理工作流。这次分享反映了整个 AI 基础设施产业正在为支持代理型系统而进行架构升级的大趋势。

### 重點
- Agent 体验技术已达可用状态（"Agent Experience is working now"）— 从两年前的概念探索到今日的生产落地
- AI 基础设施必须从批量 LLM 推理模式转型为支持 agent 工作流、实时反馈、环境交互的架构
- Modal 在 agent cloud 构建中的两年经验积累为行业提供了可参考的基础设施设计模式
