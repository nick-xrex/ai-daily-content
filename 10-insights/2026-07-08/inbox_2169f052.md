## Release Candidate v1.6.10-rc.8

GitNexus v1.6.10-rc.8 是 v1.6.10 發布前的中間 RC 版本，包含 CodeBuddy/Qoder 代理集成、完整 Codex hooks 與 plugin marketplace 支持。核心修復涵蓋 proxy-blocked 環境下 onnxruntime-node 自修復（#2372）、Windows FTS 擴展診斷與自修復（#2375）、MCP symbol 內容及行號儲存 0-based/1-based 轉換（#2380）、自定義 HTTP embedding endpoint 錯誤報告（#2386）、Windows shadow 缺失錯誤識別（#2387）、FastAPI route path 解析（#2393）。與 rc.9 主要差異在於缺少最終的 MCP query hint 節流與條件性機制。

### 重點
- CodeBuddy/Qoder 代理集成 + 完整 Codex hooks 與 plugin marketplace，支援編碼代理協作
- proxy-blocked 環境下 onnxruntime-node 自修復 + Windows FTS 擴展診斷與自修復
- MCP symbol content 與行號儲存 0-based/1-based 轉換修正，保證編輯器與 MCP 工具互操作性
