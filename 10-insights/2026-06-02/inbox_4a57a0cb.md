## Code Is Cheap. Engineering Judgement Is Now the Scarce Resource

論文指出建造成本已崩潰，工程瓶頸轉移到所有制、驗證、品味判斷和產品決策。隨著編碼門檻下降，稀缺資源變成「什麼應該存在」的決策力，而非技術實現力。強調驗證、所有制和工程品味成為新的競爭優勢。

### 重點
- 成本崩潰 → 決策品味成為稀缺資源
- 瓶頸轉移：從「如何構建」到「什麼該構建」
- 驗證、所有制、工程品味判斷成為競爭優勢
