## Google Workspace CLI: Unified Command-Line Tool Built for Humans and AI Agents

Google 發布新的 Google Workspace CLI，用 Rust 構建，提供統一介面整合 Drive、Gmail、Calendar 等服務。工具支援動態 API 適配和 100+ 內建技能，目標同時服務使用者和 AI agent。設置需要 Node.js 和 Google Cloud 專案。社群初期反饋混合，讚賞動態功能但也指出設置複雜性。

### 重點
- Rust 構建、動態 API 適配、100+ 內建 skills
- 雙重目標：human + AI agent 介面支援
- 設置門檻：需 Node.js + Google Cloud project

Google has released a new CLI for Google Workspace, offering a unified interface for various services like Drive, Gmail, and Calendar.
