## micropython-wasm 0.1a1

MicroPython WebAssembly 版本 0.1a1 發布，包含在開發 datasette-agent-micropython 時發現的限制修復。此版本作為 datasette-agent-micropython 的基礎執行環境，支持在瀏覽器和隔離 JavaScript 環境中執行 Python 代碼。

### 重點
- v0.1a1 修復在 datasette-agent-micropython 開發期間發現的已知限制
- WebAssembly 編譯支持跨平台 Python 執行（瀏覽器、Node.js 沙盒）
