## Windows Becomes the Canvas for AI and Agents: A Technical Deep Dive.

微軟宣布將 Windows 重新定位為 AI agents 的執行平台，推出 Microsoft Foundry on Windows、MCP-Powered Agent Connectors 與 Windows 365 for Agents 等關鍵組件。該戰略將 Windows 從傳統作業系統擴展為支援 AI agents 部署、管理與協作的基礎設施。MCP-Powered Agent Connectors 允許 agents 通過 MCP 標準化協議連接 Windows 系統服務與企業應用，實現無縫整合。Windows 365 for Agents 提供雲端虛擬化環境，使企業能在受控環境中大規模部署與運行 AI agents。此舉展示微軟將核心平台與 AI agent 生態系統深度融合的意圖，同時重構系統堆棧以適應 agent-native 工作流。

### 重點
- Microsoft Foundry on Windows 與 MCP-Powered Agent Connectors：採用 MCP 標準化協議連結 agents 與 Windows 系統及企業應用
- Windows 365 for Agents：雲端虛擬化環境支援企業規模部署、管理與執行 AI agents
- 平台轉變：Windows 從傳統作業系統轉向 AI agents 執行與協作平台，涉及系統堆棧重構
