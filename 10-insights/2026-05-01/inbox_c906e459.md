## JobRunr Introduces ClawRunr, an Open-Source Java AI Agent

JobRunr 開源發布 ClawRunr，一個新的 Java AI agent 框架，前身是 JavaClaw。ClawRunr 在用戶硬件上執行各類背景任務，包括定期任務、週期性任務和一次性任務。框架支援多種通信方式：web UI、Telegram Bot、Discord Bot。整合 MCP 工具和瀏覽器自動化，支持複雜的對話交互和任務自動化。依賴 JobRunr 提供任務排程、失敗重試機制和實時監控。在用戶硬件執行的特性特別適合隱私敏感的場景。

### 重點
- 支援多渠道交互：web、Telegram、Discord，適合多種使用者互動模式
- 整合 MCP tools 和瀏覽器自動化，支援複雜工作流和人機協作
- 本地執行（硬件）而非雲端，隱私敏感場景優勢明顯；JobRunr 負責排程和監控
