## Stop Copy Pasting Prompts Into Cursor and Claude. There’s a Better Way.

文章指出在 Cursor 和 Claude 中重複 copy-paste prompt 不是最佳做法。當使用者開啟新 Cursor session 時，模型狀態重置、context window 清空，導致需從瀏覽器分頁或 Notion 等工具中手動複製之前的 prompt。作者聲稱存在更優的替代方案，惟提供的摘要未揭露具體技術方案細節。該問題影響所有進行多 session 開發工作的使用者。改善 prompt 管理流程可顯著提升開發效率和減少重複勞動。

### 重點
- Cursor/Claude 中 prompt 的手動 copy-paste 導致跨 session 復用低效
- 新 session 開啟時 context window 重置，強制使用者重新複製 prompt
- 存在但未披露的更優替代方案待讀原文確認
