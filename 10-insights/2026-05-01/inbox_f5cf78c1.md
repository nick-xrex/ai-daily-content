## Broadcom Donates Velero to CNCF, Shifting Kubernetes Backup to Community Governance

Broadcom 宣佈將其 Kubernetes 生態中的核心備份和恢復工具 Velero 捐獻給雲原生計算基金會（CNCF），成為 CNCF Sandbox 級別的項目。Velero 的主要特點是在 Kubernetes API 層級進行操作，而非傳統的 hypervisor 或存儲層快照方式。它利用 Kubernetes 的自定義資源定義（Custom Resource Definitions，CRDs）來捕獲集群的完整狀態，使備份和遷移操作更加原生、輕量且與 Kubernetes 生態深度整合。這次捐獻標誌著 Velero 的治理模式從商業公司轉向社區驅動，預期將提升項目的長期維護和發展動力。

### 重點
- Velero 在 Kubernetes API 層級運作，支持多集群備份與遷移操作
- 使用 Custom Resource Definitions（CRDs）而非 hypervisor/storage snapshots，架構更輕量
- Sandbox 級別開放原始碼治理（對比商業支援），預期提升社區貢獻和長期維護
