## Agents on the Canvas in tldraw — Steve Ruiz, tldraw

Steve Ruiz（tldraw CEO）介紹 tldraw whiteboard SDK 與 AI agent canvas 整合。Tldraw 既是免費線上白板工具，也是可嵌入其他產品的 SDK（React 元件化架構）。已被 Replit agent canvas、Luba AI canvas 等採用。特色：「Make Real」應用（2023 vision models 發佈時的熱門專案），允許用戶在畫布上繪製草圖，AI 即時轉換為可互動的 UI 原型。底層使用 hackable canvas runtime（React 組件），支援繪製、自動轉換、播放動畫等。Ruiz 強調 SDK 的靈活性讓開發者能快速構建 AI-驅動的視覺化工具。

### 重點
- Tldraw SDK 支援 React 元件化架構，已成為 Replit、Luba AI、Stitch 等 AI canvas 建設基礎
- Make Real 經典案例（2023）：用戶繪製 UI 草圖→vision model 識別→自動生成可互動原型，實現快速原型設計
- Canvas runtime 與 agent 協作：通過 SDK 可快速迭代、測試不同 AI 模型、構建新產品（Steve 個人驗證
