## Vitest 4.1: Test Tags, Native Node.js Execution and AI Agent Reporter

Vitest 4.1 是由 VoidZero 開發的 JavaScript 測試框架升級版本，引入了多項關鍵新功能。首先，測試標籤（test tags）功能允許開發者對測試進行過濾和配置，提升測試組織效率。其次，新增了實驗性模式以繞過 Vite 的模組運行器，支持原生 Node.js 執行，減少額外抽象層。再次，框架提供新的生命週期鉤子（lifecycle hooks），擴展測試定制能力。此外，Vitest 4.1 原生支持 Vite 8，並在性能基準測試中相比 Jest 實現了改進。該版本同時提供遷移指南以協助現有用戶升級。

### 重點
- Test tags 功能用於過濾和配置測試邏輯
- 實驗性 Node.js 執行模式繞過 Vite module runner，支持原生執行
- 新增生命週期鉤子（lifecycle hooks），允許測試框架級的自定制行為
