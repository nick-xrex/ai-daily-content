## I Fired My IDE and Used Claude Code for Everything.

Kevin Gabeci 實驗用 Claude Code 完全取代 VS Code 一個月。Claude Code 的運作不同於典型聊天機器人（貼上程式碼手動複製），而是透過終端與開發流程整合，使用者描述需求後工具自動讀取檔案、編寫程式碼、編輯現有檔案、執行終端命令、導航專案。Gabeci 發現自己逐漸停止使用 VS Code，因為 Claude Code 已接手越來越多職責。

### 重點
- Claude Code 運作於終端整合模式，非貼上式互動——自動讀取/寫入/執行，降低人工轉運成本
- 長期使用中開發者逐漸轉向 AI 工具，IDE 職責漸被接管
- 探索指出 AI 編輯工具可顯著改變開發流程（但文章截斷，無最終評論）
