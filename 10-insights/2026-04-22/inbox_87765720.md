## From Ad Hoc Prompting to Repeatable AI Workflows with Claude Code Skills

文章展示如何用 Claude Code 的 Skill 功能將臨時的 LLM 提示升級為可重複、可版本控制的 AI 工作流。具體案例為客戶研究中的 LLM persona interview——每次提示詞都會重新調整，效率低下。通過編寫 Skill，可將這個工作流固化為可重複執行的邏輯，避免每次都重新思考提示詞結構。這種做法提升工作一致性、減少認知負擔，並使工作流易於團隊共享和迭代。

### 重點
- Claude Code Skill 將零散的 LLM 提示轉化為可版本控制、可重複的工作流
- LLM persona interview 用於客戶研究，通過 Skill 實現自動化並提升一致性
- 系統化工作流相比臨時提示，降低認知負擔並便於團隊協作
