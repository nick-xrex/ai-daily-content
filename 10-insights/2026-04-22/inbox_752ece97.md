## Dropbox Collaborates with GitHub to Reduce Monorepo Size from 87GB to 20GB

Dropbox 與 GitHub 合作最佳化 Git Delta 壓縮演算法，將後端單體庫從 87GB 縮減至 20GB。此優化改善了程式碼複製時間和 CI 性能，直接提升開發人員生產力。減少 77% 的儲存空間在大規模組織中帶來顯著的成本和效率收益。大多數團隊往往忽視儲存庫最佳化，但在大規模工程實踐中它是被低估的槓桿點。該案例展示了基礎建設層面的小改進如何帶來深遠影響。

### 重點
- Git Delta 壓縮優化：87GB → 20GB（減少 77%），直接改善 Clone 時間與 CI 效能
- 儲存庫最佳化是被低估的大規模工程效率槓桿，影響開發迴圈和成本
- 基礎建設層面的小改進在大規模組織中能帶來顯著的聯級效應
