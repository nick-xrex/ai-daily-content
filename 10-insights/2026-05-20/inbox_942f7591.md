## How fast is 10 tokens per second really?

開發者 Mike Veerman 開源 HTML 互動應用，模擬 LLM token 輸出速度的視覺化效果。支援 5–800 tokens/秒全範圍實時模擬，幫助用戶直觀理解「模型 30 tokens/sec」在實際對話中的延遲與流暢度感受。工具採開源 HTML 實現，無外部依賴，可直接在瀏覽器執行。Source code 已公開，便於開發者自行部署或集成。該工具降低了技術選型時的資訊不對稱，使工程團隊能更準確估計 LLM 集成的用戶體驗品質。

### 重點
- Token 輸出速度視覺化工具，支援 5–800 tokens/sec 全範圍
- 開源 HTML，無依賴，可直接在瀏覽器運行
