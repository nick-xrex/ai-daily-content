## Railway: The Agent-Native Cloud — Jake Cooper

Railway 雲端平台公開運營數據：300 萬使用者、每週 100K 新增註冊、自有機房、coding agent 週支出達 $200K+（月 $800K+）。平台正式推出「Agent-Native Cloud」架構，將 AI coding agent 從開發工具升級為平台一級服務對象和基礎設施。傳統 PR-based 開發流程逐漸被 agent 驅動的自動化取代，標誌 agent workflow 進入生產主流。月度 $800K+ 的 agent 支出反映大規模採用的實際可行性，改變了工程團隊的經濟學。Railway 率先將 agent 作為核心基礎設施，預示主流雲端平台將跟進採用 agent-native 設計。其他平台（AWS、Azure、Google Cloud）的 agent-native 戰略布局將成為 2026–2027 的重要看點。

### 重點
- Railway 規模：300 萬用戶、100K/週新增、自有機房、$800K+/月 agent 支出
- 架構變革：「Agent-Native」首次將 AI agent 設計成雲端平台核心對象，而非外掛工具
- Pattern：Coding agent workflow 已取代傳統 PR-based 開發；大規模成本投入($800K+/月)反映可行性已驗證
