## rc/a691dcb320a7e040dc015be13c130a312e8ee1a1

GitNexus RC：在路由節點上持久化 HTTP 方法。Web 應用程式的路由不只依賴 URL 路徑，HTTP method（GET、POST、PUT、DELETE 等）也是關鍵區分因素。此功能擴展 GitNexus 路由分析能力，讓 Route nodes 保留原始 HTTP method 資訊，支援細粒度的 API 呼叫追蹤和變更影響分析。此為多部分功能的第一階段（#2138 part 1/2），後續將進一步完善路由層級的分析精度。

### 重點
- Route nodes 持久化 HTTP method（GET, POST, PUT 等）
- 支援更細緻的 API 層級變更影響追蹤
