## Build and Run an Intelligent Document Processing (IDP) System in the Cloud

文章介紹如何在雲端環境（使用 AWS）建構和運行智能文件處理（IDP）系統，重點是自動化電子郵件中的 PII（個人可識別資訊）分類和提取。摘要篇幅限制未揭露具體架構或實現步驟，僅概述核心場景和雲端部署的效益。

### 重點
- AWS 服務自動化 PII 提取與敏感資訊檢測，減少手動處理成本
- 電子郵件分類場景適用，適配企業文件合規性需求
- 雲端部署降低基礎設施維護負擔和運營複雜度
