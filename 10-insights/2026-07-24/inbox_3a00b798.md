## vscode-v0.6.0: release: v0.35.0 (#1064)

Repowise vscode-v0.6.0 發布，完成跨越版本的同步發布。本次發布涵蓋四個 Python 套件、Claude Code 插件清單、Codex 插件升至 0.3.0、VS Code 擴展升至 0.6.0。uv.lock 依賴鎖也同步更新。獨立標籤管理確保外掛與擴展的自主發佈週期。

### 重點
- 跨四個 Python 套件、Claude Code 插件、Codex 外掛（0.3.0）、VS Code 擴展（0.6.0）的版本同步發布
- 維持 Python 依賴鎖（uv.lock）的一致性，確保環境可重現性
- 獨立標籤管理（vscode-v0.6.0），支援外掛與擴展的自主發佈週期
