## How Zalando Built an In-Process Client-Side Load Balancer for One Million Requests per Second

Zalando 工程團隊開發了一個行內（in-process）客戶端負載均衡器，能處理約 100 萬次請求/秒的高吞吐量 API 流量。此實作帶來更穩定可預測的延遲、基礎設施成本下降以及更明確的故障來源可視性。客戶端負載均衡相比傳統伺服器端方案在成本效率和診斷能力上表現優異。

### 重點
- 客戶端負載均衡器處理 ~100 萬 RPS 的高吞吐量 API
- 實現延遲更穩定可預測、基礎設施成本顯著下降
- 改善故障根源的可視性與端到端診斷能力
