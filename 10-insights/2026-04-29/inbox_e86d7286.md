## AWS Interconnect Reaches General Availability with Managed Multicloud and Last-Mile Connectivity

AWS Interconnect 正式推出，提供託管私有 Layer 3 連線到 Google Cloud，透過 Lumen 實現最後一哩路連線。Azure 和 OCI 支援預計在 2026 年下半年推出。AWS 在 GitHub 發佈底層規範（Apache 2.0 授權），Forrester 分析師認為這是 AWS 試圖為多雲連線建立事實標準的舉措。

### 重點
- AWS Interconnect GA 支援 Google Cloud 私有 Layer 3 連線與 Lumen 最後一哩路
- Azure 和 OCI 支援計劃 2026 年下半年上線
- 開放規範在 GitHub（Apache 2.0），意在建立多雲連線的業界標準
