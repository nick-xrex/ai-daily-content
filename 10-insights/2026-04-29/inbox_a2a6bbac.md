## OpenAI Expands to AWS: Amazon Adds AI Models After Microsoft Exclusivity Ends

OpenAI 宣佈與 Amazon Web Services（AWS）達成合作，在 AWS 平台上提供 OpenAI 模型服務，這標誌著 Microsoft 與 OpenAI 長期獨占協議的結束。該舉措打破過去 Azure 與 OpenAI API 的綁定格局，允許企業在多雲環境中選擇 OpenAI 模型。文章強調這不僅是合作更新，而是重塑 AI 產業競爭格局的戰略轉變。

### 重點
- OpenAI 與 AWS 合作提供模型服務，終止 Microsoft 獨占協議
- 企業用戶現可在 AWS、Azure 等多雲平台自由選擇 OpenAI 模型
- 該舉措重塑 AI 雲服務產業的競爭格局
