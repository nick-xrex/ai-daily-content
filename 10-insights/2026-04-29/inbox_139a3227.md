## The One File That Controls Every Claude Code Session (And How to Write It Correctly)

CLAUDE.md 是專案根目錄的設定檔，在 Claude Code 工作階段最初載入（早於初始提示、代碼和專案審視）。文章指出常見三個陷阱：(1) 長度超限—Claude 系統提示已佔約 50 條指令，留給 CLAUDE.md 僅 100–150 條「認知預算」；(2) 內容無關—多數開發者忽視或填入不相關資訊，浪費令牌額度；(3) 結構不明—導致 Claude 浪費時間推導建置命令。文章建議優秀的 CLAUDE.md 應能在 30 秒內「簡報」整個專案，意味著檔案須簡潔聚焦、分層組織、僅含必要資訊。此方法將直接影響每個 Claude Code 工作階段的效率。

### 重點
- 認知預算限制：系統提示已用 50 條，CLAUDE.md 只有 100–150 條指令空間，不可超載
- 30 秒簡報原則：優秀的 CLAUDE.md 應能在半分鐘內向資深工程師描述整個專案
- 三大陷阱：長度超限、無關內容、結構不明；後兩者會浪費令牌和 Claude 推導時間
