## How I configure Claude Code with settings.json

教程文章介紹如何透過 settings.json 檔案控制 Claude Code 的權限與行為。核心概念是在單一 JSON 配置檔中定義：Claude Code 可以執行哪些操作、需要確認的操作、完全禁止的操作。這讓使用者能精細化控制 Claude Code 在開發環境中的權限範圍，平衡自動化效率與安全性。

### 重點
- settings.json 集中管理 Claude Code 權限（允許/確認/禁止三級）
- 配置的「威力」來自於細粒度控制而非全有全無
- 一個小 JSON 檔案可統一管理整個 Claude Code 環境的行為策略
