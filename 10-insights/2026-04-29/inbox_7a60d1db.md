## Amazon CloudWatch Introduces OpenTelemetry Metrics Support in Preview

AWS CloudWatch 推出 OpenTelemetry Metrics 支援（公開預覽版）。開發者現在可以透過 OpenTelemetry 協議直接向 CloudWatch 發送 metrics，並將其與現有 AWS 服務 metrics 並列檢視。此舉進一步整合開源可觀測性標準與 AWS 生態系統。

### 重點
- CloudWatch 支援 OpenTelemetry metrics 發送（公開預覽）
- 開發者可將 OTel metrics 與 AWS 原生 metrics 並列檢視
- 推進 OpenTelemetry 在 AWS 生態中的整合
