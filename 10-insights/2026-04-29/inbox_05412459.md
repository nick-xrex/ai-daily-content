## OpenAI Codex Masterclass  — Vaibhav Srivastav & Katia Gil Guzman

OpenAI DevX 團隊展示 Codex 最新進展。Codex 不只是編碼 agent，而是完整軟體工程 agent，可執行命令、運行測試、探索代碼庫。模型基礎歷經 GPT-5.2、5.2 Codex、5.3 Codex、5.3 Codex Spark、5.4（最新）等迭代，每次模型改進都直接提升 Codex 能力。系統架構包含 unified agent harness、tool execution 與環保境設置，支援多表面互動（app、IDE、CLI、Slack、GitHub）及與 Figma、Linear、Notion 等工具整合。

### 重點
- Codex 5.4 為當前 SOTA，上週剛發布 mini 版本，優化長程任務和複雜任務執行
- 架構層面：unified agent harness 統一管理評估、工具執行、環境設置和安全；embedded safety 防控風險
- 多表面與工具整合：IDE 外掛、CLI、Slack/GitHub 命令、Figma/Linear/Notion API，使 agent 可操作開發全流程
