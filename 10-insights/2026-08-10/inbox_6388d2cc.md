## GitHub Code Quality Targets Maintainability as AI-Generated Code Increases

GitHub Code Quality 正式版推出（GitHub Enterprise Cloud 和 GitHub Team）。整合 CodeQL 分析與 AI 輔助的可維護性、可靠性檢測，透過 Copilot Autofix 在 pull request 中自動建議修改供審核，應對 AI 生成代碼增加帶來的代碼品質挑戰。

### 重點
- GitHub Code Quality GA：結合 CodeQL 靜態分析與 AI 檢測可維護性和可靠性問題
- Copilot Autofix 自動生成修改建議並在 PR 中進行審核
- 支援 GitHub Enterprise Cloud 和 GitHub Team 計畫
