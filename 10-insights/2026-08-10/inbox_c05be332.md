## OpenRouter API for Beginners: From API Key to Your First AI Request

這篇文章為初學者介紹 OpenRouter API 的基本使用方法，涵蓋 API 金鑰設置、發送首個 AI 請求的完整步驟。OpenRouter 是一個模型聚合平台，允許開發者透過統一介面訪問多家廠商的 LLM，無需逐一處理不同廠商的 API。文章採用手把手的教學方式，適合完全陌生 API 的新手開發者快速上手。使用 OpenRouter 的優勢在於降低切換模型與廠商的成本，開發者可以輕鬆比較不同模型的輸出，而無需重寫集成代碼。這對構建多模型應用或進行模型評估的開發者特別有用。該文章是工具使用的基礎教學資源，面向 AI 初學者。

### 重點
- OpenRouter 提供統一 API 介面訪問多個 LLM 提供商的模型，免除廠商 API 差異
- 降低開發者切換模型與進行多模型對比的成本與代碼改寫量
- 適合初學者快速上手、構建多模型應用或進行模型評估
