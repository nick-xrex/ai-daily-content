## CloudFlare Previews Automatic WebMCP Support for Web Pages

Cloudflare 推出了 WebMCP（Web Model Context Protocol）的开发者预览版本。网站管理员只需在 Cloudflare 仪表板中启用一个开关，即可为任何网站自动启用 WebMCP 接口，无需修改网站代码。启用后，AI agents 可以通过结构化的 MCP 工具与网页互动，而不是依赖脆弱的网页爬取或模式匹配。这种标准化的接口方式提高了 agent 与 web 应用的交互可靠性和效率。同时网站保持对人类流量和关键操作的控制权，避免了完全自动化带来的风险。该功能简化了 AI agents 与现有 web 系统的集成流程。

### 重點
- Cloudflare WebMCP 开发者预览让任何网站用单一开关启用，无需代码修改
- AI agents 通过结构化 MCP 工具而非网页爬取与网页互动，提高可靠性和效率
- 网站保留人类流量和控制权，避免完全自动化的风险
