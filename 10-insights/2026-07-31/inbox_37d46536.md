## datasette-agent 0.4a0

datasette-agent 0.4a0 發布新的 await context.browser_task() 機制，允許代理工具直接在用戶瀏覽器中運行代碼。該機制簡化了 Datasette Agent 插件開發，讓開發者能輕鬆創建在瀏覽器環境中執行自定義 JavaScript 的代理工具，擴展了代理在客戶端環境的能力邊界。

### 重點
- 新增 await context.browser_task() API 允許代理在用戶瀏覽器中直接執行 JavaScript 程式碼
- 簡化 Datasette Agent 插件開發，降低瀏覽器端工具集成門檻
- 擴展代理工具在客戶端環境的能力，支援更複雜的互動與自動化場景
