## How to Debug AI Coding Agents When They Change the Wrong Thing

提供 AI coding agents 的系統化 debug 教程。涵蓋記錄 tool requests、對比實際函數結果、保存 patches 和 checks、截圖記錄、以及完整 run logs。該方法論針對代理執行錯誤的程式碼修改，提供了可重現和可驗證的診斷流程。

### 重點
- 記錄 AI agent tool requests 和實際函數執行結果差異來診斷誤改
- 保存 patches、checks、screenshots 形成完整 debug 軌跡供回放驗證
- 使用 run logs 重現代理的決策鏈路進行根本原因分析
