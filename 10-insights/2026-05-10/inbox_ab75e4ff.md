## OSS UI with Skills support similar to Claude?

使用者尋求開源本地 LLM UI 並具備類似 Claude Skills 的動態技能支持能力。現有主流選項如 OpenWebUI（功能複雜且 Skills 支持不完整）、Jan（功能受限）、LM Studio（閉源且無 Skills 支持）都無法滿足需求。期望找到支持 Skills 動態載入與使用的本地 LLM 整合方案。

### 重點
- OpenWebUI、Jan、LM Studio 等開源 UI 皆缺乏 Claude 式的 Skills 動態支持機制
- 使用者期望 Skills 遷移性與統一接口，但現無可行解決方案
- 本地 LLM 工具鏈中 Skills 與 agent 能力整合仍是技術缺口
