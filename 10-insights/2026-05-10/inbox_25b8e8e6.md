## Hugging Face co-founder says Qwen 3.6 27B running on airplane mode is close to latest Opus in Claude Code

Hugging Face 共同創辦人在 Reddit 評論指出，Qwen 3.6 27B 在 AI Desktop 98 飛行模式（本地運行）的性能接近 Claude Code 最新版 Opus。帖子未提供具體性能對比數據或測試細節，僅提及在 iPhone 上運行本地 LLM 的體驗。

### 重點
- Qwen 3.6 27B 本地模型性能可接近 Claude Opus（未提供量化指標）
- AI Desktop 98 支援在本地運行開源 LLM（如 qwen）
- 飛行模式意味著完全本地運行，無須網路連接
