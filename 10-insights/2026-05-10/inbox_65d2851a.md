## MySQL 9.7: First Major LTS Since 8.4 Brings Enterprise Features to Community Edition

Oracle 公告 MySQL 9.7.0 通用版本可用，標誌 9.7 LTS 新系列的開始，也是自 MySQL 8.4 以來的首個主要版本。此版本首次將先前企業版的功能引入社區版。然而，社群中對 MySQL 開發活動下降和 Oracle 對該項目的長期承諾仍存擔憂。

### 重點
- MySQL 9.7 是自 8.4 後首個主要版本，啟動新 LTS 系列，提供更長期的支援
- 企業版功能首次在社區版本中提供，降低社區用戶升級成本
- 社群對 MySQL 開發速度放緩和 Oracle 長期承諾的持續擔憂

# MySQL 9.7: First Major LTS Since 8.4 Brings Enterprise Features to Community Edition

Oracle has announced the general availability of MySQL 9.7.0, marking the start of a new 9.7 LTS release series and the first major one since MySQL 8.4. The release arrives amid community concerns about declining MySQL development activity and Oracle's long-term commitment to the project. By Renato Losio
