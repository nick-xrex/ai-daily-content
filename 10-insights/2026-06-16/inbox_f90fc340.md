## I Turned Claude Code’s Status Line Into a Live Dashboard

作者分享了一個創意的客製化項目：將 Claude Code 終端底部的預設 status line 改造為功能性的迷你儀表板。改造後的儀表板可實時展示目前的資料夾路徑、Git 版本庫名稱以及當前分支資訊。這種視覺化的設計讓開發者無需切換視窗，就能快速瞭解目前的工作環境狀態。該示例充分展示了 Claude Code 介面的高度客製化能力，使開發者能夠根據個人需求打造專屬的開發環境。透過增強 status line 的資訊量，開發者可以顯著提升工作效率，減少環境切換造成的效率損失。

### 重點
- Claude Code status line 支援客製化為迷你儀表板
- 可實時展示資料夾路徑、Git 版本庫、分支資訊等開發環境狀態
- 透過儀表板減少視窗切換，快速掌握工作環境
