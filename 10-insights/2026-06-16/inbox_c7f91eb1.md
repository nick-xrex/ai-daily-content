## Java News Roundup: A2A Java SDK 1.0, Jakarta EE 12, JNoSQL, GraalVM, Micrometer, OpenXava, Gradle

2026 年 6 月第二週 Java 生態新聞總結，涵蓋企業級框架、構建工具和監測工具的多項發布。其中 A2A Java SDK 1.0 正式上線，Jakarta EE 12 發佈新版更新；Micrometer Metrics 和 Micrometer Tracing 推出點位發布，強化應用可觀測性；GraalVM Native Build Tools 和 OpenXava 推出維護版本，持續優化原生編譯和企業開發體驗；Gradle 9.6 RC2（第二候選版本）推進穩定化；Eclipse JNoSQL 1.2 M1 發佈首個里程碑版本，擴展 NoSQL 生態支持。這些發布覆蓋構建、監測、原生編譯、微服務框架和資料持久化等 Java 全棧關鍵領域。

### 重點
- A2A Java SDK 1.0 GA、Jakarta EE 12 更新、Gradle 9.6 RC2 推出，強化企業 Java 工具鏈
- Micrometer Metrics/Tracing 點位發布強化應用可觀測性，GraalVM Native Build Tools 維護版優化原生編譯
- Eclipse JNoSQL 1.2 M1 發布，涵蓋構建、監測、框架、原生化和 ORM 等生態各層

# Java News Roundup: A2A Java SDK 1.0, Jakarta EE 12, JNoSQL, GraalVM, Micrometer, OpenXava, Gradle

This week's Java roundup for June 8th, 2026, features news highlighting: the GA release of A2A Java SDK 1.0; an update on Jakarta EE 12; point releases of Micrometer Metrics and Micrometer Tracing; maintenance releases of GraalVM Native Build Tools and OpenXava; the second release candidate of Gradle 9.6; and the first milestone release of Eclipse JNoSQL 1.2.
