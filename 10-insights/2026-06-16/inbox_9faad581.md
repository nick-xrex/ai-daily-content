## Learn Claude Code: /export

Claude Code 內建了 /export 命令，這是一個實用的對話導出工具。使用者只需執行一個命令，就可以一鍵將整個對話歷史保存為純文本文件。該功能適用於多種場景：備份重要的對話內容、與團隊成員分享工作成果、或進行離線知識整理。相比於手動逐句複製貼上，/export 命令大幅提升了工作效率和內容可複用性。這個功能展示了 Claude Code 如何透過簡單的命令來強化使用者的生產力。

### 重點
- Claude Code 內建 /export 命令，一鍵導出完整對話歷史
- 支援將對話保存為純文本文件格式
- 適用於備份、分享、離線整理等多種使用場景
