## Java News Roundup: A2A Java SDK 1.0, Jakarta EE 12, JNoSQL, GraalVM, Micrometer, OpenXava, Gradle

InfoQ Java 生態新聞匯總（六月，2026）覆蓋 Java 及相關生態的多項發布。A2A Java SDK 1.0 正式發佈，代表新的 API 管理標準達到生產級別。Jakarta EE 12 同時發佈，推進企業級 Java 標準演進。觀測和構建工具層有多項更新：Micrometer Metrics 和 Micrometer Tracing 發佈點版本更新，強化系統可觀測能力。構建工具方面 Gradle 9.6 推出第二候選版本，GraalVM Native Build Tools 發佈維護版本。數據層面 Eclipse JNoSQL 1.2 發佈首個里程碑版本。這些發布涉及企業框架、編譯構建、運行時和數據層等多個層次，反映整個 Java 生態的持續演進。

### 重點
- A2A Java SDK 1.0 GA、Jakarta EE 12 推進企業級 Java 標準及 API 整合
- Gradle 9.6 RC2、GraalVM 更新推動構建和運行時工具鏈演進
- Micrometer Metrics/Tracing、JNoSQL 1.2 milestone 等觀測與數據層工具迭代
