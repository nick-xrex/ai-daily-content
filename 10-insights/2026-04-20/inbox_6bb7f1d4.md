## 0.122.0

Claude Code v0.122.0 發布，帶來多項重大功能更新。獨立安裝程式改進在 Windows 及 Intel Mac 上的自我包含性與應用安裝流程；TUI 新增 `/side` 快速側邊對話功能，並在執行中支援斜線命令與 shell 提示詞排隊輸入。Plan Mode 可在新鮮上下文中啟動實作，並在決策前顯示上下文使用量。插件工作流新增標籤瀏覽、內嵌啟用/停用切換、marketplace 移除功能，支援遠端、跨 repo 或本地 marketplace 來源。檔案系統權限現支援 deny-read glob 策略、託管 deny-read 需求、平台沙箱強制與隔離 `codex exec` 執行。工具發現與影像生成預設啟用，MCP 與 js_repl 影像輸出支援更高解析度與原始詳細中繼資料。此版本包含多項安全強化（logout 撤銷管理 ChatGPT token、project hook 與 exec 策略要求信任工作區、Windows 沙箱避免寬鬆權限授予）及 TUI 穩定性修復。

### 重點
- Plan Mode 支援在新鮮上下文啟動實作，顯示上下文使用量供決策參考
- 插件工作流新增標籤瀏覽、內嵌切換、跨來源 marketplace（遠端/本地/跨 repo）
- 安全增強：deny-read glob 策略、managed deny-read、Windows 沙箱隔離、logout token 撤銷、project hook 信任要求

<h2>New Features</h2>
<ul>
<li>Standalone installs are more self-contained, and <code>codex app</code> now opens or installs Desktop correctly on Windows and Intel Macs (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17022">#17022</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18500">#18500</a>).</li>
<li>The TUI can open <code>/side</code> conversations for quick side questions, and queued input now supports slash commands and <code>!</code> shell prompts while work is running (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18190">#18190</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18542">#18542</a>).</li>
<li>Plan Mode can start implementation in a fresh context, with context-usage shown before deciding whether to carry the planning thread forward (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17499">#17499</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18573">#18573</a>).</li>
<li>Plugin workflows now include tabbed browsing, inline enable/disable toggles, marketplace removal, and remote, cross-repo, or local marketplace sources (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18222">#18222</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18395">#18395</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17752">#17752</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17751">#17751</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17277">#17277</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18017">#18017</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18246">#18246</a>).</li>
<li>Filesystem permissions now support deny-read glob policies, managed deny-read requirements, platform sandbox enforcement, and isolated <code>codex exec</code> runs that ignore user config or rules (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/15979">#15979</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17740">#17740</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18096">#18096</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18646">#18646</a>).</li>
<li>Tool discovery and image generation are now enabled by default, with higher-detail image handling and original-detail metadata support for MCP and <code>js_repl</code> image outputs (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17854">#17854</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17153">#17153</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17714">#17714</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18386">#18386</a>).</li>
</ul>
<h2>Bug Fixes</h2>
<ul>
<li>App-server approvals, user-input prompts, and MCP elicitations now disappear from the TUI when another client resolves them, instead of leaving stale prompts behind (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/15134">#15134</a>).</li>
<li>Remote-control startup now tolerates missing ChatGPT auth, and MCP startup cancellation works again through app-server sessions (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18117">#18117</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18078">#18078</a>).</li>
<li>Resumed and forked app-server threads now replay token usage immediately so context/status UI starts with the restored state (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18023">#18023</a>).</li>
<li>Security-sensitive flows were tightened: logout revokes managed ChatGPT tokens, project hooks and exec policies require trusted workspaces, and Windows sandbox setup avoids broad user-profile and SSH-root grants (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/17825">#17825</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/14718">#14718</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18443">#18443</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18493">#18493</a>).</li>
<li>Sandboxed <code>apply_patch</code> writes work correctly with split filesystem policies, and file watchers now notice files created after watching begins (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18296">#18296</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18492">#18492</a>).</li>
<li>Several TUI rough edges were fixed, including fatal skills-list failures, invalid resume hints, duplicate context statusline entries, <code>/model</code> menu loops, redundant memory notices, and terminal title quoting in iTerm2 (<a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18061">#18061</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18059">#18059</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18054">#18054</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18154">#18154</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18580">#18580</a>, <a class="issue-link js-issue-link" href="https://github.com/openai/codex/pull/18261">#18261</a>).</li>
</ul>
