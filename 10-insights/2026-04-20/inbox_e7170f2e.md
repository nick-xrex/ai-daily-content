## Java News Roundup: OpenJDK JEPs, Jakarta EE 12, Spring Framework, Micrometer, Camel, JBang

Java 生態系統 2026 年 4 月更新，包括新的 OpenJDK JEPs、Jakarta EE 12 進展、Spring Framework 維護版本、Micrometer、Camel 與 JBang 的點版本更新。本次更新涵蓋多個框架版本升級、安全修復（CVE 解決）與新工具測試版發布，包括 Spring Data 與 Micrometer Metrics 首次 RC 版本、Eclipse Store 與 Eclipse Serializer 的測試版本。

### 重點
- OpenJDK 新增多個 JEPs，Apache Grails、Camel、JBang 提供點版本更新
- Spring Framework 包含 CVE 安全修復的維護版本
- Spring Data 與 Micrometer Metrics 首次候選版本（RC）發布
