## How Intercom 2x’d their engineering velocity in 9 months with Claude Code | Brian Scanlan

这也验证了 AI 代码助手在企业级应用中的实际效能，不仅加速单个开发者的编码效率，更重要的是通过组织层面的变革能够产生倍增效果。Intercom 团队在 Brian Scanlan 的领导下，通过采用 Claude Code 在 9 个月内实现了工程速度翻倍增长。这一成果基于三个互相支撑的因素：首先，充分运用 Claude Code 提供的各项技能和能力来加速开发流程；其次，建立深度的遙測体系持续收集和分析工程效率数据，形成数据驱动的决策基础；第三，打造一种赋能工程师快速发布、敢于尝试的组织文化。这个案例表明仅有工具本身是不够的，需要工具、数据和文化的三位一体配合，才能实现生产力的质的飞跃。对于正在寻求工程效率提升的组织，这提供了一个完整的参考模板。

### 重點
- Intercom 用 Claude Code 在 9 个月内实现工程速度 2 倍增长
- 成功三要素：Claude Code 技能 + 深度遙測数据 + 赋能工程师文化（缺一不可）
- 工具 + 数据 + 组织文化的三维组合是生产力倍增的关键，工具本身不充分
