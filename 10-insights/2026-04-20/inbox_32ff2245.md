## Google ADK for Java 1.0 Introduces New App and Plugin Architecture, External Tools Support, and More

Google Agent Development Kit for Java 發佈 1.0 版本，新增外部工具集成、應用與插件架構、高級 context engineering 和人工介入工作流等功能。此版本達到穩定發佈里程碑，為 Java 開發者提供完整的生產級 agent 開發框架。
