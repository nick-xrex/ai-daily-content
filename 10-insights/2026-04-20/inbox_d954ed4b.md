## Google ADK for Java 1.0 Introduces New App and Plugin Architecture, External Tools Support, and More

Google Agent Development Kit for Java（ADK）達到 1.0 版本，引入新的應用程式與外掛架構、外部工具整合、進階上下文工程與人類參與迴圈等功能。此版本標誌著 Google 對 Java 開發人員提供完整代理開發框架的承諾，涵蓋應用程式管理、工具擴展性與人類協作等關鍵需求。新架構使開發人員能更靈活地構建智能代理系統，整合外部工具實現更複雜的自動化工作流。

### 重點
- Google ADK for Java 1.0 正式發布，包含新應用架構與外掛系統
- 支援外部工具整合、上下文工程與人類參與迴圈（human-in-the-loop）
- 為 Java 開發者提供生產級代理系統建構框架
