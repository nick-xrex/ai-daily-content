## Claude Code Adds Dynamic Workflows for Parallel Agent Coordination

Anthropic 在 Claude Code 推出 Dynamic Workflows 功能。用於協調多個 AI agents 執行複雜軟件工程任務。支援動態生成編排腳本、並行執行子任務、驗證結果。實現大規模 agent 協調的完整工作流。適用於複雜工程場景，推進軟件開發自動化。

### 重點
- Claude Code 新增 Dynamic Workflows，動態協調多個 AI agents 執行複雜任務
- 支援動態編排腳本、並行子任務執行、結果驗證三層架構
- 大規模 agent 協調模式，推進工程流程自動化
