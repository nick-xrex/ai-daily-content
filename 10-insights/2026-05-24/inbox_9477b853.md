## DeepSeek reasonix, DeepSeek native coding agent with high caching and low cost

DeepSeek 推出 Reasonix，一款原生編碼代理，強調高快取利用和低成本特性。該工具設計用於幫助開發者提升編碼效率，同時降低 API 調用成本。DeepSeek 於相同時期宣佈 V4 Pro API 的價格折扣永久化，原價的 25%。這一系列舉措表明 DeepSeek 在成本友善型 AI 編碼工具市場上的定位。Reasonix 代表了 AI 編碼代理領域的競爭加劇，推動成本和效率優化。

### 重點
- DeepSeek Reasonix 原生編碼代理，特點是高快取利用率和低成本運營
- V4 Pro API 永久折扣至原價 25%（相當於 75% 折扣）
- 高快取機制 + V4 Pro 永久 75% 折扣，大幅降低編碼代理的使用成本
