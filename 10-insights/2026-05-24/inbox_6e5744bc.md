## The AI paradox: More automation, more humans, more work | Dan Shipper

Dan Shipper 提出 AI 工作新悖論：自動化程度提高反而增加人類工作量。他認為未來大多數工作將在 Codex 或 Claude Code 內進行，CLI 時代已經結束，每個 AI agent 都需要人類監督。這反映出 AI 助手從純工具演進為工作流中心，但決策與質控仍需人類參與。他對 PM 和設計師的未來角色持高度樂觀態度，認為他們能在 AI 時代發揮更大價值。

### 重點
- Codex/Claude Code 成為工作中心，取代傳統 CLI 工作流
- Agent 需要人類監督，自動化反而擴大人類參與空間
- PM 和設計師角色升級，成為 AI 時代的關鍵決策者
