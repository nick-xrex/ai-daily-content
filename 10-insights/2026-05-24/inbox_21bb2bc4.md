## O que é Claude Code

葡萄牙文文章解釋 Claude Code 與傳統聊天機器人的區別。Claude Code 是針對軟體開發的 AI 代理，不僅回答文字詢問，而是主動分析本地程式碼庫、理解相關檔案、建議修改、且在獲得權限後可編輯檔案、執行終端命令。相較於傳統聊天機器人只能解釋 BUG 修復方式，Claude Code 可自主調查登入失敗、找出根本原因、提出修正、直接修改程式碼、協助 Git 流程，集成於 IDE、終端、Slack、網頁介面。文章強調技術加速需與架構、安全、可擴展性、維護深度的權衡搭配。

### 重點
- 代理 vs 聊天機器人：分析程式碼庫、編輯檔案、執行命令，而非僅文字回答
- 多環境整合：IDE、終端、Slack、網頁介面，跨多開發工具
- 技術判斷仍須：AI 加速開發但不能取代架構、安全、可擴展性考量
