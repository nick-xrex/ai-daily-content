## datasette-agent 0.1a4

datasette-agent 0.1a4 版本發布，充分利用 Datasette 1.0a30 新增的 makeJumpSections() JavaScript plugin hook。新版本將 Agent 聊天界面整合至 Jump to 菜單中，用戶可在任何時刻按 / 鍵直接啟動新的 agent 對話。用戶可在 agent.datasette.io 使用 GitHub 帳號登入試用此功能。

### 重點
- 版本 0.1a4：整合 Jump to 菜單，按 / 啟動 agent 聊天
- plugin hook：利用 makeJumpSections() 的新 JavaScript API
- 測試環境：agent.datasette.io 支援 GitHub OAuth 登入
