## AWS Announces General Availability of DevOps Agent for Automated Incident Investigation

AWS 宣佈 DevOps Agent 正式上市 (GA)，這是一個生成式 AI 助手，旨在幫助開發者和運維人員跨 AWS 環境進行故障排除、部署分析和自動化運維任務。此工具整合了 AWS 原生能力，簡化了複雜環境中的事件調查和操作自動化流程。

- AWS DevOps Agent 達到 GA 正式版本
- 支援跨 AWS 環境的故障排除與部署分析
- 自動化運維任務，降低事件調查複雜度
