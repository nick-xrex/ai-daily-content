## A Month With Claude Code: It’s Really Not the Same Thing as ChatGPT

mcAlex 分享一個月使用 Claude Code 的實務經驗。Claude Code 與 ChatGPT 的根本差異在於運作模式：而非對話式的來回互動，Claude Code 功能更像命令行工具，能讀取檔案、編輯檔案、執行測試、檢查 git diff，甚至協助 commit。一名獨立開發者用 Claude Code 在兩天內完成 Node.js/PostgreSQL 餐廳訂位後端（估計手動開發需 4-5 天），工具還識別出開發者遺漏的 SQL 注入漏洞。限制包括跨專案工作困難、大型代碼庫的上下文遺忘、Monorepo 編輯錯誤位置、遠程調試受限。Claude Code Pro 定價 $20/月，相比雇用初級開發者划算。

### 重點
- Claude Code vs ChatGPT：完全不同的運作模式，自主執行 + 檔案操作 vs. 對話式
- 實務提速：2 天完成 4-5 天工作量，並自動發現 SQL 注入漏洞
- 已知限制：跨專案、大型代碼庫、Monorepo、遠程調試困難
