## Release Candidate v1.6.9-rc.4

GitNexus v1.6.9-rc.4 發布，包含四項新增功能與修復。新增 Python 原始碼/下沉點模型進行污點追蹤分析（taint analysis），擴展程式安全檢查能力。新增 Kotlin Spring HTTP 消費者提取功能，與 Java 提供者達到功能對等。修復 LadybugDB 在 PDG 分析時的雙重釋放（double-free）錯誤並強化連線序列化。新增 Django 多倉庫路由提取功能（#1836），首次支援跨多個倉庫識別 Django 路由。本 RC 為穩定版 1.6.9 的第 4 個候選版本，供早期測試。

### 重點
- Python 污點分析新增原始碼與下沉點模型，支援程式安全脆弱性檢測
- Kotlin Spring HTTP 消費者提取達到與 Java 提供者功能對等
- LadybugDB 雙重釋放修復與連線序列化強化，提升 PDG 分析穩定性
- Django 多倉庫路由提取支援，包括鑽石路由模式與非列表 urlpatterns 處理
