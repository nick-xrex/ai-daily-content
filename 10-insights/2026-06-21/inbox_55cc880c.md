## The OpenAI and Anthropic weekly brief (Week 25, 2026)

Tibor Blaho 的第 25 週 OpenAI 和 Anthropic 簡報統整雙方動向。OpenAI 恢復 ChatGPT 的定時任務功能（帶改進的監控）、淘汰 Pulse、部署 GPT-5.5 Instant 作為新健康智能標準（向免費用戶開放，健康相關事實性錯誤下降 71%）。發佈部署模擬方法論預測模型行為異常，強化學習對齊研究顯示 44/53 獨立評估改進。此外 Noam Shazeer（Transformer 共同作者）加入 OpenAI，開設斯德哥爾摩辦公室，向 Rust 基金會投入 $60 萬。Anthropic 建立首爾辦公室與韓國 AI 生態合作，Claude Design 刷新支援與 Claude Code 雙向同步 + 新出口選項。Project Fetch 第二階段展示 Claude Opus 4.7 自主編程機器人速度提升 20 倍。Workload Identity Federation 正式推出，以臨時域內憑證替代靜態 API 金鑰。經濟指數報告分析 ~40 萬 Claude Code 會話，發現領域專業知識比編程背景更關鍵。

### 重點
- OpenAI：GPT-5.5 Instant 健康應用誤報率 -71%、恢復定時任務、Noam Shazeer 加入
- Anthropic：Claude Opus 4.7 自主編程速度 20 倍提升、Workload Identity Federation 正式推出
- 市場信號：40 萬 Claude Code 會話分析顯示領域專業知識優於編程背景
