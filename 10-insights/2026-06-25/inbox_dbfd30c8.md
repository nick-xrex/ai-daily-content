## Cloudflare Ships Agent Skills for Zero Trust Deployment and Migration

Cloudflare 發布開源的 Cloudflare One Stack，一套面向 Zero Trust 環境規劃、部署與管理的代理技能庫。該技能庫包含針對 Zscaler 和 Palo Alto Networks 的自動化遷移邏輯，與 Cloudflare 的 Descaler 計畫採用相同邏輯，該計畫已將企業客戶的遷移時間從數月縮短至數小時。開源化這些遷移技能使企業能夠用代理自動化複雜的基礎設施部署和遷移工作流程。

### 重點
- Cloudflare One Stack 是開源代理技能庫，支援 Zero Trust 環境部署與自動化遷移
- 自動化遷移邏輯已在 Descaler 計畫中驗證，將遷移時間從月級縮短至小時級
- 支援 Zscaler 和 Palo Alto Networks 自動化遷移
