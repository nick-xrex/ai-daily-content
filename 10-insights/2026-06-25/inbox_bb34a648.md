## Build Your Own Local LLM Agent Workflow in 400 Lines of Python

教程介紹如何用 Python 在 400 行代碼內構建本地 LLM agent 工作流。核心方法是將單一 agent 轉變為可重複的人工審閣管道，採用編號文件夾和 Markdown 純文本組織，支持分層 context 加載機制。適合想要自託管 LLM 系統且避免 API 依賴的開發者。

### 重點
- 400 行 Python 代碼實現完整 agent 工作流
- 採用編號文件夾 + Markdown 組織 context，支持人工把關
- 本地運行避免 API 調用，降低成本與延遲
