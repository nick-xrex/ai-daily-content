## How OpenAI Optimized AI Agents For Scale

OpenAI 通过 Harness、API 和推理三个层面的效率优化来支持 Codex 和 ChatGPT Work 的快速扩展。Harness 级别优化加速模型训练和推理框架，API 效率优化提升并发处理和降低调用延迟，推理层优化减少端到端延迟并增强成本效益。这套多层级优化范式展示了大规模 AI Agent 系统从基础设施到应用层的全景优化策略。

### 重點
- Harness 级框架优化：加速模型训练和推理框架执行，直接提升系统吞吐量
- API 层效率优化：通过并发控制和请求聚合减少延迟，增强用户端体验
- 推理执行优化：降低模型推理延迟，直接支持 Codex（代码生成）和 ChatGPT Work（工作流）的大规模部署
