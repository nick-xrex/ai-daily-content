## How I Built a Claude Code Skill to Write Sales Proposals

作者分享了如何利用 Claude Code 技能自動化銷售提案撰寫流程。系統接收四個關鍵商務輸入，經 Claude Code 處理後在 30 分鐘內交付成品提案。這相較於傳統手工撰寫的數日周期，效率提升顯著。文章並反思人類在此工作流中的角色邊界，指出即使 AI 能自動生成，人工審核與商務決策層仍不可或缺。此案例代表了 Claude Code（結合代碼執行與多輪推理）在商務文檔自動化中的實踐應用，對銷售、運營團隊的效率優化具有直接參考價值，同時也突出了人機協作的必要邊界。

### 重點
- Claude Code 技能整合四個業務輸入，自動生成完整銷售提案，時間從數日縮至 30 分鐘
- 自動化程度雖高，但人工審核商務邏輯與最終決策層仍是必要環節
- 此模式適用於其他結構化文檔生成任務（合約、報告、計畫書），展示 Claude Code 在商務流程自動化的潛力
