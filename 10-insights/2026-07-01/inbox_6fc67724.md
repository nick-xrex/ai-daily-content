## HeroUI v3 Lands as a Ground-Up Rewrite for React and React Native, Built on Tailwind CSS v4

HeroUI v3 發布為 React 元件庫的完全重寫版本（原為 NextUI），提供 75+ 元件、新增 21 個元件。同時推出 React Native 子庫含 37 個元件。新版本基於 React Aria 與 Tailwind CSS v4，強調無障礙性（accessibility）與自訂彈性。與舊版本的遷移需做相應調整。

### 重點
- React 元件庫完全重寫，75+ 元件（新增 21 個）
- React Native 版本新增 37 元件
- 基於 React Aria、Tailwind CSS v4，強調無障礙性
