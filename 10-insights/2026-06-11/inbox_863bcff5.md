## Learn Claude Code: /autofix-pr

Claude Code 推出 /autofix-pr 功能，允許開發者將 PR 交由 Claude Code 的 web session 自動監視、審查和修復。該功能持續監控 CI 構建結果並執行代碼審查，在開發者離線時自動推送修復提交。這個工具將 PR 審查從同步阻塞轉變為異步自動化，適合分佈式團隊和持續交付工作流，加速 feedback loop 和代碼合併週期。具體修復成功率或支持的 CI/CD 平台範疇未在摘要中詳述。

### 重點
- Claude Code /autofix-pr：自動 PR 監視、審查、修復的非同步工作流
- 無需開發者同步等待，CI 失敗時自動執行代碼分析和修復提交
- 降低 PR 審查週期的人工成本，加速分佈式團隊的代碼交付速度
