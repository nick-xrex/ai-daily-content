## OpenAI's GPT-5.5 and Codex Reach General Availability on Amazon Bedrock

OpenAI 的 GPT-5.5、GPT-5.4 和 Codex 在 Amazon Bedrock 上正式上市，实现了一个月前修订独家 Azure 协议后的重要里程碑。AWS 用户可按 OpenAI 官方定价使用这些模型，消费额计入 AWS commitments。Codex 改为按 token 计费、取消座位费。GPT-5.4 首次登陆 AWS GovCloud，扩展了政府云端的模型选择。这标志着 OpenAI 模型生态在云平台上的进一步商业化。

### 重點
- GPT-5.5、GPT-5.4、Codex 在 Amazon Bedrock 通用（取代 Azure 独家安排）
- 定价与 OpenAI 官方一致、消费计入 AWS commitments；Codex 改为按 token 计费无座位费
- GPT-5.4 首度在 AWS GovCloud 上市，政府云端模型选项扩展
