## The Hidden Cost of JSON in the AI Era

文章分析 JSON 在 AI 時代的隱藏成本。根據副標題，LLM 傾向使用 TOON 等替代格式而非 JSON，token 成本的差異正迫使業界重新思考資料格式的選擇。這個洞見揭示了在大規模 LLM 應用中，序列化格式直接影響推理成本。不同的資料格式在 tokenization 效率上存在顯著差異，例如 JSON 的冗餘括號與鍵值對結構可能導致 token 膨脹。此發現對依賴 LLM API 的企業具有實務意義，可能改變結構化資料的設計與存儲策略。

### 重點
- LLM 傾向 TOON 等替代格式，JSON 的 token 成本較高
- 資料格式選擇直接影響 LLM 推理成本與 API 費用
- 需重新評估結構化資料的序列化策略以優化 token 效率
