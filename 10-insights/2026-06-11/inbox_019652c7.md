## Presentation: Building and Scaling UI Systems for Internal Tools at Meta

Meta 分享了統一 UI 系統 XDS 的設計與演變過程。XDS 目前支撐公司內部超過 10,000 個內部工具的開發。系統在三個層面提供關鍵價值：首先，使用 JavaScript AST 和 AI 驅動的 codemod 自動化大規模 monorepo 的安全重構，減少人工介入；其次，通過特性標誌（feature flag）機制來漸進式地遷移，消除破壞性變更的風險；再次，將 UI 庫邊界逐步擴展為包含路由、狀態管理等完整全棧功能的平台。此演講特別針對軟體架構師和工程主管，提供了可操作的大規模社群貢獻管理實踐。

### 重點
- XDS 統一 UI 系統支撐 Meta 內部 10,000+ 個工具，解決跨團隊協調成本
- 使用 JavaScript AST 和 AI codemod 自動化大規模 monorepo 重構，降低人工成本
- 通過特性標誌（feature flag）和漸進式遷移策略消除破壞性變更風險
