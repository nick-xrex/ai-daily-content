## Claude Code PushNotificationTool

Claude Code 宣布推出 PushNotification 工具功能。該工具是 Claude Code 環境中的原生功能，允許開發者透過程式碼直接呼叫。使用者可利用此工具向手機或 Claude 應用程式發送推送通知。這項功能增強了開發工具的行動裝置整合能力，提升開發工作流程與用戶間的即時溝通。

### 重點
- Claude Code 推出原生 PushNotification 工具，支持程式碼呼叫
- 支持向手機裝置和 Claude 應用程式發送推送通知
- 增強開發工具與用戶設備的互動能力
