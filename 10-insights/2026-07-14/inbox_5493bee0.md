## datasette 1.0a37

Datasette 發布 1.0a37 alpha 版本，主要包含權限系統的效能優化與文檔改進，並還原了一個在先前版本中導入的 API 變更（該變更破壞了幾乎所有現有插件的測試套件）。此版本為常規維護發布。

### 重點
- 權限系統效能與文檔改進
- 還原 API 變更以修復插件測試相容性問題
