## Google Cloud Workbench Notebooks Extension Connects VS Code to Google Cloud's Jupyter Notebooks

Google Cloud 推出 Workbench Notebooks VS Code 擴展，為開發者提供新的混合開發選項。該擴展使開發者能將本地 VS Code IDE 直接連接到 Google Cloud 上的受管 Jupyter notebook 環境。此工具簡化了跨 Cloud 與本地開發環境的協作流程，允許開發者在熟悉的 VS Code 編輯器中操作 Cloud 端 notebooks。目標用戶是需要在 Google Cloud 進行 notebook 型開發工作的開發者和數據科學家。該擴展是 Google 持續改進其 Cloud IDE 工具生態的一部分。

### 重點
- VS Code 擴展直接連接本地 IDE 至 Google Cloud Jupyter notebooks
- 簡化混合開發工作流，支持在 VS Code 環境中操作 Cloud 端 notebooks
