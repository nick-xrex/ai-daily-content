## How to Make Claude Code Follow Your Project Rules

本文介紹如何透過 CLAUDE.md 檔案、scoped rules 和 reusable skills 三項機制，確保 Claude Code 遵循專案開發規範。重點是建立明確的規則定義層級和可複用的技能庫，使 AI 助手成為開發工作流中的可靠夥伴。這套方法論將 AI 整合工作從臨時性降低為系統化實踐，顯著提高程式碼品質和團隊協作效率。

### 重點
- 使用 CLAUDE.md 檔案定義全域和專案級規則，實現規則的版本控制和團隊共享
- 透過 scoped rules 實現不同元件、模組或專案的細粒度控制，避免衝突
- 建立 reusable skills 庫讓 Claude Code 複用驗證過的工作流和最佳實踐
