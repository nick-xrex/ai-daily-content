## How to Plan a Claude Code Loop for Auditing and Refactoring KPIs

本文展示如何規劃 Claude Code 迴圈進行 KPI 審計和重構。核心方法論分為三步：Find（尋找 KPI 計算邏輯）、Fix（修正問題和最佳化）、Verify（驗證修改結果）。這套框架讓 Claude Code 系統化地檢查業務專案中的 KPI 相關程式碼，提高計算準確性和程式碼品質，降低手工審計成本。

### 重點
- 三步 workflow：Find 定位 KPI 計算、Fix 修正邏輯問題、Verify 驗證修改結果
- 自動化審計業務邏輯，減少人工審查時間和錯誤率
- Claude Code 迴圈可複用於其他商業邏輯稽核場景
