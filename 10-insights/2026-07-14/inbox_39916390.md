## Claude Loops 2: Context Is the Hidden Loop

本文探討 Claude 長時間會話中性能衰退的根本原因，核心論點為「context 是隱藏的 loop」。隨著對話長度增加，Claude Code sessions 的品質逐漸下降，成為長會話 agent 系統的核心瓶頸。文章提出四層管理策略應對此問題：memory 管理、context compacting、清除冗餘段落、以及透過 subagents 分流工作。該框架提供了設計長會話系統時如何在保持品質與 context 成本之間找到平衡的實踐指引。

### 重點
- 長 context 是 Claude Code 隱藏的效能成本，需主動管理而非被動容納
- 四層策略（memory、compacting、clearing、subagents 分流）可分散 context 壓力
- 設計長會話 agent workflow 時必須預先規劃 context 衰減曲線以保質量
