## Engineers Are Still Saying No For A Reason That Stopped Being True

GitHub 觀察到工程團隊的決策成本已經超過實現成本。對於某些類別的變更，進行技術爭論、審查和決策所消耗的時間與資源已經比直接實現該變更更高。這種成本倒轉改變了工程師對於拒絕新提案的成本效益計算，迫使團隊重新思考決策流程設計。

### 重點
- GitHub 觀察：某類變更的決策成本 > 實現成本，改變了技術拒絕的經濟邏輯
- 工程實踐演進：當辯論成本 > 實現成本時，應該降低決策門檻允許更多嘗試
- 對敏捷開發和快速迭代的深層啟示
