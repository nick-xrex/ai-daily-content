## Java News Roundup: Value Objects, WildFly 41, TornadoVM, LangChain4j, Oracle AI Agent Studio

InfoQ 發布 2026 年 7 月第二週的 Java 生態版本摘要，涵蓋多個主要項目和工具的更新發布。核心項目升級包括：Value Objects 以 Preview 狀態重新回歸 Java 語言、WildFly 41 達成 GA 階段、Open Liberty 26.0.0.7 七月版本發布。工具鏈方面，TornadoVM、Apache TomEE、Java Operator SDK 和 LangChain4j 都發布了 point releases，其中 LangChain4j 推進了 Java 生態的 AI/LLM 集成能力。此外，Oracle 推出了新的 AI Agent Studio for Fusion Applications，專門支援企業應用層的 AI 代理開發；Micronaut 發布維護更新，Quarkus 引入新的 Shim extension 擴充功能。

### 重點
- WildFly 41 GA 發布、Value Objects Preview 回歸、Open Liberty 26.0.0.7 釋出
- LangChain4j 進行 point release，強化 Java 對 AI/LLM 工具鏈的原生支援
- Oracle 推出 AI Agent Studio for Fusion Applications，針對企業 SaaS 應用的 AI 代理開發
