## Azure API Management Ships Unified Model API and MCP Content Safety at Build 2026

Azure API Management (APIM) 在 Build 2026 發佈統一模型 API 與 MCP 內容安全功能。核心創新：(1) 統一模型 API 允許客户端使用單一格式，APIM 自動轉譯請求至 Anthropic、Vertex AI 與其他後端，簡化多模型集成；(2) 內容安全政策擴展覆蓋 MCP 工具呼叫與 Agent-to-Agent 承載，不限於 LLM 流量；(3) Token 指標追蹤推理、快取與音訊 Token 跨多家供應商。此舉標誌企業 AI Gateway 從單一模型支援向多模型、多協議統一管理的演進。

### 重點
- 統一模型 API 支援 Anthropic、Vertex AI 等多個後端，客户端代碼無需改動
- 內容安全政策首次涵蓋 MCP tool calls 與 Agent-to-Agent payloads，超越傳統 LLM 流量監控
- Token metrics 新增推理、快取、音訊三種 Token 類型追蹤，跨供應商計費透明化

# Azure API Management Ships Unified Model API and MCP Content Safety at Build 2026

Azure API Management shipped a Unified Model API that lets clients speak one format while APIM transforms requests to Anthropic, Vertex AI, and other backends. Content safety policies now cover MCP tool calls and Agent-to-Agent payloads alongside LLM traffic. Token metrics expanded to track reasoning, cached, and audio tokens across providers.
