### 1. Claude Code v2.1.108：快取調優與會話復原新功能

開發團隊應重點關注：快取設定如何影響單位成本與回應速度（特別是針對 API 費用敏感的工作負載），以及 Skill 發現機制如何簡化工具鏈集成。建議在 Bedrock/Vertex 環境中優先測試新快取參數，驗證與主流 Claude API 的一致性。

### 3. GPT-5.4-Cyber 專有化與信任驗證機制並行
OpenAI 推出 GPT-5.4-Cyber，一個為防禦性網路安全工作特別微調的 GPT-5.4 變體，同步擴展 2 月啟動的「Trusted Access for Cyber」計畫。使用者可透過 Persona 驗證政府核發身分證件後自助獲得基礎模型存取權；頂級工具仍需額外申請，整體做法與 Anthropic 的 Project Glasswing 相近。

這一動作反映了業界對 AI 安全能力雙重監管的共識：既要讓合法防禦者能快速獲得最新工具，又要防止進階能力外流。GPT-5.4-Cyber 的專有化微調展示了比通用模型更精準的安全任務匹配，降低了偽正例的誤導；分層驗證機制（基礎自助、進階申請）平衡了易用性與管制。

安全採購經理應監控兩家廠商驗證流程的差異與穩定性。工程師應評估 GPT-5.4-Cyber 微調範圍及其與通用 GPT-5.4 的推理能力差異。長期來看，這兩家廠商的分層模式可能成為 AI 安全能力分發的行業標準。
